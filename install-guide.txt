
==== 법령검토 · 세법자문-회신 스킬을 쓰려면 (처음 한 번) ====
1) 법제처 OPEN API 인증값(OC): https://open.law.go.kr 회원가입 -> OPEN API 신청 (승인 1~2일)
   OC 는 가입 아이디(이메일 @ 앞부분). 법령 본문·부칙, 행정규칙, 판례·해석례·헌재결정례, 별표·서식, 조세심판원을 모두 체크
2) korean-law 서버 등록 (<본인OC> 를 바꿔 넣는다):
   claude mcp add -s user korean-law -e LAW_OC=<본인OC> -- node "{MCP_INDEX}"
3) 행정해석·판례 본문 검색·고시(korean-law-mcp): 클로드 설정 > 커넥터 > 커스텀 커넥터 추가에
   https://mcp.gomdori.app/law?oc=<본인OC>
   OC 는 1) 과 같다. ?oc= 를 빼면 키 없는 사용자가 함께 쓰는 한도에 걸려 자주 막힌다
4) 세법을 볼 때 TaxDoctor: https://taxdoctorai.com 무료 가입 -> 클로드 설정 > 커넥터 > 커스텀 커넥터 추가
   주소 https://mcp.taxdoctorai.com/mcp
5) 앱을 다시 열고 "민법 제162조 원문 찾아줘" 로 확인
자세한 안내: https://github.com/hany202507/finance-ai-skills/tree/main/skills/%EB%B2%95%EB%A0%B9%EA%B2%80%ED%86%A0 (준비 절)

==== 양도소득세 스킬의 법령 기준 ====
- 세율·공제율·신고기한은 설치한 판의 기준정보 확인일 기준이다. 그 뒤에 공포된 개정은 계산에 들어가지 않는다
- 확인일에서 7일이 지나면 모든 계산 결과에 갱신 경고가 붙는다. 확인일은 "양도소득세 기준정보 확인일 알려줘" 로 본다
- 새 기준정보 받기: 이 설치 줄을 다시 실행한다(스킬 폴더를 덮어쓴다). 저장소의 확인일은 운영자가 갱신해 올린 날이다
- 직접 갱신하기(위 1·2·4 를 마친 뒤): ~/.claude/skills/양도소득세 에서(맥·리눅스는 python3)
   python scripts/refresh/fetch_articles.py
   python scripts/build_ruleset.py build
- 공포 전 개정안 경고(계류)는 정부가 낸 안과 국회를 통과한 안만 담는다. 다른 개정 소식은 법령검토 스킬에 "최신 개정 반영됐나" 로 묻는다
