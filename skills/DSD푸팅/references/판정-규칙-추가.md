# 판정 규칙 추가분

보고서 35건의 안 맞음을 판정하며 나온 규칙이다(2026-10-13). 판정 기록에 적힌 식 208개를 뜻이 같은 것끼리 묶어 84개로 정리했다. 등급은 여러 보고서의 판정을 모아 정한 제안이다. `판정-근거.md` 의 A 규칙과 같은 식도 넷 있다(N04 는 A16, N14 는 A15, N76 은 A13, N77 은 A14).

- 근거 문단은 판정 에이전트가 회계기준 조회 도구로 확인해 적은 것을 모았다. 숫자만 적힌 문단은 K-IFRS, 「일반」 은 일반기업회계기준이다.
- 조건부 식은 `연결.json` 에 `when` 으로 조건을 적는다.

## 규칙 표
