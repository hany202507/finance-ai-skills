# 주석 유형별 연결

주석을 읽고 연결을 적을 때 대조하는 목록이다. 회사마다 주석 구성이 다르므로 그 주석의 제목과 문장이 이 목록보다 우선이다. 목록에 없어도 주석의 뜻으로 같아야 하는 칸이면 건다.

- 근거(2026-10-13): 보고서 35건. 일반기업회계기준 9, K-IFRS 별도 13 · 연결 13. 앞 판(2026-10-12)의 네 건에 공시 보고서 31건을 더했다. 업종은 제조, 건설, 유통, IT, 바이오이고 규모는 대형, 중견, 소형이다.
- 금융업은 아직 읽지 않았다.
- 표기: 「주석」 은 그 주석의 표, 「BS」 재무상태표, 「IS」 손익계산서(포괄손익계산서), 「CF」 현금흐름표, 「SCE」 자본변동표, 「OCI」 기타포괄손익, 「FVPL」 당기손익-공정가치, 「FVOCI」 기타포괄손익-공정가치.
- 근거 수: 「주의」 끝의 괄호는 그 유형을 걸었거나 고치자고 적은 보고서 수다. 「K」 는 K-IFRS 별도, 「연결」 은 K-IFRS 연결, 「일반」 은 일반기업회계기준이다. 「(1건)」 은 한 보고서에서만 나온 유형이다. 그 주석의 문장을 먼저 본다. 「(앞 판)」 은 앞 판의 네 건에서 확인했고 이번 31건의 보고서가 따로 적지 않은 유형이다.
- 현금흐름표와 잇는 식(취득, 처분, 신규리스)은 주석에 식의 항이 적혀 있을 때 건다. 항이 주석에 없으면 걸지 않고 「회계사 확인」 으로 보고한다. 조건은 유형마다 「주의」 에 적었다.
- 주석에 문장이 없고 줄 이름과 표의 구성으로만 읽은 연결은 걸되 `basis` 에 「주석에 문장은 없다」 를 적고 보고의 「내 이해가 틀렸을 수 있는 연결」 에 넣는다.

## 현금및현금성자산, 단기금융상품 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 주석 합계(당기말, 전기말) = BS 과목 | 내역이 한 줄뿐이어도 합계 줄에 건다 (앞 판) |
| 사용제한 예금 주석의 금액 = 그 예금의 주석 금액 | 통화 단위(JPY)로 적힌 표는 외화 금액 칸과 맞춘다 (앞 판) |
| 사용제한 예금만 적은 주석의 합계 | BS 현금및현금성자산에 걸지 않는다. BS 과목이 그 주석을 가리켜도 일부만 담은 표다. 현금 구성 표가 따로 없으면 걸 곳이 없다고 보고한다 (일반 2건) |
| 사용제한 금융상품의 줄 = 담보제공자산 주석 · 약정 주석 · 특수관계자 담보 표의 같은 예금 줄 | 같은 이름 줄이 여럿이면 `row_nth`. 질권이 설정된 예금처럼 일부만 제한된 줄은 걸지 않는다 (K 1 · 연결 2건) |
| CF 당기 기초의 현금 = 전기 기말의 현금 | 같은 표의 두 열이라 `links` 에 적는다 (앞 판) |

## 매출채권, 대손충당금, 손실충당금 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 구성 표의 총액 = BS 매출채권 | BS 가 충당금을 따로 적으면 BS 매출채권은 총액이다 (앞 판) |
| 구성 표의 대손충당금 = BS 대손충당금 | BS 에 대손충당금이 여럿이면 매출채권 바로 아래 줄(`row_nth`) (앞 판) |
| 구성 표의 합계(순액) = BS 매출채권 + BS 대손충당금 | (앞 판) |
| 충당금 변동표의 기말 = 구성 표의 대손충당금(손상차손누계액) | 부호가 반대인 경우가 많다. 변동표가 재무위험관리(신용위험) 주석 안에 있는 보고서가 있다. 난외약정 손실충당금이 채권 차감 금액에 섞인 보고서가 있었다 (K 2 · 연결 3건) |
| 충당금 변동표의 당기 기초 = 전기 기말 | 당기와 전기가 한 표의 두 열이면 `links` 에 같은 표를 양쪽에 적는다 (연결 1건) |
| 충당금 변동표의 설정 + 환입 = 판관비 대손상각비 + 기타의대손상각비 - 기타의대손충당금환입 | 채권 종류를 가르지 않은 변동표는 총액끼리 안 맞고 순액으로 맞는다. 변동표가 음수 표기면 부호 반대. 매출채권 표와 기타 금융자산 표가 따로면 두 표의 합에 건다. 기타채권분의 손익 과목이 주석에 없으면 표별로 가르지 않는다 (K 3 · 연결 4건) |
| 충당금 변동표의 「환입 등」 열 | 「등」 이 붙은 감소 열은 제각이 섞인다. 환입과 제각이 나뉘어 있을 때만 대손상각비에 건다 (1건) |
| 충당금 변동표의 제각 = 현금흐름표 주석(비현금거래)의 제각 | (앞 판) |
| 연령분석 · 충당금 설정률표의 총 장부금액 합계 = 구성 표의 매출채권 총액, 손실충당금 합계 = 변동표 기말 | 구간 금액은 충당금이나 BS 에 걸지 않는다. 받을어음을 뺀 기간이 있었다. 개별평가분이 문장에만 있으면 합계가 다르다 (K 2 · 연결 4건) |
| 금융자산과 금융부채의 상계 표: 「재무상태표에 표시되는 순액」 = 채권 · 채무 구성 주석의 그 줄 | 채권은 손실충당금을 뺀 순액과 같았다. 미수금은 단기 + 장기다 (K 1 · 연결 1건) |
| 금융자산의 양도: 양도한 매출채권 = 관련 차입금 = 차입금 내역의 담보부차입금 줄 | 차입금을 음수로 적는 표가 있다. 담보부차입금 줄이 여럿이면 주석이 가리킨 은행 줄만 건다 (K 1 · 연결 1건) |
| BS 매출채권 = 범주 표의 상각후원가 측정분 + FVPL 측정분 | 유동화 대상 채권을 FVPL 로 나눠 적는 회사. 각주에 포함 금액이 문장으로 있다 (K 1 · 연결 1건) |

## 재고자산 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 구성 표의 장부금액 합계 = BS 재고자산 | 평가충당금이 0 이면 취득원가와 금액이 같다. 장부금액 열에 건다 (앞 판) |
| 내역 줄 = BS 재고자산의 하위 과목(완성건물, 미완성공사, 건설용지) | BS 가 빈 칸이고 주석이 0 이면 걸 수 없다 (일반 1건) |
| 성격별 비용의 「재고자산의 변동」 = 재고자산 전기말 - 당기말 | 주석에 그렇게 적혀 있을 때. 부호(기초 - 기말인지)가 주석에 없으면 확신이 낮다고 보고한다. 「제품과 재공품의 변동」 은 제품 + 재공품 장부가액으로 건다. 전기는 전전기말 잔액이 없어 걸 수 없다 (K 2 · 연결 1건) |
| IS 기말재고액 = BS 재고 과목(부호 반대), 당기 기초재고액 = BS 전기 = 전기 기말재고액 | 매출원가를 풀어 적은 IS 나 매출원가 내역 주석일 때. 상품, 제품, 완성건물, 미완성공사 모두 같다. 당기 내역이 전부 0 으로 적힌 보고서는 연결을 그대로 두고 FALSE 로 보고한다 (일반 3건) |

## 투자증권, 종속 · 관계 · 공동기업투자(별도) (일반, K)

연결재무제표의 지분법은 「지분법, 관계 · 공동기업」 절에 있다.

| 연결 | 주의 |
|---|---|
| 내역 표의 장부금액 합계 = BS 과목 | 취득원가 열을 BS 에 걸지 않는다. 합계 줄이 없으면 회사별 합. 한 표에 투자유가증권과 회원권이 함께 있으면 줄 = BS 과목, 합계 = BS 투자자산 (일반 1건) |
| 요약 표(한 줄)의 취득원가 · 순자산가치 · 장부금액 = 회사별 내역 표의 줄 합 | 회사별 표에 합계 줄이 없을 때 (일반 1건) |
| 변동표의 기말 = BS 당기, 당기 기초 = 전기 변동표의 기말 | (앞 판) |
| 변동표의 취득 = CF 취득 | 취득이 전부 현금이라고 읽힐 때만 건다. 각주 · 비현금거래 주석 · 특수관계자 주석에 현물출자, 출자전환, 주식선택권 부여, 대체, 콜옵션이 있으면 그 줄을 넣은 식으로 적고, 한 기간에만 그런 문장이 있으면 그 기간은 걸지 않는다. 금융자산(FVPL, FVOCI)의 취득 · 처분도 같다. 식 없이 걸어 한 기간 이상 안 맞은 보고서가 6건이다 (K 3 · 연결 4건) |
| CF 처분 = 변동표의 처분 장부금액 + 처분이익 - 처분손실 | 손익 내역에 처분손익 줄이 없으면 CF 처분 = 처분 장부금액. 종속과 관계기업을 한 변동표에 적으면 분류가 엇갈릴 수 있다. 변동표에 현금 없는 처분(대체)이 있으면 안 맞는다 (K 4 · 연결 2건) |
| 변동표가 없는 보고서: CF 처분 = 전량 매도한 회사의 전기말 장부금액 + 처분이익 - 처분 관련 미수금 증가 | 각주에 전량 매도가 적혀 있고 비현금거래 주석에 미수금 줄이 있을 때 (1건) |
| 변동표의 손상차손 = 기타비용의 투자주식손상차손 = 누적손상차손의 증감 | 손상 표의 「손상차손 인식후」 = 내역 표의 그 회사 장부금액. 회수가능가액 열은 항이 아니다 (K 3건) |
| 변동표의 대체 = 비현금거래의 대여금 출자전환 | 특수관계자 주석의 출자전환 금액은 환산 전 대여금 총액이라 다를 수 있다 (1건) |
| 특수관계자 자금거래의 현금출자 합 = 변동표의 취득 = CF 투자주식 취득 | 출자 대상이 전부 투자 주석의 회사일 때. 합계 줄이 없으면 칸을 전부 더한다. 기타 특수관계자 묶음은 뺀다. 변동표가 없으면 이 표로만 CF 취득을 걸 수 있다. 한 기간이 안 맞은 보고서가 1건 있었다 (K 3건) |
| 금융자산 변동내역의 평가손익 = OCI 법인세 효과 표의 반영 전 금액 | FVOCI 지분상품 (K 1 · 연결 2건) |
| 매도가능증권: BS 당기 = 전기 + CF 취득 - 평가손, 비현금거래의 평가손익 = SCE 평가손(부호 반대) | 처분이 없을 때 (일반 1건) |
| 피투자기업 요약재무정보: 자본 = 자산 - 부채 | 같은 줄 안의 연결 (앞 판) |

## 금융상품 범주별 분류 (K, 연결)

| 연결 | 주의 |
|---|---|
| 과목별 합계 열 = BS 과목 | 같은 이름이 유동 · 비유동 두 줄이면 `row_nth`. 범주 열 하나를 BS 과목에 걸지 않는다. 금융상품에 들지 않는 금액(선급금, 종업원 관련 채무, 미지급금의 일부)을 뺀 표는 BS 보다 작다. 과목 이름이 같으면 걸고 FALSE 는 회계사 확인으로 보고한다. 묶인 과목의 일부만 담은 줄은 걸지 않는다 (K 1 · 연결 3건) |
| 합계 열이 없는 표: BS 과목 = 그 줄의 범주 칸 전부의 합 | `left` 를 BS 칸에 둔다 (K 1 · 연결 2건) |
| 금융자산 합계 줄의 범주 열 = BS 그 범주 과목의 합, 금융부채 합계 = BS 금융부채 과목의 합 | 상각후원가 열은 대응 과목이 여럿이면 걸지 않는다. BS 가 파생상품을 FVPL 과목에 넣으면 과목 줄 하나를 걸지 말고 합계 줄에 건다 (K 2 · 연결 2건) |
| 범주 열의 과목 칸 = 금융자산 구성 주석의 그 범주 줄 | 리스부채를 차입금 과목에 넣어 표시하는 회사는 차입금 내역의 리스부채 줄, 담보부차입금 줄에 건다 (K 1 · 연결 1건) |
| 리스부채 열 합계 = 리스 주석의 리스부채 합계 | (앞 판) |
| 금융부채(종업원 관련 채무 제외) = 채무 주석의 금융부채 소계 | 어느 과목을 뺐는지 주석에 없으면 회계사 확인으로 보고. 채무 주석에 금융부채분이 따로 없으면 유동성위험 표의 매입채무 + 미지급금 + 미지급비용 + 임대보증금 장부금액에 걸고 확신이 중간이라고 보고한다 (K 1 · 연결 3건) |
| 전기 표에 줄이 없는 과목 | 다른 줄에 합쳐져 있을 수 있다. 채권 주석의 합계가 두 과목의 합인지로 확인한다 (1건) |
| 범주별 순손익의 과목별 합계 = 금융수익 · 금융원가 · 기타손익 · 판관비 명세의 같은 과목 | 범주 열 하나를 걸지 않는다. 비용을 음수로 적은 표면 부호 반대. 손상, 처분손익은 대응 과목이 주석에 없으면 확신이 낮다. 5건이 안 맞은 보고서가 있었다 (K 2건) |
| 범주별 순손익의 외환차이(금융자산 표 + 금융부채 표) = 금융손익과 기타손익의 외환차익 + 외화환산이익 - 외환차손 - 외화환산손실 | 외환 손익이 금융손익 주석과 기타손익 주석에 나뉘어 있으면 넷을 다 더한다. 한 표만 걸면 안 맞는다. 같은 이름 줄이 범주마다 있으면 그 합에 건다(`row_nth`) (K 5 · 연결 6건) |
| 범주별 순손익의 평가손익 = 금융수익의 평가이익 - 금융비용의 평가손실 | 자산 표와 부채 표를 따로 건다. 왼쪽에 한 칸을 두고 나머지를 오른쪽에 부호 반대로 적는다 (K 2 · 연결 2건) |
| 금융원가의 이자비용 = 범주별 이자비용 + 리스부채 이자 | 범주 표에 리스부채 열이 없을 때. 이자비용 내역이 발생원천별이면 줄마다 건다. 걸기 전에 회계정책 주석을 본다. 충당부채의 시간경과 이자가 금융비용에 들어가면 범주별 이자비용과 다르다 (K 3 · 연결 5건) |
| 범주별 이자수익 합 = 금융수익의 이자수익 | 리스채권 이자는 범주 표에 없다. 리스 제공자는 IS 이자수익과 다를 수 있다 (K 2 · 연결 1건) |
| 범주별 배당금수익 = 금융수익(기타수익)의 배당금수익 - 종속 · 관계기업 배당 | 「종속회사 배당금 제외」 각주가 있을 때. 특수관계자 주석의 배당수익을 더해 건다 (K 3 · 연결 1건) |
| 범주별 손익의 대손 = 대손충당금 변동표의 대손상각비 + 환입 - 계약자산(미청구공사)분 | 미청구공사는 금융자산 표에 없다 (K 1 · 연결 1건) |
| FVOCI 열의 평가손익 = OCI 법인세 효과 표의 반영 전 금액 | 세후 금액으로 적는 회사는 기타자본구성요소 변동표의 당기 변동 + 법인세효과에 건다 (K 3건) |
| FVPL 금융자산 손익 내역 합계 = 범주별 순손익의 그 범주 배당금수익 + 평가손익 | (1건) |

## 재무위험관리 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 신용위험 최대노출의 줄 = 채권 주석의 순액(총액 + 대손충당금) = 범주 표의 같은 줄 | 표가 손실충당금을 빼기 전 금액으로 적힌 보고서가 있다. 같은 주석의 설정률표가 장부금액과 기대신용손실을 따로 적으면 총액이다. 근거 문장이 「장부금액」 이면 순액에 걸고 FALSE 로 보고한다 (K 1 · 연결 2건) |
| 신용위험의 현금성자산 = 현금 주석 합계 - 보유현금 | 「현금시재액 제외」 각주가 있을 때. 각주가 없어도 보통예금 줄에 걸어 맞은 보고서가 있다 (연결 1건) |
| 신용위험 최대노출의 계약자산 = BS 계약자산, 금융보증 최대노출금액 = 만기분석의 금융보증계약 합계 | 금융보증을 뺀 줄은 최대노출금액 = 장부금액(가로 구조, `only`) (K 1 · 연결 2건) |
| 지역별 · 유형별 최대노출 합계 = 최대노출 합계 | (앞 판) |
| 유동성위험 만기분석의 장부금액 = BS 또는 채무 주석의 같은 과목, 장부금액 합계 = 범주별 금융부채 합계 | 계약상 현금흐름 열과 구간 칸은 걸지 않는다 (K 1 · 연결 2건) |
| 만기분석의 리스부채 줄: 계약상 현금흐름 합계와 구간 = 리스 주석 만기분석(최소리스료)의 합계와 구간 | 같은 만기분석을 두 번 적은 경우다. 구간 경계가 다르면 더해서 맞춘다(3개월 이내 + 3개월~1년 = 1년 이내). 다른 과목의 구간 칸은 걸지 않는다. 표가 리스부채를 장부금액으로 적었으면 리스부채 합계에 건다. 어느 쪽인지는 표 머리말의 「할인하지 않은」 문장으로 정한다 (K 4 · 연결 2건) |
| 장부금액 열이 없는 만기분석의 과목별 합계 = BS 과목 | 이자를 더했다는 말이 없고 과목이 그 주석을 가리킬 때만. 각주가 기간마다 기준을 달리 적으면 원금 · 장부금액 기준이라고 적힌 기간만 건다. 원금 + 이자, 채권최고액 기준인 기간은 걸지 않는다. 「원금 기준」 은 현재가치할인차금 차감 전일 수 있다 (K 1 · 연결 1 · 앞 판) |

| 이자를 더했다고 적힌 만기분석의 무이자 과목(매입채무, 미지급금, 미지급비용) | 채무 주석에 「무이자조건」 문장이 있거나 BS 과목이 그 주석을 가리키면 합계 = 채무 주석 합계(BS 과목)로 걸고 확신이 낮다고 보고한다. 그런 근거가 없으면 걸지 않는다. 앞 판의 「걸지 않는다」 가 세 보고서에서 지나치게 엄격했다 (K 1 · 연결 1 · 일반 1건) |
| 만기분석의 구간 칸 = 차입금 상환계획의 같은 구간 | 구간이 연도와 하나씩 맞지 않으면 묶어서 건다. 차입금 1년 미만 = 단기차입금 + 유동성장기부채(상환계획의 첫 해), 차입금 합계 = 단기 + 장기차입금 내역 계 (일반 2건) |
| 이자율위험의 변동이자부 자산 · 부채 = 구성 주석의 그 줄 | 어느 차입금이 변동이자인지 주석에 없으면 걸지 않는다. 민감도는 걸 수 없다. 현금성자산은 현금 주석 각주에 변동이자율 조건이라고 적혀 있을 때 요구불예금 줄에 건다 (연결 1건) |
| 자본위험관리의 부채 · 자본 = BS 총계 | 비율은 걸 수 없다 (앞 판) |
| 자본위험관리의 차입금 총계 = BS 단기차입금 + 유동성장기부채 + 사채 + 장기차입금, 차감하는 현금 = BS 현금및현금성자산 + 단기 · 장기금융상품(부호 반대) | 차입금 총계 · 부채총계 · 자본총계 줄은 `no_sums`. 순부채 구조는 「합계 구조」 절 (K 3 · 연결 3건) |
| 외화 자산 · 부채의 원화환산액 | BS 과목에 걸지 않는다. 그 과목의 외화분만이다. 현금 주석에 외화예금 줄이 따로 있으면 예금의 통화별 원화환산액 합을 그 줄에 건다 (K 1건) |
| 환산이익 · 환산손실 합계 = IS 또는 금융손익 내역의 외화환산이익 · 손실 | (앞 판) |

## 유형자산, 무형자산, 투자부동산 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 내역 표의 합계 장부금액 = BS 과목 | (앞 판) |
| 내역 표의 자산별 취득원가 · 누계액 = BS 의 같은 줄 | 누계액 줄이 여럿이면 순서대로(`row_nth`). BS 와 주석의 이름이 다를 수 있다(영업권과 임차권리금, 개발비와 특허권). 자산마다 취득원가 줄과 누계액 줄이 번갈아 있는 변동표는 줄마다 기말 = BS 같은 줄 (일반 1건) |
| BS 가 순액 한 줄이면 BS 과목 = 내역 표의 취득원가 + 누계액 | 무형자산은 직접 차감 표시가 많다 (앞 판) |
| 유형자산과 무형자산이 한 표인 변동표 | 계는 유형자산만이고 무형자산은 계 아래 한 줄일 수 있다. 무형자산 줄 = BS 무형자산과 그 아래 과목 (일반 1건) |
| 변동표의 합계 기말 = BS 당기, 전기 변동표의 합계 기말 = BS 전기 | (앞 판) |
| 변동표의 자산별 기말 = 내역 표의 자산별 장부금액 | (앞 판) |
| 당기 변동표의 기초 = 전기 변동표의 기말 | 자산마다. 천원 표에서 1 다른 경우가 잦다 (앞 판) |
| 변동표의 상각 합계 = IS 감가상각비(무형자산상각비) | 부호 반대. 원가 · 연구개발비에 들어간 상각비가 있으면 그 합. K-IFRS 는 성격별 비용 주석의 감가상각비 합계에 건다. 처분 시점까지의 상각비를 처분 열에 넣은 표는 감가상각비와 처분이 같은 금액만큼 반대로 어긋난다 (일반 1건) |
| CF 감가상각비 = 유형자산 + 사용권자산 + 투자부동산 감가상각비 | 성격별 비용 주석의 각주로 확인. 성격별 비용이 감가상각비와 무형자산상각비를 한 줄로 적으면 무형 상각까지 더한다. 각주에 「전기오류수정손실 포함」 이 있으면 변동표 감가상각비 합계 = CF 감가상각비 + IS 전기오류수정손실 (K 1 · 일반 1건) |
| 유형자산 변동표의 사용권자산 열 = 리스 주석 사용권자산 변동표의 합계 열(줄마다) | 줄 이름이 다르다(취득과 증가, 처분과 감소). 리스 주석의 감소 = 유형자산 변동표 그 열의 대체 + 처분 + 폐기. 사용권자산이 투자부동산에 들어간 보고서는 BS 사용권자산 = 변동표 기말 합계 - 투자부동산 열 (K 2 · 연결 3건) |
| 변동표의 취득 합계 = CF 취득 + 비현금거래 주석의 취득 관련 줄 | 비현금거래 주석이나 각주에 취득과 현금의 차이를 적은 줄(미지급금 변동, 연불구입, 선급금 대체, 정부보조금 수령, 사용권자산 취득)이 있을 때 그 줄을 넣은 식으로 건다. 그런 줄이 없으면 K-IFRS 보고서에서는 걸지 않고 회계사 확인으로 보고한다. 줄 없이 걸어 한 기간 이상 안 맞은 보고서가 7건, 식을 적고도 한 기간이 안 맞은 보고서가 9건, 두 기간 모두 맞은 보고서가 4건이다. 식을 적은 연결의 FALSE 는 그대로 두고 「식의 항이 더 있을 수 있다」 로 보고한다. 비현금거래 주석은 중요한 거래만 적는다 (K 8 · 연결 12건) |
| 비현금거래 주석의 줄이 유형과 무형을 합쳐 적은 보고서: 유형 취득 + 무형 취득 = CF 유형 + 무형자산의 취득 + 미지급된 유 · 무형자산 취득 | 식도 합쳐 적는다. 처분(미수령된 처분)도 같다. 「건설중인자산의 비현금취득」 은 대체 줄에 들어간 경우가 있다 (K 2 · 연결 2건) |
| 정부보조금을 장부금액에서 빼는 회사: 취득 = CF 취득 + 미지급 취득(비현금거래) - CF 정부보조금 수령 | 변동표에 보조금 줄이 없을 때. CF 「취득 미지급금의 지급」 당기 = 전기 비현금거래의 미지급 취득 (K 2 · 연결 2건) |
| 「취득 관련 미지급금의 변동」 줄의 부호 | 부호의 뜻을 적지 않은 보고서가 있다. 증가를 양수로 읽고 `basis` 에 적는다. 네 번 모두 안 맞은 보고서가 있었다 (1건) |
| 취득 식에 CF 영업권의 취득(사업양수 대가)을 넣는 경우 | 무형자산 말고도 다른 자산이 대가에 들어 있어 안 맞는다. 사업결합 주석이 없으면 회계사 확인으로 보고한다 (1건) |
| 변동표의 자산별 취득 = CF 의 자산별 취득 줄 | CF 가 자산별로 적혀 있을 때(일반). 한 표에서 당기 열은 항목이 음수, 전기 열은 양수로 적힌 보고서는 `sign` 을 기간마다 따로 적는다 (일반 1 · 앞 판) |
| CF 처분 = 변동표의 처분 장부금액 + 처분이익 - 처분손실 | 다음이 모두 맞을 때만 건다. 변동표 줄 이름이 「처분」 이다(「처분 등」 「처분 및 폐기」 「처분/폐기」 는 폐기와 손상이 섞인다). 손익 주석에 그 자산의 처분이익 · 처분손실 줄이 있다(줄이 없으면 CF 처분 = 처분 장부금액). CF 처분 줄과 처분손익 줄이 같은 자산 묶음이다(CF 줄이 여럿이면 합으로 적는다). 사용권자산 열과 계약 해지는 뺀다. 비현금거래 주석에 처분 미수금 · 선수금 줄이 있으면 식에 넣는다. CF 에 「처분 미수금의 회수」 줄이 따로 있는 회사, 판매후리스가 있는 기간, 현금 없는 처분(수수료로 쓴 가상자산)이 있는 기간, 해외 자산이 섞인 처분은 걸지 않고 회계사 확인으로 보고한다. 한 기간 이상 안 맞은 보고서가 16건이고 연결재무제표는 13건 가운데 8건이다 (K 7 · 연결 8 · 일반 1건) |
| 투자부동산: CF 처분 = 처분 장부금액 + 처분이익 - 처분손실 - 현물출자로 받은 주식 | 비현금거래 주석의 「투자부동산과 종속기업주식 대체」 줄이 있을 때. 손실 과목 이름이 주석마다 다를 수 있다(투자자산처분손실과 투자부동산처분손실) (K 1 · 연결 2건) |
| 매각예정자산: CF 처분 = 변동표의 처분 + 처분이익 - 처분손실, 변동표의 대체 = 비현금거래의 매각예정자산 분류 | 종속기업의 자산과 부채를 함께 매각예정으로 분류했다는 각주가 있으면 비현금거래의 매각예정부채 분류를 뺀다 (K 1 · 연결 1건) |
| 변동표의 폐기 합계 = 기타비용의 폐기손실 | 부호 반대 (1건) |
| IS 손상차손 = 자산 손상 표의 합계 + 투자주식 손상 표의 회사별 손상차손 | IS 과목이 주석 번호 여럿을 가리킬 때 (1건) |
| 변동표의 대체 = 주석에 적힌 상대 과목 | 건설중인자산의 본계정 대체 + 타계정 대체, 투자부동산 대체는 비현금거래 주석의 줄과 부호 반대. 각주에 다른 과목 대체가 문장으로 있으면 안 맞는다. 중요한 거래만 적는 비현금거래 주석으로 대체 합계의 식을 적으면 안 맞는다(당기 두 건이 안 맞은 보고서) (K 1 · 연결 1건) |
| 투자부동산 변동표의 대체 = 유형자산 변동표의 대체(부호 반대) | 유형자산 대체 합계 = -(투자부동산 대체 + 무형자산 대체), 투자부동산 대체 = 비현금거래의 유형자산 재분류 + 사용권자산 재분류로도 건다. 비현금거래 금액이 취득원가 기준인지 장부금액 기준인지 기간마다 다를 수 있다. 공정가치 모형이면 계정대체에 재평가손익(OCI 법인세 효과 표의 반영 전)이 더해진다 (K 3건) |
| 투자부동산: 성격별 비용 · 수익비용 표의 투자부동산상각비 = 변동표의 감가상각비, 공정가치 표의 장부금액 = 구성 내역의 장부금액 | 부호가 같다 (K 2건) |
| 처분이 없는 과목(투자부동산, 회원권): 상각 · 손상 누계액 당기말 = 전기말 + 당기 상각 · 손상 | 변동표에 처분 줄이 없을 때만 (1건) |
| 개발비 세부내역의 합계 줄 = 무형자산 변동표 개발비 열의 취득원가 · 누계액 · 장부금액 | 줄 이름이 전부 「개발비」 일 수 있다 (K 1 · 연결 1건) |
| 배출권: 무형자산 변동표의 기타 = 배출권 변동표의 정부제출 금액 | 각주에 그렇게 적혀 있을 때 (1건) |
| 가상자산: 인식한 손익 = 무형자산 변동표의 그 자산 손상차손 | 시장가치 · 수량 줄은 항이 아니다 (1건) |
| 정부보조금: 내역 표의 정부보조금 칸 = 정부보조금 주석의 총액 - 기말 상계누계액 | 부호 반대. 자산별 연결과 합계 연결을 함께 건다. 주석의 계정과목 이름이 대체 전 이름으로 남을 수 있다 (연결 1건) |
| 재평가(일반): 재평가 관련 OCI 변동표의 기말 = BS 재평가잉여금, 변동 = SCE 의 OCI 누계액 열, 역사적 원가 표의 장부금액 = BS 토지 | 변동이 0 이어도 건다. 장부금액 - 역사적 원가 = 재평가 OCI 누계액은 법인세 효과를 인식하지 않을 때만 성립한다. 주석에 식이 없어 확신이 낮다 (일반 1건) |
| 공시지가 표의 장부금액 = BS 토지, 투자부동산의 토지 | 표 제목 문장으로 판단 (앞 판) |

## 리스 (K, 연결)

| 연결 | 주의 |
|---|---|
| 사용권자산 합계 = BS 사용권자산 또는 유형자산 내역 표의 사용권자산 장부금액 | (앞 판) |
| 리스부채 유동 · 비유동 = BS 두 과목 | 리스부채 조정표의 기말 줄 이름이 「당기말 리스부채」 면 엔진이 구조를 못 찾는다 (K 1건) |
| 사용권자산 감가상각비 합계 = 유형자산 변동표의 사용권자산 감가상각비 | 부호 반대 (앞 판) |
| 리스 이자비용 = 금융원가 내역의 리스부채 이자 | 「금융원가에 포함」 이라고만 적혀 있으면 걸지 않는다. 범주별 순손익 표가 리스부채 열에 이자비용을 따로 적었으면 그 칸에 건다. 금융비용 내역에 리스 이자 줄이 없으면 이자비용 - 리스 이자 = 상각후원가 금융부채 이자로 건다 (연결 2건) |
| 리스부채 변동표의 지급 = CF 리스부채의 상환 + 이자 | 변동표의 지급에 이자가 들어 있는 표(이자비용을 더하고 지급을 빼는 표). 이자를 영업활동에 적는 회사는 이자만큼 다르다. 차입금이 없다는 문장이 있으면 CF 이자의 지급 = 변동표의 이자. 해지위약금 리스료가 있는 기간은 안 맞는다 (K 3 · 연결 3건) |
| 재무활동 부채 변동표의 리스부채: 기말 = 리스부채 합계, 현금흐름 = CF 리스부채의 상환, 비현금 변동 = 리스부채 변동표의 취득 + 처분 + 기타 | 재무활동 부채 변동표의 현금흐름은 원금만이다. 이자비용과 이자 지급은 상쇄된다 (K 3 · 연결 3건) |
| 재무활동 부채 변동표(리스부채 변동표)의 신규리스 = 비현금거래의 사용권자산 인식 | 주석이 두 금액이 같다고 적었거나 비현금거래 줄 이름이 리스부채의 증가일 때만 건다. 사용권자산 증가에는 선급 리스료, 복구충당부채, 보증금의 현재가치 차이가 들어가 리스부채 신규 금액과 다르다. 건 6건 가운데 5건이 한 기간 이상 안 맞았고 4건은 같은 이유로 걸지 않았다. 기간마다 한쪽은 사용권자산 금액, 한쪽은 리스부채 금액으로 적은 보고서도 있었다 (K 5 · 연결 5건) |
| 비현금거래의 「사용권자산의 인식」 = 사용권자산 변동표의 취득, 재무활동 부채 표의 신규리스 = 리스부채 변동표의 증가 | 사용권자산끼리, 리스부채끼리는 건다. 비현금거래 줄이 「신규 리스계약 및 계약해지」 면 재무활동 부채 조정표의 리스부채 기타비현금거래에 건다. 「사용권자산의 변동」 을 순증감으로 적은 보고서는 기말 - 기초에 건다 (K 2 · 연결 2건) |
| 사용권자산 취득 = CF 사용권자산의 취득 + 선급금 대체 + 리스부채 증가 | 걸지 않는다. 주석에 취득의 구성이 없다. 두 기간 모두 안 맞은 보고서가 있었다 (1건) |
| 최소리스료 합계와 구간 = 유동성위험 표의 리스부채 계약상 현금흐름 합계와 구간 | 「재무위험관리」 절의 리스부채 줄과 같은 연결이다 (K 3 · 연결 2건) |
| 리스해지손익 = 기타손익 내역의 같은 과목, 사용권자산처분이익 = 리스부채 변동내역의 감소(부호 반대) - 사용권자산 처분 장부금액 | (연결 1 · 앞 판) |

| 차입금 내역 표의 합계 = BS 차입금 | 장기차입금 표는 합계 = BS 유동성장기부채 + 장기차입금, 「차감: 유동성」 줄 = BS 유동성장기부채, 맨 아래 줄 = BS 장기차입금. 줄 이름이 「유동성대체」 「차감잔액」 인 표도 같다. BS 에 유동성장기차입금만 있으면 맨 아래 합계(장기 순액 0)는 구조만 건다 (일반 2건) |
| 리스부채를 차입금 과목에 넣는 회사: BS 유동성장기부채 = 유동성장기차입금 계(리스부채 포함) + 유동성사채 | 회계정책 주석에 그렇게 분류한다고 적혀 있을 때 (K 1 · 연결 1건) |
| 주석 표가 「단기차입금(유동성장기부채 포함)」 으로 적힌 회사: BS 단기차입금 = 주석의 단기차입금 계 - 유동성장기부채(차입금 표, 사채 표), BS 장기차입금 = 장기차입금 계 + 사채 합계 | 표기로 확인한다. 주석 표가 유동성장기부채를 어느 쪽에 넣었는지 읽고 식을 적는다 (1건) |
| 사채 내역: 합계 = BS 유동성사채 + 사채, 유동성 줄 = 유동성사채, 비유동 줄 = BS 사채 | 장기차입금 표와 구조가 같다. 유동성 줄이 양수인지 음수인지 표마다 다르다. 기말 사채 = 액면 소계 - 할인발행차금. 외화금액 열은 `only` 로 뺀다 (K 2 · 연결 1 · 일반 1건) |
| 상환계획 합계 = 장기차입금 표의 합계, 1년 이내 = 유동성장기부채 | 표 제목이나 각주가 이자를 더한 금액이라고 적었으면 걸지 않는다. 원금인지 적혀 있지 않은 상환계획을 걸어 두 칸이 안 맞은 보고서가 있었다. 합계 열이 없고 유동성분을 뺀 해부터 적힌 표는 연도 칸의 합 = 장기차입금(유동성 차감 후) (연결 1 · 일반 1건) |
| 재무활동 부채 변동표: 기말 = BS 과목, 당기 기초 = 전기 기말, 현금흐름 = CF 재무활동의 같은 항목 | 리스 · 기타금융부채는 유동 + 비유동. 임대보증금 같은 줄도 건다 (앞 판) |
| 재무활동 부채 변동표의 열이나 CF 줄이 합쳐진 보고서: 단기 + 유동성장기 + 장기차입금(+ 사채)의 현금흐름 = CF 차입금의 증가 + 감소 줄의 합 | CF 가 「유동성장기부채의 상환」 한 줄이면 장기차입금 열과 사채 열을 묶어 건다. 유동성장기부채의 감소도 더한다. 현재가치할인차금 상각이 현금흐름에 섞이면 그만큼 다르다. 「사채 및 장기차입금」 열은 BS 유동성장기부채 + 사채 + 장기차입금 (K 3 · 연결 4건) |
| 재무활동 부채 변동표의 현금흐름 합계 = CF 재무활동 현금흐름 + 배당금의 지급 | 표가 배당을 담지 않을 때. 미지급배당금 줄이 있으면 상환 = CF 배당금 지급, 당기발생 = SCE 배당 (K 1 · 연결 1건) |
| 재무활동 부채 변동표의 유동성 대체 = 비현금거래의 유동성 대체, 「영업활동현금흐름」 열 = CF 운전자본 조정의 같은 과목 | 전기가 안 맞은 보고서가 있었다 (연결 1 · 앞 판) |
| 지급보증 · 담보 · 약정 표의 차입금액 = 차입금 내역 표의 그 차입처 줄 | 열 이름이 「차입금 잔액」 「대출금액」 「실행액」 처럼 그 차입처의 잔액을 뜻하고 차입금 내역에 같은 차입처(은행, 대출 종류) 줄이 있을 때 건다. 열 이름이 「관련채무」 「담보제공차입금액」 처럼 담보나 보증에 관련된 금액만 뜻하면 그 차입처의 차입금 전체가 관련분이라는 문장이 있을 때만 건다. 담보 표에 걸어 은행 셋 가운데 하나가 안 맞은 보고서, 외화 차입금의 환산 금액이 달라 안 맞은 보고서가 있었다. 같은 은행 줄이 여럿이면 주석이 가리킨 줄만 걸고 순서로 대응했으면 보고한다. 대출금액 합계 = 차입금 합계도 건다. 보증금액 · 채권최고액 · 한도 열은 걸지 않는다 (K 1 · 연결 3 · 일반 3건) |
| 담보제공자산의 장부가액 = 변동표의 그 자산 기말 | 줄이 「토지, 건물」 처럼 자산 전체일 때만 건다. 과목의 일부면 걸지 않는다 (일반 1건) |
| 특수관계자 채무의 장기차입금 = 차입금 내역의 주임종장기차입금 줄 | 차입금 내역에 주임종 줄이 따로 있을 때. 확신은 중간이다 (일반 1건) |
| 자본화된 차입원가 주석의 금액 = 금융원가 내역의 차감 줄(부호 반대) | (1건) |

## 퇴직급여, 확정급여부채, 충당부채 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 변동표의 기말 = BS 과목, 당기 기초 = 전기 기말 | 한 표에 당기 · 전기 열이 있으면 `links` 에 같은 표를 양쪽에 적는다 (일반 1 · 앞 판) |
| 순확정급여부채 = 확정급여채무 기말 - 사외적립자산 기말 = BS | 채무와 자산 변동표 각각의 기말에 건다. 순확정급여자산이 있는 회사는 순액 = BS 순확정급여부채 - BS 순확정급여자산. 연결은 종속기업마다 초과적립 여부가 달라 BS 에 자산과 부채가 함께 있다 (K 1 · 연결 2건) |
| 초과적립액이 다른 과목에 든 회사: BS 장기금융상품 = 범주 표의 장기금융상품 + 초과적립액 | 퇴직급여 주석과 금융상품 주석의 각주가 같은 금액을 가리킬 때. BS 순확정급여부채는 0 이다. 기타비유동자산의 일부로 들어간 초과적립액은 걸지 않는다 (K 2 · 연결 1건) |
| 사외적립자산(퇴직연금운용자산) 구성 합계 = 그 변동표의 기말 | (앞 판) |
| 당기근무원가 · 순이자 = 채무 · 자산 변동표의 같은 줄 | 순이자 = 이자원가 - 이자수익 (K 1건) |
| 변동표의 설정(총비용) = IS 퇴직급여 또는 성격별 비용의 퇴직급여 | 확정기여형을 함께 운영하면 걸지 않고 회계사 확인으로 보고. 확정기여 비용이 문장에만 있으면 식을 적을 수 없다. 손익 인식 표의 합계 = 계정과목별 표의 합계, 계정과목별 표의 판관비 = 판관비 명세 퇴직급여는 확정기여형이 있어도 걸린다. 「원가 대체액」 줄이 있으면 소계와 합계 가운데 어느 쪽인지 기간마다 다를 수 있다 (K 3건) |
| CF 주석 조정의 퇴직급여 = 당기근무원가 + 이자비용 + 과거근무원가 - 사외적립자산 이자수익 | 확정기여형을 함께 운영해도 조정 항목의 퇴직급여는 확정급여 비용과 같다. 확정기여 비용은 현금 지출이라 조정에 없다. 성격별 비용의 퇴직급여와는 걸지 않는다. 확정기여 비용이 CF 조정에 든 회사는 안 맞는다 (K 5 · 연결 5건) |
| 변동표의 지급 = CF 퇴직금의 지급, 기여금 = CF 사외적립자산 불입 | 관계사 전출입이 섞이면 안 맞는다. 퇴직금의 지급에 확정기여 납부액이 섞이는 회사가 있다. 두 기간 모두 안 맞은 보고서가 있었다. 주석에 설명이 없으면 확신이 낮다고 보고한다 (K 3건) |
| CF 주석의 사외적립자산 감소(증가) = 자산에서 지급한 급여 - 기여금, CF 순확정급여부채의 증감 = 급여지급액 + 기여금납입액(+ 전출입) | 표의 부호를 줄마다 본다 (K 5 · 연결 2건) |
| 재측정요소(세전) = 사외적립자산 재측정 - 채무 재측정 줄들 = OCI 법인세 효과 표의 반영 전 | 「- 」 로 시작하는 재측정 줄은 글자 그대로 적는다 (K 4 · 연결 2건) |
| 재측정요소(세후) = IS 기타포괄손익의 재측정요소 | 법인세 효과 표의 세후금액에 건다. 세후 표가 없으면 세후 = -(채무 재측정 줄) + 자산 재측정 + 자본에 직접 가감된 이연법인세(이연법인세 변동표의 OCI 반영액)로 적는다 (K 3 · 연결 2건) |
| 일반: 변동표 지급액 = CF 퇴직금의 지급 + CF 퇴직급여 - 변동표 설정액 | 확정기여형을 함께 운영하고 불입액을 지급할 때 비용으로 적는다는 회계정책이 있을 때 (일반 1건) |
| 장기종업원급여부채: 변동표 기말 = BS 과목, CF 주석 조정 줄 = 기말 - 기초 | 자산 · 부채 변동에 지급 줄이 따로 없을 때만. 지급 줄이 따로 있으면 조정 줄은 비용 인식액이다 (K 1 · 연결 1건) |
| 충당부채: 변동표 합계의 유동 · 비유동 = BS 두 과목 | 변동표 아래에 유동 · 비유동 줄이 붙는다. BS 유동 충당부채가 종류 둘의 합(판매보증 + 유동 복구)일 수 있다. 구조는 둘(기말 = 기초 + 변동, 기말 = 유동 + 비유동) (K 2 · 연결 2건) |
| 충당부채: 변동표의 전입 = CF 주석 조정의 충당부채전입액, 사용 = CF 자산부채 변동의 충당부채 | 부호 반대. 「환입 및 사용액」 이 한 열이면 환입액 줄과 바로 걸지 않고 합계 - 환입액 = 자산부채 변동으로 건다. CF 에 전입 · 환입 줄이 따로 있는 충당부채는 운전자본 줄에서 뺀다. 전입액이 원가에 들어가 IS 에 줄이 없어도 CF 가산 항목에 건다. 공사손실충당부채는 전입과 환입이 같은 금액만큼 달랐다(총액과 순액) (K 4 · 연결 2 · 일반 1건) |
| 충당부채: 변동표가 기말 = 기초 + 전입뿐이면 전입 = CF 주석의 비용(설정) + 자산 · 부채 변동의 충당부채 증감 | 전입이 순증일 때. 조정 항목에 전입액이 따로 없으면 CF 주석의 충당부채 증감 = 기말 - 기초. 판관비의 판매보증비에는 걸지 않는다 (K 2건) |
| 하자보수 전입 = 성격별 비용의 하자보수비 | (1건) |
| 복구충당부채 설정 = 유형자산 변동표의 대체 | 주석에 그렇게 적혀 있을 때 (앞 판) |

## 비용의 성격별 분류, 판관비 명세, 기타손익, 금융손익 (일반, K, 연결)

## 법인세, 이연법인세 (일반, K, 연결)

| 연결 | 주의 |

| OCI 의 법인세 효과 = 변동표의 OCI 반영 합계, 세후금액 = IS 기타포괄손익 과목 | 변동표의 OCI 열은 항목별로 건다(퇴직급여, 지분법, FVOCI 평가). 지분상품 처분손익이 「자본에 직접 반영」 표에 따로 있으면 합계끼리는 안 맞는다. IS FVOCI 평가손익 = 평가손익 + 처분손익의 세후 금액. 자기주식처분손익 줄은 OCI 에 넣지 않는다 (K 3 · 연결 2건) |

| 이연법인세 변동표: 상계 후 순액 = BS 이연법인세자산(부채), 항목별 당기 기초 = 전기 기말 | 전기에만 있는 항목은 뺀다. 각주에 기초 조정(세무신고 차이 포함)이 적혀 있으면 항목별 기초 = 전기 기말을 걸지 않고 합계만 건다. 인식한 법인세효과와 BS 의 차이를 말하는 각주가 있으면 BS 에 걸지 않는다 (K 3 · 연결 2건) |

## 자본금, 자본잉여금, 기타자본, 자기주식, 주식선택권, 이익잉여금, 배당 (일반, K, 연결)

| 기타자본 · OCI 누계액 내역: 항목별 당기말 = 전기말 + SCE 의 그 변동 줄(그 과목 열) | 평가손익, 재평가잉여금, 해외사업환산손익, 자기주식처분이익 모두 같다. 연결재무제표는 지배기업 귀속분만이라 IS 금액(비지배지분 포함)에 걸지 않는다. SCE 「비지배지분과의 거래 및 연결범위변동」 줄이 섞이는 항목은 안 맞는다. 자기주식 · 주식선택권 줄은 구성이 없으면 걸지 않는다 (K 3 · 연결 6 · 일반 1건) |
| OCI 누계액 변동(평가액 + 법인세효과) = SCE 총 기타포괄손익의 기타자본항목 열, 평가액 = IS 세전 과목의 합 | 이익잉여금으로 가는 재측정요소는 뺀다. FVOCI 평가손익 당기말 = 전기말 + SCE 평가이익 + 처분으로 인한 대체. FVOCI 장부가액 - 취득원가 = 법인세전 평가손익은 걸지 않는다 (K 1 · 연결 2건) |
| 자기주식 변동내역: 매입 = SCE 자기주식 취득 = CF 자기주식의 취득(부호 반대), 이익소각 = SCE 자기주식소각 = 처분계산서의 자기주식 소각 = 비현금거래의 이익소각, 기말 = 기타자본 구성의 자기주식(부호 반대) | 무상출연과 처분은 처분손익이 섞여 SCE 금액과 다르다. 걸지 않고 보고한다. 이익소각은 이익잉여금과 기타자본 사이의 대체라 SCE 총계가 0 이다. 양도제한조건부 주식 지급, 합병으로 얻은 자기주식이 있으면 CF 와 SCE 가 다르다 (K 4 · 연결 4건) |
| SCE 자기주식의 처분 = CF 자기주식의 처분 + 법인세 주석의 「자본에 직접 가감한 법인세」 | 기타자본 주석에 처분이익을 법인세 차감 뒤로 적는다는 각주가 있을 때 (K 1 · 연결 1건) |
| 자기주식 변동표의 처분 금액 = SCE 주식기준보상거래의 자본조정(부호 반대), 자본잉여금 증가 = SCE 자본잉여금 | (1건) |
| 이익잉여금 구성 합계 = BS 이익잉여금 | 내역의 소계는 바로 위 묶음만 더한다. 법정적립금이 한 줄이면 소계가 임의적립금만의 합일 수 있다 (K 1건) |
| 적립금(이익준비금, 임의적립금) 당기말 = 전기말 + 전기 처분계산서의 적립액 | 전기 처분은 당기 중에 확정된다. 처분계산서가 원 단위, 나머지가 천원 단위일 수 있다 (K 6 · 연결 1건) |
| 처분계산서의 미처분이익잉여금 = BS 미처분이익잉여금 = 이익잉여금 내역의 미처분이익잉여금, 당기순이익 = IS | 부호 확인. BS 에 미처분 줄이 없으면 Ⅰ = BS 이익잉여금 - 이익준비금. 연결재무제표의 미처분이익잉여금 변동은 지배기업 귀속 순이익에 건다 (K 1 · 연결 1 · 일반 1건) |
| 처분계산서의 재측정요소 · 지분상품 처분손익 · 자기주식소각 · 신종자본증권배당 = SCE 이익잉여금 열의 그 줄 또는 IS 기타포괄손익의 그 줄 | 이익잉여금에 직접 반영하는 줄이다 (K 5 · 연결 1건) |
| 처분계산서: 당기의 전기이월 = 전기의 차기이월 | 같은 표의 두 열이라 `links` 에 적는다 (일반 3 · 앞 판) |
| 처분계산서의 전기이월 = SCE 기초 이익잉여금 | 처분이 없고 이익잉여금이 미처분 한 줄뿐일 때. 이익준비금과 배당이 있으면 전기이월 = SCE 기초 이익잉여금 - 이익준비금 + 그 해 현금배당(음수). 전기 열의 전기이월 = SCE 전기초 이익잉여금도 건다 (일반 4건) |
| 처분계산서의 차기이월 = SCE 당기말 이익잉여금 = BS 이익잉여금 | 처분(배당, 적립)이 없고 이익잉여금이 미처분 한 줄뿐일 때만. BS 이익잉여금이 이 주석을 가리키면 이 연결이 없을 때 `unlinked` 에 남는다 (일반 1 · 앞 판) |
| 결손금처리계산서: Ⅰ 미처리결손금 = BS 미처리결손금(결손금), 전기이월미처리결손금 = SCE 기초 이익잉여금(부호 반대) | BS 가 결손금을 양수로 적으면 SCE 이익잉여금 열 = BS 결손금(부호 반대). 처리액이 0 이고 이익잉여금이 미처리결손금 한 줄일 때 (일반 3건) |
| 처분계산서의 배당금 = 배당금 계산 표의 금액 | 기말배당의 배당받을 주식 = 유통주식수 변동표의 기말 = 발행주식수 - 자기주식수. 두 표가 같은 단위로 읽혀야 한다 (K 1 · 연결 2건) |
| SCE 당기 배당 = 전기 처분계산서(배당금 계산 표)의 배당금(부호 반대) = CF 배당금 지급 | 당기 처분 예정 배당은 다음 해에 지급된다. 배당금 계산 표가 없으면 처분계산서 전기 열의 배당금에 건다. 지급내역 표에 합계 줄이 없으면 종류별 줄을 더한다 (K 4 · 일반 1건) |
| CF 배당금 지급 = SCE 배당 + 미지급배당금 증감(채무 주석의 미지급배당금 당기말 - 전기말) | 미지급배당금이 있는 회사. 전기는 전전기말이 없어 걸 수 없다 (연결 2건) |
| 분기(중간)배당을 하는 회사: SCE 당기 배당 = 당기 분기배당 + 전기 기말배당, 처분계산서의 분기배당 = 분기배당 표의 계 합 = SCE 중간배당 = CF | 단수 차이 1 이 잦다. 연결의 총계 열은 비지배지분 배당 때문에 CF 와 다를 수 있다 (K 2 · 연결 1건) |
| 포괄손익계산서 주석(일반): 당기순손익 = IS 당기순이익, OCI 항목 = SCE 의 그 변동 줄 = OCI 누계액 변동내역의 같은 줄 | 당기포괄손익을 IS · CF 의 당기순이익에 걸지 않는다. 「기타포괄손익」 줄은 숫자가 없는 소제목일 수 있다 (일반 3건) |
| OCI 누계액 변동내역(일반): 기말 = BS = SCE 기말, 기초 = SCE 기초, 변동 줄 = SCE 변동 줄 | 당기와 전기가 열로 놓이면 당기 기초 = 전기 기말은 `links` 에 같은 표를 양쪽에 적는다 (일반 1건) |

## 주당이익, 주식수 (일반, K, 연결)

| 연결 | 주의 |
|---|---|
| 산출 표의 당기순이익 = IS 당기순이익, 기본 · 희석주당이익 = IS | 주당이익 = 당기순이익 ÷ 가중평균유통보통주식수는 `calcs` 로 건다. 원 미만을 버린 회사가 있어 허용 폭은 마지막 자리 하나다. 적수 계산(일수 가중)은 걸 수 없다. 연결재무제표는 IS 의 지배기업 소유주지분 귀속 줄에 건다. 우선주가 있으면 당기순이익 = 보통주 해당분 + 우선주 해당분(기본, 희석 각각) (K 2 · 연결 3건) |
| IS 희석주당이익 = 기본주당이익 | 「희석성 잠재적 보통주 없음」 문장이 있을 때. IS 안에서만 걸면 `unlinked` 로 남는다. 주석 칸에도 건다 (연결 2 · 앞 판) |
| 유통주식수 = 주주현황 합계 - 자기주식 | 기초 유통주식수 = 자본금 주석의 발행주식수 - 자기주식 변동표의 기초, 당기 기초 = 전기 기초 + 전기 변동. 기간이 한 줄(연중 전체)뿐이면 가중평균주식수 = 그 줄의 유통주식수. 「변동이 없었으므로」 문장이 있으면 가중평균유통주식수 = 발행주식수 (K 4 · 연결 3 · 일반 3건) |
| 유통주식수 표의 자기주식 취득 · 처분 = 자기주식 수량 변동표의 같은 줄 | 부호 반대. 이익소각이 있으면 발행주식수 당기말 = 전기말 - 소각 주식수이고 자본금은 주식수 × 액면과 다르다. 주식선택권 행사 수량 = 가중평균 산출표의 자기주식처분 수량. 합병 단주가 있으면 표마다 주식수가 다를 수 있다 (K 4 · 연결 2건) |
| 주식수 열과 금액 열이 한 표에 있는 보고서 | 엔진이 표 단위(천원)를 주식수에도 적용해 연결이 안 맞는다. 표 전체가 주식수면 `units` 로 단위를 1 로 고친다. 섞인 표는 `skipped` 에 적고 보고한다 (K 2 · 연결 3건) |

| 합계 열의 감가상각비 · 무형자산상각비 = 상각 내역 주석(성격별 비용, 변동표)의 계 | 각주 「사용권자산 상각비 포함」 이 있으면 사용권자산 감가상각비를 더한다. 투자부동산에 들어간 사용권자산은 두 주석에 모두 나온다 (K 1 · 연결 6건) |
| 「기타는 별도로 표시하지 않았습니다」 가 적힌 부문 표 | 계 = 부문 열의 합 구조를 적지 않는다. `no_sums` (K 1 · 연결 1건) |
| 지역별 정보: 조정후(연결후) 금액 = 지역 열 + 내부거래조정, 외부매출액의 조정후 금액 = IS 매출액 | 연결조정 열은 음수로 적힌다. 부문 표의 연결조정 매출액 = 지역 표의 연결조정. 지역 정보의 국내 · 국외 = 수익 구분 주석의 같은 줄 (연결 5건) |
| 지역별 비유동자산 합계 = BS 비유동자산 | 금융상품과 이연법인세자산을 뺀 금액이면 안 맞는다. 표에 뺀 과목이 적혀 있을 때만 식으로 건다. 구성이 적혀 있지 않은 표를 걸어 두 기간 모두 안 맞은 보고서가 있었다. 「비유동자산의 취득」 은 변동표의 취득과 같지 않을 수 있다(현금 기준으로 모은 보고서) (연결 5건) |
| 단일 부문: 서비스별 · 국가별 · 인식시점별 수익 합계 = IS 매출액(영업수익) | 부문 표가 없다 (연결 3건) |
| 부문 열의 영업수익 = IS 의 사업별 수익 줄 | IS 가 수익을 사업별로 풀어 적었을 때 (K 1 · 연결 1건) |
| 조정내역: 연결실체 영업이익 = IS, 보고부문 총 영업이익 = 부문 표의 영업이익 합계 | 부문 표가 조정 뒤 금액을 적으면 안 맞는다. 고치지 말고 보고한다 (1건) |
| 부문(지역) 열 = 그 부문을 이루는 종속기업 요약재무정보의 합(매출, 순이익, 자산, 부채) | 부문별 회사 구성 표가 있거나 그 지역에 종속기업이 하나뿐일 때만. 「부문간제거」 열이 따로 있어야 한다. 지배기업이 든 부문과 지역은 걸지 않는다. 주석이 매출을 고객 위치로 나눴다고 적었으면 확신이 낮다고 보고한다 (연결 3건) |
| 부문별 영업권 계 = 무형자산 변동표의 영업권 기말 | (1건) |

## 비지배지분, 연결 본표 사이 (연결)

연결재무제표 13건에서 읽었다. 본표의 합계 구조는 「합계 구조」 절에 있다.

| 연결 | 주의 |
|---|---|
| IS 「당기순이익의 귀속」 줄(지배기업 소유주지분, 비지배지분) = SCE 당기순이익 줄의 지배기업 소계 열(이익잉여금 열)과 비지배지분 열 | IS 에 같은 이름의 귀속 줄이 당기순이익 아래와 총포괄이익 아래에 두 번 나온다(`row_nth`). 비지배지분이 0 이어도 건다 (연결 12건) |
| IS 총포괄이익의 귀속 줄 = SCE 총포괄손익 줄의 지배기업 소계 열과 비지배지분 열 | SCE 에 총포괄손익 합계 줄이 없으면 당기순이익 줄 + OCI 줄들의 합으로 적는다. 빈 칸은 항에 넣지 않는다. 전기 줄에 이익잉여금 직접 조정이 섞여 총계가 다른 보고서가 있었다 (연결 10건) |
| SCE 기말 줄의 비지배지분 열 = BS 비지배지분, 지배기업 소계 열 = BS 지배기업 소유주지분 | BS 한 과목이 SCE 두 열(주식발행초과금, 기타)일 수 있다. 주석의 내역으로 열을 나눈다 (연결 9건) |
| SCE 관계기업 OCI 지분(지분법자본변동) 한 줄 = IS 의 재분류되지 않는 줄 + 재분류되는 줄 | IS 에 같은 이름이 두 줄이다(`row_nth`) (연결 3건) |
| 비지배지분 주석의 변동표: 당기 기초 = 전기 기말, 합계 기말 = BS 비지배지분, 당기순손익 배부액 합계 = IS 비지배지분 귀속, 전기 표의 기초 = SCE 전기초 비지배지분 열 | 표가 「비지배지분이 중요한 종속기업」 만 담으면 BS 와 IS 에 걸지 않는다. 종속기업 현황의 지분율로 전부인지 판단한다. 합계 줄이 없으면 회사 줄을 하나씩 더한다. 회사 이름의 각주 표시 때문에 당기 표와 전기 표의 줄 이름이 다르다 (연결 5건) |
| 비지배지분 변동표의 손익 배부가 아닌 변동 열의 합 = SCE 「주주와의 거래」 소계의 비지배지분 열 | 열 이름(사업결합, 지분변동)과 SCE 줄 이름이 기간마다 다르게 대응한다. 줄별로는 이름이 같은 기간만 건다 (1건) |
| CF 배당금의 지급 = SCE 연차배당의 자본 합계 열(비지배지분 배당 포함) | SCE 에 종속기업 배당 줄이 따로 있으면 더한다. 해외 종속기업의 비지배 배당이 있으면 환산 차이로 안 맞을 수 있다. 한 기간이 안 맞은 보고서가 2건이다 (연결 3건) |
| SCE 종속기업 유상증자 · 자기주식처분 총계 = CF 같은 줄, SCE 종속기업의 소유지분변동 총계 = CF 비지배지분과의 거래, 비지배지분에 의한 자본납입 = SCE 그 줄의 비지배지분 열 | 현금 없는 거래가 있는 기간은 안 맞는다. 기타자본 열의 금액 = 기타자본 내역의 연결자본조정 당기말 - 전기말 (연결 3건) |
| 주석(범주별 손익, 법인세 효과, 재측정요소 변동)의 OCI 금액 = IS 과목 | 주석이 지배지분 금액만 적으면 비지배지분 몫만큼 다르다. 기간마다 기준이 다를 수 있다. 차이가 SCE 비지배지분 열과 같은지 보고에 적는다 (1건) |
| 비지배지분으로 분류한 신종자본증권: 발행 연도가 같은 증권의 합계(발행비용 차감 후) = SCE 신종자본증권의 발행 줄의 비지배지분 열 | 배당은 문장 금액이 많다 (1건) |
| 비지배지분 = 종속기업 순자산 × 비지배지분율 | 곱셈이라 적을 수 없다. `skipped` (연결 2건) |

## 지분법, 관계 · 공동기업 (연결)

| 연결 | 주의 |
|---|---|
| 변동표의 기말 합계 = BS 과목 = 내역(현황) 표의 장부금액 합계, 회사별 기말 = 내역 표 장부금액 = 순자산 조정표의 장부금액, 당기 기초 = 전기 기말 | 내역 표에 합계 줄이 없으면 BS 를 왼쪽에 두고 회사별 값을 더한다. 관계기업 내역 계 + 공동기업 내역 계 = BS 인 보고서가 있다. 현황 표의 취득원가는 누적 금액이라 변동표의 취득과 걸지 않는다. 「기타」 줄은 기간마다 구성이 달라 기초 = 전기 기말을 걸지 않는다 (연결 10건) |
| 회사 이름이 표마다 다르게 적힌 보고서 | 각주 표시, 「㈜」 의 위치, 띄어쓰기, 바뀐 회사명이 표마다 다르다. 읽기 자료에서 줄 이름을 글자대로 읽어 스크립트로 짝을 짓는다. 금액은 쓰지 않는다 (연결 5건) |
| 변동표의 지분법손익 합계 = IS 지분법손익 = CF 주석 조정의 지분법손익(부호 반대) | IS 가 이익과 손실을 따로 적으면 합계 = 지분법이익 - 지분법손실, 표가 나뉘어 있으면 표의 부호로 정하고 `basis` 에 적는다. 각주에 「매출로 분류」 라고 적힌 회사 줄은 뺀다. 당기에 지분을 판 회사가 있으면 IS 지분법 줄에 처분손익이 섞인다 (연결 10건) |
| 변동표의 손상차손 합계 = 기타비용의 투자주식손상차손 = CF 조정 | 부호 반대 (연결 4건) |
| 변동표의 지분법자본변동 합계 = SCE 의 지분법 OCI = IS 지분법자본변동 줄들의 합 | 변동표가 세전이면 OCI 법인세 효과 표의 반영 전 금액에 걸고, 세전 금액 + 자본에 직접 반영된 법인세 = SCE 로 적는다. 적용내역 표의 기타변동과는 세전 · 세후가 달라 걸지 않는다 (연결 7건) |
| 변동표의 취득 = CF 관계기업투자주식의 취득 = 특수관계자 자금거래의 출자 | 현물출자, 연결범위 변동, 현금 없는 취득이 있으면 걸지 않는다. 두 보고서에서 한 기간이 안 맞았다. 비현금거래의 「지배력상실로 인한 공동기업투자 취득」 = 공동기업 변동내역의 취득 (연결 8건) |
| 변동표의 처분 = CF 처분 = 특수관계자 자금거래의 회수 | 처분손익 줄이 없을 때만 처분 = CF. 처분손익이 있으면 CF 처분 = 처분(부호 반대) + 처분이익 - 처분손실 - 비현금거래의 미수금 증가. OCI 재분류가 있으면 안 맞는다. 유상감자는 특수관계자 주석의 문장으로 확인한다. 변동표의 「배당」 열에 지분 매각을 적은 보고서는 이름대로 걸고 FALSE 로 보고한다 (연결 5건) |
| 변동표의 배당 = 특수관계자 주석의 배당금수익 = CF 배당금의 수취 | 부호 반대. 회사별로 건다 (연결 5건) |
| 특수관계자 자금거래 ↔ 변동표: 회사마다 취득 · 처분 · 환급 + 배당 = 현금출자 - 배당금 수령 | 변동표에 회사 이름이 따로 적힌 회사만. 37건 가운데 34건이 맞은 보고서가 있다. 제3자 처분과 현금 없는 취득이 있으면 안 맞는다 (연결 5건) |
| 순자산 조정표: 순자산 = 요약재무정보의 자본(자산 - 부채), 장부금액 = 내역 표의 회사별 장부금액, 미반영손실 = 미반영손실누적액 | 순자산 × 지분율은 걸 수 없다. 연결재무제표를 내는 관계기업은 비지배지분 때문에 자본 = 자산 - 부채가 성립하지 않는다. 「지배주주지분만」 각주가 붙은 회사는 `only` 로 빼고 건다. 금융업 관계기업은 순자산이 요약재무정보의 자본과 다를 수 있다. 지분법 적용을 중지한 회사는 0 이다 (연결 9건) |
| 개별적으로 중요하지 않은 기업의 지분해당액(관계 + 공동) = 지분법평가 내역 「기타」 줄의 손익 · 자본변동 | (1건) |
| 요약재무정보의 수령한 배당금 = 변동표의 배당(부호 반대) | (연결 2건) |
| 관계기업에서 금융자산으로 분류 변경: 변동표의 「기타」(대체) = 금융자산 내역의 그 종목 장부금액 = 수준 3 변동표의 대체 | 각주로 확인 (1건) |

## 사업결합과 영업권 (K, 연결)

| 연결 | 주의 |
|---|---|
| 사업결합 표의 영업권 = 영업권 내역 표의 그 현금창출단위 = 무형자산 변동표 영업권 열의 「연결범위의 변동」(사업결합), 취득 유형자산 = 유형자산 변동표의 「연결범위 변동으로 인한 증가」 | 같은 기간에 다른 편입 · 제외가 있으면 변동표와 안 맞는다. 표가 「주요」 사업결합만 담으면 변동표에 걸지 않는다. 환산 환율이 달라 조금 다를 수 있다 (연결 5건) |
| CF 사업결합 순현금유출 = 이전대가 - 취득한 현금 | 사업결합이 한 건이고 표가 전부를 담을 때만. CF 종속기업 취득 현금은 다른 편입이 섞이면 걸지 않는다. 표의 비지배지분과 SCE 「종속기업의 취득」 은 확신이 낮다 (연결 4건) |
| 현금창출단위별 영업권 합계 = 무형자산 변동표(내역)의 영업권 기말 | 취득원가 열과 금액이 같아도 장부금액에 건다. 합계의 기초 · 손상차손 · 매각예정 대체도 영업권 열의 그 줄에 건다 (K 1 · 연결 6건) |
| 단위별 손상검사 표의 손상차손 합 = 변동표의 영업권 손상차손 | 표에 일부 단위만 있으면 걸지 않고 회계사 확인으로 보고한다 (연결 2건) |
| 동일지배 사업결합: 자본잉여금 = SCE 의 그 줄, 인수 계약부채 · 유형자산 = 변동표의 「사업결합」 | 열이 「금액」 하나고 합계라는 말이 없다. 이전대가는 음수, 부채는 양수로 적힌다 (1건) |
| 합병(별도): 이전대가(종속기업투자) = 내역 표의 소멸 회사 전기말 장부금액, 취득 현금 = CF 합병으로 인한 현금의 증가, 투자차액 = SCE 합병, 인수 차입금 = 재무활동 부채 조정표의 합병 열 | 동일지배 합병 (1건) |
| 사업결합 주석이 없는 보고서의 영업권 | 무형자산 내역과 변동표의 영업권 줄끼리만 건다 (연결 2건) |

## 재무제표 사이 (일반, K, 연결)

연결 본표의 귀속 줄은 「비지배지분, 연결 본표 사이」 절에 있다.

| 연결 | 주의 |
|---|---|
| CF 당기순손익 = IS 당기순손익 = SCE 당기순손익 | 손실을 양수로 적은 IS 면 부호 반대. SCE 의 당기순이익은 당기와 전기 두 줄이라 `row_nth` (앞 판) |
| CF 기말의 현금 = BS 현금및현금성자산 | 엔진 규칙이 당기와 전기에 건다. BS 과목 이름이 「현금성자산」 처럼 다르면 규칙이 걸리지 않으므로 `links` 에 적는다 (일반 1건) |
| CF 의 현금 유출입 없는 손익 = IS 의 같은 과목 | 이름이 다를 수 있다(단기매매증권과 단기투자자산). 손익 종류까지 다른 이름(평가이익과 처분이익)은 걸고 확신이 낮다고 보고한다. CF 줄 이름이 서로 바뀐 것으로 보이는 보고서는 이름대로 걸고 FALSE 로 보고한다 (일반 2건) |
| SCE 당기말 · 전기말의 열마다 = BS 자본 과목 | SCE 안의 당기초 = 전기말은 합계 구조로 적는다. BS 가 결손금을 양수로 적으면 부호 반대 (일반 1 · 앞 판) |
| IS 기타포괄손익 과목 = SCE 의 그 변동 줄 | 법인세 효과를 따로 묶어 적은 IS 는 세금 효과가 없는 줄(해외사업환산손익, 관계기업 재측정요소)만 건다. 세전과 세후가 섞인다. 연결의 해외사업환산손익은 SCE 총계에 걸고 OCI 누계액 열(지배기업 귀속분)에는 걸지 않는다 (연결 3건) |
| IS 총포괄손익 = SCE 의 당기순이익 + OCI 줄 총계의 합 | SCE 에 총포괄손익 줄이 없을 때 (연결 2건) |

## 문장 속 금액(「주석N-문장」 표) (일반, K, 연결)

보고서 37건에서 문장 금액 1,400칸을 정한 결과로 모은 것이다. 연결 · 계산 · 조서 대사 · 걸지 않음 가운데 하나로 정한다.

| 문장 금액 | 정한 것 | 주의 |
|---|---|---|
| 「납입자본금은 …」 「자본금 …」 | 재무상태표 자본금 = 문장(항등식). 액면 × 주식수 = 자본금은 `calcs` | 주식수 글(「…주」)은 문장 칸이 생기지 않는다. 계산식에 숫자로 적는다 |
| 「비용으로 인식한(매출원가에 포함된) 재고자산의 원가」 | IS 매출원가(조건부: 매출원가에 재고자산 아닌 원가가 없다) | 제약 · 기술이전 · 임대 수익이 있는 회사는 두 기 모두 달랐다. 성격별 분류의 원재료 사용 + 제품 · 재공품 변동의 합과 같은 회사도 있다(약함) |
| 「재고자산평가손실 · 환입」 | CF 재고자산평가손실, 평가충당금 증감(조건부) | 충당금이 폐기로 줄면 다르다 |
| 「리스의 총 현금유출」 | CF 리스부채 상환 + 리스부채 이자 + 단기 · 소액 · 변동 리스료(조건부, 1116 문단 53(7)) | 전기 금액에서 이자를 빼고 적은 보고서가 둘(작년에서 넘어온 차이) |
| 「확정기여제도 관련 비용」 | 퇴직급여 - 확정급여 비용(조건부) | 차이가 크면 「늘 나는 차이」 로 두지 않는다 |
| 「경상연구개발비」 | 성격별 · 판관비 명세의 경상연구개발비(조건부) | |
| 「총 배당금」 「주당 배당금」 | 자본변동표 배당(항등식), 주당 배당금 × 주식수 = 총 배당금(`calcs`) | 결의와 지급의 기간이 다르면 다음 해 자본변동표 |
| 「유형자산 매각 대금」 「처분 금액」 | CF 처분(조건부) | |
| 「출자 · 취득원가」 「출자원금 회수」 | 투자 변동표의 취득 · 처분, CF 취득 · 처분(조건부) | |
| 「장기저축성보험」 「기타금융상품 … 전액」 | 그 표의 칸(항등식) | |
| 각주의 대체 금액(「건설중인자산 … 대체」) | 변동표의 대체 줄(조건부) | 각주에 없는 대체가 섞이면 다르다 |
| 같은 확약 · 한도를 여러 주석에서 되풀이 | 한 칸만 조서 대사로 두고 나머지는 그 칸과 연결(항등식) | |
| 약정 한도, 담보 설정액, 근저당, 보험 부보금액, 지급보증 금액, 소송가액, 과징금, 공시지가, 정부보조금 미사용잔액 | 조서 대사(은행조회서, 등기부등본, 보험증권, 소송 대장, 공시지가 열람) | 보고서 안에 맞춰 볼 곳이 없다. 같은 성격은 한 줄로 묶는다 |
| 「(전기: …)」 로 적힌 전기 금액 | 그 보고서에 전기 열이 있으면 연결, 없으면 조서 대사(작년 보고서와 대사) | 작년 보고서의 같은 문장과 잇는 수단은 아직 없다 |
| 연혁 설명의 금액(「1999년 유상증자 …」) | 걸지 않음 | |

## 합계 구조 (일반, K, 연결)

표 안의 합계는 `sums` 에 적는다. 엔진이 찾은 구조(읽기 자료의 「엔진 합계」)가 맞으면 적지 않는다. 아래는 엔진이 자주 놓치는 것이다.

### 재무제표 본표

| 구조 | 주의 |
|---|---|
| 유동자산 · 비유동자산 · 유동부채 · 비유동부채 = 다음 중간 합계 앞까지의 과목 | 번호 없는 K-IFRS 본표는 엔진이 못 찾는다. `from` · `to` 로 적는다. 일반기업회계기준은 유동자산 = 당좌자산 + 재고자산 (앞 판) |
| 자산총계 = 유동자산 + 비유동자산, 부채총계 = 유동부채 + 비유동부채, 부채와자본총계 = 부채총계 + 자본총계 | (앞 판) |
| 자본총계 = 자본 과목의 합 | 음수로 적힌 과목은 그대로 더한다. 양수로 적힌 결손금은 뺀다 (앞 판) |
| 연결 BS: 자본총계 = 지배기업 소유주지분 + 비지배지분, 지배기업 소유주지분 = 자본 과목의 합 | 엔진은 앞의 것만 찾는다. 뒤의 것은 `from` · `to` 로 적는다 (연결 8건) |
| 연결 IS: 당기순이익과 총포괄이익은 식이 둘이다(위에서 내려오는 계산식, 지배 + 비지배 귀속) | 귀속 줄은 합계 줄 아래에 있고 같은 이름이 두 번 나와 `nth` 로 적는다. 엔진이 한 식을 이미 찾았으면 다른 식에 `"keep": true` 를 적는다. 엔진이 못 찾았으면 둘 다 적는다 (연결 11건) |
| 연결 SCE 가로: 지배기업 소유주지분 합계 = 자본 과목 열, 자본 총계 = 지배기업 소유주지분 합계 + 비지배지분 | 엔진은 하나만 찾는다. 열 이름 앞에 「지배기업소유주지분」 같은 묶음 이름이 붙는다. 비지배지분 칸이 빈 줄이 있다 (연결 8건) |
| 하위 과목이 하나뿐인 과목(재고자산 = 상품, 자본금 = 보통주자본금, 매출액 = 매출 세목 하나) | 엔진은 항이 하나면 구조를 버린다 (앞 판) |
| 손익계산서: 매출총이익, 영업이익, 법인세비용차감전순이익, 당기순이익, 총포괄이익 | 위에서 아래로 차례로 계산한다. 양수로 적힌 비용은 `sign: -1` (앞 판) |
| 차감 항이 0 이거나 빈 칸인 구조(법인세등 0 의 당기순이익, 매출원가 0 의 매출총이익, 항목이 0 인 CF 유출액 소계) | 엔진이 더하는 것으로 적는다. 뜻이 차감이면 `sign: -1` 로 다시 적는다. 같은 보고서의 전기 표나 같은 표의 다른 차감 줄 방식을 따른다 (일반 4건) |
| 기타포괄손익 = 아래 항목 | 숫자가 없는 소제목 줄은 항에 넣지 않는다 (앞 판) |
| 자본변동표: 기말 줄 = 기초 줄 + 그 기간의 변동 줄, 총계 열 = 자본 과목 열 | 줄이 기간이다. 같은 이름의 변동 줄은 `nth`. 주석 번호 열은 엔진 표에 없으므로 `skip` 에 적지 않는다. 당기초 = 전기말은 항이 하나인 구조로 적는다 (일반 1 · 앞 판) |
| 현금흐름표: 활동별 현금흐름, 유입액 · 유출액 소계, 현금의 증가, 기말의 현금 | 유출액 소계가 음수고 항목이 양수면 `sign: -1`. 유입액과 유출액은 활동마다 따로 확인한다. 투자활동은 항목이 양수, 재무활동은 항목이 음수인 보고서, 당기 열과 전기 열의 부호가 다른 보고서가 있다. 기간별로 구조를 둘 적는다 (일반 2 · 앞 판) |
| 현금흐름표: 영업활동 현금흐름 = 영업에서 창출된 현금 + 이자 · 배당 · 법인세 | 중간 합계가 두 단이면 단마다 구조를 적는다 (앞 판) |
| 현금흐름표의 「수익 등의 차감」 | 소계는 음수, 항목은 양수다. 항목이 하나도 없는 0 소계는 요청 자료에 나오지 않는다 (일반 2 · 앞 판) |
| 세부 열과 소계 열이 따로 있는 현금흐름표 | 활동 소계를 합계 구조로 적을 수 없다. 같은 표 안의 `links` 로 적는다. `"col": "전기"` 는 첫 전기 열이다 (1건) |

### 주석 표

| 구조 | 주의 |
