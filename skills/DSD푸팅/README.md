# DSD푸팅

회사가 준 DART 편집기 파일(dsd)이나 DART 공시 원문(xml)으로 감사인의 푸팅을 합니다. 표 안 합계, 재무제표 ↔ 주석 레퍼, 주당이익 같은 계산, 작년 보고서와의 전기 대사, 정산표(WTB)와의 대사, 오타 · 대표이사 · 본점 주소 · 감사기간 같은 문장 검토가 엑셀 조서와 브라우저 검토 화면(HTML)으로 나옵니다.

- **나누는 일.** 엔진이 금액을 보지 않고 위치 · 이름으로 연결 후보를 내고, 계산과 비교는 엔진과 엑셀 수식이 합니다. Claude 는 주석을 읽어 틀린 후보만 고치고 후보에 없는 연결을 더합니다. 금액이 같은 칸을 찾아 잇지 않습니다.
- **결과.** 엑셀 `DSD푸팅_<파일>.xlsx`(조서 정본: 표지 · 오버뷰 · 볼 것 · 검증 범위 · 문장 검토)와 검토 화면 `DSD보기_<파일>.html`.
- **입력.** dsd 하나. 있으면 작년 보고서(`--prior`), 정산표(`--wtb`, 감사 법인 WTB 양식도 읽음), 이전 판(`--prev`), 기준사실.json(대표이사 · 주소 · 감사기간).

## 쓰는 법(Claude 에게 이렇게 말합니다)

1. **첫 화면(30초 안팎)**: 「<dsd 경로> 빠른 검토해 줘. 정산표는 <경로>, 작년 보고서는 <경로>, 이전 판은 <경로>」. 엔진만 돌린 결과가 브라우저(http://127.0.0.1:8791)에 열립니다. 이 화면의 FALSE 는 AI 판정 전입니다.
2. **AI 판정**: 「AI 판정까지 해 줘」. Claude 가 FALSE 와 할 일만 보고 연결 · 판정을 적은 뒤 다시 검증합니다. 화면의 「다시 검증」 을 누르면 새 결과로 바뀝니다.
3. **조서 정본까지**: 「이 dsd 처음부터 끝까지 푸팅해 줘」. 읽기 자료를 끝까지 읽고 독립 검증까지 합니다.
4. **판만 견주기**: 「<옛 판> 이랑 <새 판> 판 비교 HTML 로 보여 줘」.

## 검토 화면(HTML)

| 화면 | 보는 것 |
|---|---|
| 판 비교 | 이전 판과 나란히 놓고 한 번에 스크롤합니다. 연두 추가 · 분홍 삭제 · 하늘색 변경 · 주황 옮김. 칸에 마우스를 올리면 옛 값 · 새 값 · 차이. 오른쪽 목록을 누르면 그 칸으로 갑니다. 목록 맨 위 「같이 고칠 곳」 은 이전 판에서 같은 숫자였던 곳 가운데 이번에 한 곳만 고친 곳입니다 |
| 숫자 검증 | 칸 색이 결과입니다(초록 맞음 · 빨강 FALSE · 노랑 확인 · 하늘색 조서와 맞출 칸 · 회색 검증 없는 숫자). 칸을 누르면 그 칸의 검증(식 · 두 금액 · 차이 · 판정 · 차이 설명 후보)이 오른쪽에 나옵니다 |
| 문장 검토 | 오타 · 표현 · 사실 불일치 · 공시 누락 표 |

화면에서 바로 고칠 수 있습니다.

- 검증 카드의 「판정이 고치라는 칸 … [수정]」, 숫자 칸을 눌러 나오는 「이 칸 고치기」, 문장 검토 표의 「수정」.
- 누르면 확인 창 뒤에 원본은 그대로 두고 `<이름>_수정판.dsd` 에 써서 다시 검증합니다. 쓴 뒤 다시 읽어, 고친 칸 말고 다른 숫자가 바뀌었으면 쓰지 않습니다.
- 「되돌리기」 는 마지막 수정을 빼고, 「수정판 받기」 로 dsd 를 받습니다. 수정판은 DART 편집기에서 열어 본 뒤에 제출 파일로 씁니다.
- 검증마다 O · X 와 메모를 누르고 「확인 내려받기」 로 받은 파일을 결과 폴더에 두면 엑셀 확인 칸에 들어갑니다.

화면 서버는 이 PC 안(127.0.0.1)에서만 열립니다. HTML 은 바깥 주소를 부르지 않습니다. 고객 dsd 로 만든 화면과 엑셀은 결과 폴더에만 두고 공유 폴더나 저장소에 올리지 않습니다.

## 한계

- 연결의 뜻은 Claude 가 읽어 정하므로 「확인 전」 입니다. 회계사가 엑셀 확인 칸이나 화면의 O · X 로 봅니다.
- 빠른 검토는 FALSE 와 할 일만 읽어서, 엔진 후보에도 할 일에도 없는 계산 · 연결은 빠질 수 있습니다. 조서 정본은 끝까지 읽은 판으로 만듭니다.
- 반기 · 분기 · 사업보고서는 `python scripts/run.py fetch <접수번호 | DART PDF>` 로 OpenDART 에서 원문을 받아 연결과 별도로 나눈 뒤 돌립니다(인증키는 환경변수 `DART_API_KEY`). 원문 xml 이 이미 있으면 `scripts/split_periodic.py` 로 나눕니다.
- 감사 엔진에서 dsd 푸팅에 쓰는 부분만 담았습니다(`scripts/audit`). 감사 폴더 연동은 공개본에 없습니다.
