# DSD푸팅

회사가 준 DART 편집기 파일(dsd)이나 DART 공시 원문(xml) 하나로 감사인의 푸팅을 엑셀 수식으로 만듭니다. 표 안 합계, 재무제표 ↔ 주석 레퍼, 주당이익 같은 계산, 작년 보고서와의 전기 대사, 정산표(WTB)와의 대사, 오타 · 대표이사 · 본점 주소 · 감사기간 같은 문장 검토가 한 파일에 나옵니다.

- **나누는 일.** 엔진이 금액을 보지 않고 위치 · 이름으로 연결 후보를 내고, 판정을 적지 않은 후보는 그대로 연결이 됩니다. Claude 는 주석을 읽어 틀린 후보만 고치고 후보에 없는 연결을 더합니다. 계산과 비교는 엔진과 엑셀 수식이 합니다. 금액이 같은 칸을 찾아 잇지 않습니다.
- **결과.** `DSD푸팅_<파일>.xlsx`. 합계 칸 바로 옆에 TRUE · FALSE, 오버뷰 시트에 합계 · 레퍼 · 전기 · 버전 신호등, 「볼 것」 시트에 FALSE 의 판정과 고칠 칸 후보, 「문장 검토」 시트, 조서 표지(결론 · 작성자 · 검토자)가 있습니다.
- **입력.** dsd 하나. 있으면 작년 보고서(`--prior`), 정산표(`--wtb`, 감사 법인 WTB 양식도 읽음), 기존 판(`--prev`), 기준사실.json(대표이사 · 주소 · 감사기간).

## 시험해 보기

가상 회사 가온정밀(가상)의 dsd 에 오류 11개를 심은 `examples/모의자료/` 가 있습니다. Claude 에게 「DSD푸팅 예시로 돌려 줘」 라고 하거나 SKILL.md 「시험해 보기」 절의 명령을 돌립니다. 엔진만으로 숫자 오류 1(재고자산 주석 자리 바뀜, 엔진 후보를 넣은 뒤) · 오타 3 · 사실 불일치 6 이 나오고, 나머지 셋은 Claude 가 문장을 읽어 찾습니다.

## 한계

- 연결의 뜻은 Claude 가 읽어 정하므로 「확인 전」 입니다. 회계사가 엑셀의 확인 칸(O · X)으로 봅니다.
- 반기 · 분기 · 사업보고서는 `python scripts/run.py fetch <접수번호 | DART PDF>` 로 OpenDART 에서 원문을 받아 연결과 별도로 나눈 뒤 돌립니다(인증키는 환경변수 `DART_API_KEY`). 원문 xml 이 이미 있으면 `scripts/split_periodic.py` 로 나눕니다.
- 감사 엔진에서 dsd 푸팅에 쓰는 부분만 담았습니다(`scripts/audit`). 감사 폴더 연동은 공개본에 없습니다.
