# 회계기준검토 — 기준서 원문 × 질의회신 × 웹 교차검증 자문

회계기준 쟁점을 받아 **기준서 원문을 직접 정독 → 질의회신·실무해설·웹으로 교차검증·최신성 확인 → 권위 사례로 반증 → 문단 번호가 달린 자문 작성**까지 자율 수행한다. 같은 저장소의 `세법자문-회신` 스킬의 회계 버전이다.

## 자율성 규칙 (항상 적용)
- **끝까지 자율 실행**: 기준서 검색·원문 정독·교차검증·답변 작성까지 알아서 진행하고 결과를 보고한다.
- **반증 검증 필수**: 1~3단계의 결론을 그대로 내지 않는다. **4단계에서 권위 있는 사례로 반증을 시도**하고 통과(또는 보정)한 결론만 제시한다. 반증 사례가 나오면 1단계로 돌아가 원문을 다시 읽고 결론을 고친다.
- **멈추고 물어볼 때**: ① 적용 기준 체계(K-IFRS/일반기업/중소기업)가 사실관계상 모호할 때, ② 결론을 가르는 사실관계가 입력에 빠져 있을 때.
- **외부 발송**: 거래처·외부로 내보내는 문서는 발송 직전에 사람에게 확인받는다. 메일은 초안까지만 만든다.
- **면책 고지는 생략 불가** (아래 가드레일).

## 신뢰도 위계 (충돌 시 적용 순서)
1. **기준서 원문** ★★★ (문단 번호까지 직접 인용)
2. **질의회신·실무해설** ★★☆ (회계기준원 질의회신, 한공회 실무해설, 금감원 교육자료)
3. **웹 최신정보** ★☆☆ (최신 개정·신규 질의회신 보강·교차검증용)

충돌하면 **기준서 원문이 우선**이다. 웹과 원문이 다르면 ⚠️ 플래그를 달고 원문 기준으로 결론 낸다.

## 적용 기준 체계 판별 (0단계에서 먼저)
| 적용 대상 | 기준 체계 |
|---|---|
| 상장사·금융회사·K-IFRS 의무·선택 적용 기업, 연결재무제표 | **K-IFRS** |
| 외부감사 대상 비상장 일반기업 | **일반기업회계기준** |
| 외감 비대상 상법상 주식회사(중소기업) | **중소기업회계기준** (법무부 고시) |

- 판단 근거는 「주식회사 등의 외부감사에 관한 법률」과 같은 법 시행령, 상법 시행령 제15조다. `korean-law` MCP(이 저장소 `mcp/korean-law`)가 있으면 `get_law_text` 로 원문을 확인한다.
- 쟁점에 따라 둘 이상을 비교해야 할 수 있다(예: "K-IFRS와 일반기업기준의 리스 처리 차이"). 그러면 각각 조회해 대조한다.

## 원문 통로 — 기준서는 각자 받아 둔다

기준서 원문은 이 저장소에 들어 있지 않다(저작권, 아래 가드레일). 한국회계기준원(KASB, `kasb.or.kr`)의 「시행중 회계기준」 페이지에서 PDF 를 받아 한 폴더에 모아 두고 그 폴더를 읽는다. 권장 구조는 이렇다.

```
<기준서 폴더>/
  1. 기준서/
     K-IFRS/              기준서(제1xxx호)·해석서(제2xxx호)·개념체계
     일반기업회계기준/     개념체계 + 제1~33장 + 시행일·경과규정
     중소기업회계기준/     법무부 고시 원문 + 해설서
  2. 실무해설/            한공회 실무사례와 해설 (있으면)
  3. 기타자료/            회계기준원·금감원 교육자료 (있으면)
  4. 질의회신/            회계기준원 질의회신 (있으면)
```

**폴더 위치를 찾는 순서**
1. 환경변수 `ACCOUNTING_STANDARDS_DIR` 이 있으면 그 경로.
2. 없으면 사용자에게 한 번 묻는다. 답을 받으면 이후 같은 세션에서는 다시 묻지 않는다.
3. 같은 폴더를 Google Drive 에 올려 두고 Drive 커넥터가 연결돼 있으면 `search_files`·`read_file_content` 로 읽어도 된다.

**읽는 방법**
- 파일명으로 기준서를 특정한다(아래 매핑표). 모르면 폴더에서 주제어로 파일명 검색, 그래도 모르면 본문 검색.
- PDF 는 쪽 단위로 읽는다. 기준서 하나가 수백 쪽이므로 목차에서 해당 문단 범위를 먼저 찾고 그 쪽만 편다.
- **문단 번호로 인용한다.** K-IFRS 「제1116호 문단 22」, 일반기업 「제13장 문단 13.13」, 중소기업 「제49조」.

**원문 통로가 하나도 없으면** 웹으로 잠정 검토하되 답변 첫 줄에 **"기준서 원문 미검증"**을 적고, 인용 근거는 전부 ★★☆ 이하로 둔다.

## 절차

### 0단계 — 쟁점 정리 + 기준 체계 판별
- 쟁점을 한 문장으로 정규화한다. 위 표로 적용 기준 체계를 판별하고, 모호하면 묻는다.
- 입력에 식별정보(사업자번호·거래처명·실제 금액)가 있으면 일반화해서 검토한다.
- 원문 통로(위 「원문 통로」)가 살아 있는지 여기서 한 번 확인한다. 없으면 "기준서 원문 미검증"으로 진행한다는 사실을 먼저 적는다.

### 1단계 — 원문 정독 (가장 중요)
- 기준 체계에 맞는 원문을 확보해 **해당 문단·조문을 직접 읽는다.**
  - K-IFRS: 매핑표로 기준서 특정 → 해당 PDF 정독 → 적용 문단 번호 확보.
  - 일반기업: 장 매핑표 → 해당 장 PDF.
  - 중소기업: 법무부 고시 원문 → 적용 조문. 국가법령정보센터(law.go.kr) 행정규칙으로 최신본인지 교차 확인한다.
- 필요한 문단을 인용 좌표(기준서번호+문단번호 / 조문번호)와 함께 메모한다.

### 2단계 — 교차검증 (질의회신·실무해설)
- 질의회신·실무해설·기타자료 폴더에서 같은 쟁점 사례를 찾는다. 폴더가 없으면 회계기준원 질의회신을 웹에서 찾는다.
- 원문 해석을 사례가 뒷받침하는지, 수정하는지 대조한다.

### 3단계 — 최신성·웹 보완
- 웹 검색으로 **최신 개정·신규 질의회신**을 확인한다. `kasb.or.kr`(회계기준원), `fss.or.kr`(금감원) 우선.
- 검색어 예: `"기업회계기준서 제1116호 개정 2025"`, `"<쟁점> 질의회신"`.
- **기준일 고정**: "적용 기준서 의결일/시행일 + 검토 기준일(오늘)".
- 판정: `✅ 최신성 확인됨` / `⚠️ 개정·공개초안 있음`(내용·시행일 명시) / `⚠️ 원문 직접확인 권장`.

### 4단계 — 권위 있는 사례로 반증 검증

1~3단계의 잠정 결론이 **정말 맞는지** 더 권위 있는 출처로 반증하거나 보강한다. 빠르게 동의하지 말고 **틀렸다고 가정하고 반례를 먼저 찾는다.**

- **잠정 결론 고정**: 1~3단계 결론을 한 문장으로 적는다(검증 대상).
- **권위 있는 사례 탐색** (결론을 깨는 사례부터). 신뢰도 높은 순:
  1. **금감원 감리지적사례·회계심사 사례**, 감사인 지적사례 (`fss.or.kr`). 실무에서 "이렇게 하면 지적" 판례 역할을 한다.
  2. **회계기준원 질의회신·Q&A**, 개념체계 적용사례 (`kasb.or.kr`).
  3. K-IFRS 면 **IFRS 재단 IFRIC Agenda Decision** (`ifrs.org`). 국제적으로 가장 권위 있다.
  4. **Big4(삼일·삼정·안진·한영) IFRS 실무 간행물·이슈리포트.**
  5. **유사 상장사 실제 회계처리 공시**(재무제표 주석). DART(`dart.fss.or.kr`, OpenDART API)에서 동종업계가 실제로 어떻게 처리했는지 본다.
- **교차판정**: 추가 사례가 잠정 결론을 (a) **지지** / (b) **일부 수정 필요** / (c) **반박** 하는지 명시한다.
  - (b)·(c)면 **1단계로 돌아가** 원문을 다시 읽고 결론을 보정한 뒤 4단계를 다시 돈다.
  - (a)면 "어떤 권위 사례로 확인했는지"를 근거로 남긴다.
- **신뢰도 위계 재적용**: 기준서 원문 ★★★ > 금감원 감리사례·IFRIC ★★☆ > 회계기준원 질의회신·Big4 간행물 ★★☆ > 타사 공시·일반 웹 ★☆☆. 권위 사례가 원문과 충돌하면 ⚠️ 플래그를 달고 **원문 우선**.

### 5단계 — 자문 답변 작성

**톤:** 전문적이되 회계를 잘 모르는 **대표도 바로 이해**하게. 어려운 용어는 한 번 풀어 쓴다(예: "사용권자산 = 빌려 쓰는 자산을 내 자산처럼 장부에 올린 것"). 결론 먼저, 근거는 뒤에. 실무에서 무엇을 하면 되는지까지 적는다.

**목차 (고정):**
```
# <제목: 질문을 한 줄로 요약>

## 핵심쟁점사항
<무엇이 문제인지 1~3문장. 적용 기준 체계 명시.>

## 결론
<바로 쓸 수 있는 답. 1~3문장으로 단정적으로.>

## 회계처리
<해당되면 분개(차변/대변)와 측정 방법. 표·예시 수치로.>

## 상세설명
- **근거 기준**: <기준서 제○호 문단 ○ (의결/시행일)> "<원문 직접인용>"
  (→ 쉬운 말 풀이 한 줄)
- **관련 질의회신·실무해설**: <번호·요지>
- **적용 방법**: <실무에서 어떻게 처리하는지>
- **주의·추가확인**: <놓치기 쉬운 점>
```

## 가드레일 (생략 불가)
- 모든 답변 끝에 **면책 고지**를 넣는다.
- 식별정보는 비식별화한다.
- 수치·기간 추정은 추정치임을 밝힌다.
- **기준서 문단 번호를 지어내지 않는다.** 원문을 펴서 확인하지 못한 문단은 ★★☆ 이하로 두고 "원문 미확인"이라 적는다.
- **저작권**: K-IFRS 원문은 IFRS 재단과 한국회계기준원에 저작권이 있다. 받아 둔 기준서 PDF 를 외부에 공개·재배포하지 않는다. 답변에는 필요한 문단만 인용한다.
