# 급여대장 및 원천세신고

급여 자료가 든 폴더 하나로 그 달 원천세 신고 파일까지 만듭니다. 급여대장 엑셀이 있으면 그대로 읽고, 인사카드 · 급여계약 · 항목규칙 csv 만 있으면 급여대장부터 계산합니다. 그 달 퇴사자의 퇴직금 · 퇴직소득세 · 중도퇴사 정산과 강사료 같은 기타소득도 같은 신고에 넣습니다.

```
급여대장(또는 csv 셋) + 회사기초정보
  → 원천징수 집계표 · 신고값 → 홈택스 전자신고 파일(YYYYMMDDC103900.01) → 형식검증 22개
```

## Claude 앱에 이렇게 보냅니다

설치는 「hany202507/finance-ai-skills 의 급여대장 및 원천세신고 스킬을 설치해 줘」 라고 보냅니다. 공개 저장소에는 샘플 자료가 없으니 자기 회사 한 달 자료로 시작합니다.

할 일마다 보낼 문장은 아래와 같습니다.

| 할 일 | 보낼 문장 |
|---|---|
| 신고 파일 | 「D:\급여\2026-07 폴더로 7월 원천세 신고 파일 만들어 줘」 |
| Drive 자료 | 「이 Drive 폴더로 7월 원천세 신고 파일 만들어 줘 https://drive.google.com/drive/folders/…」 |
| 퇴사 | 「E002 가 7월 31일 퇴사했어. 월 통상임금은 360만원이야. 퇴직금하고 중도정산 계산해서 7월 신고에 넣어 줘」 |
| 강사료 | 「기타소득 지급 목록으로 강사료 원천징수 계산해 줘」 |
| 근로계약서 | 「이 근로계약서 검토해 줘. 입사일은 8월 1일이야」 |
| 최신화 | 「급여대장 및 원천세신고 근거목록 최신화해 줘」 |

회사기초정보(홈택스 ID · 사업자번호 · 대표자 · 세무대리인 여부 등)가 없으면 빈 틀을 만들고 여덟 가지를 한 번에 묻습니다. 다음 달부터는 그 파일을 그대로 읽습니다.

## 계산하는 것

- **급여대장.** 과세표준을 소득세 · 국민연금 · 건강보험 · 고용보험마다 따로 만듭니다. 국외근로수당처럼 소득세는 비과세인데 건강보험 보수에는 들어가는 항목이 있어서입니다. 상용 · 일용 · 사업소득(3.3%)을 한 표에 담고, 합계와 실지급액은 엑셀 수식입니다.
- **원천징수이행상황신고서.** 소득코드별 인원 · 총지급액 · 소득세, 가감계(A10 · A20 · A30 · A40)와 총합계(A99), 납부세액, 납부 기한(다음 달 10일, 주말이면 다음 영업일)을 계산합니다. 자가운전보조금처럼 지급명세서 제출이 면제되는 비과세는 총지급액에서 뺍니다.
- **퇴사.** 평균임금 기준과 통상임금 기준 퇴직금을 나란히 계산하고 큰 쪽을 씁니다. 퇴직소득세, 1월(그해 입사자는 입사월)부터 퇴사월까지 중도정산, 4대보험 상실 신고 기한도 계산합니다. 퇴직금은 A22 에 적고, 55세 미만은 IRP 이전이라 소득세 0, 55세 이상은 현금 수령으로 퇴직소득세를 뗍니다.
- **기타소득.** 강연료 · 인적용역 · 자문료는 필요경비 60% 를 뺀 금액의 20% 를 원천징수하고 A59 로 적습니다.
- **전자신고 파일.** 국세청 전산매체제출요령(2026-05-16) 규격대로 cp949 고정길이 파일을 만듭니다. 같은 규격으로 생성 코드와 따로 짠 형식검증 22개를 모두 통과해야 파일을 넘깁니다.

## 근거와 최신화

요율 · 간이세액표 · 비과세 한도 · 세율 · 공제 · 기한 · 소득코드 값 59개를 `references/근거목록.json` 에 적었습니다. 값마다 근거 조문 · 별표, TaxDoctor 원천 스냅샷 id(어느 법령 판을 읽었는지), 시행일, 조문 마지막 개정일, 확인 등급이 붙어 있습니다. 시험이 근거목록의 값과 엔진 코드의 값이 같은지 봅니다.

「최신화」 를 부탁하면 Claude 가 근거를 다시 읽습니다. 세법 조문 · 별표 · 비세법 참조 법령 · 시행예정 개정은 TaxDoctor 로, 최저임금법 · 노인장기요양보험법 시행령처럼 TaxDoctor 에 없는 법령은 법제처 korean-law 로 읽습니다. 그다음 법령 판이 바뀌었거나 시행예정 개정이 걸린 값을 보고합니다. **값은 자동으로 바꾸지 않습니다.** 고칠 후보와 근거 원문을 보이고, 확인받은 뒤 엔진 코드와 근거목록을 함께 고치고 시험을 돌립니다. 국민연금 기준소득월액 상한 · 하한 같은 고시와 국세청 규격서는 「사람 확인」 으로 남습니다.

2026-11-02 근거목록 기준으로 사람이 확인할 값이 하나 남아 있습니다. 장기요양보험료의 법령 식은 건강보험료 × (9,448/1,000,000 ÷ 719/10,000) 이고, 비율과 중간 금액의 끝수 처리는 법에 없습니다. 엔진은 이 비율을 0.1314 로 반올림해 씁니다. 10원 미만을 버리므로 대부분 같지만, 계산값이 10원 단위 경계에 걸리면 10원 차이가 날 수 있습니다.

국민연금 근로자 부담률은 2027-01-01 부터 1만분의 500(국민연금법 부칙 제20903호 제4조)으로 계산합니다. 2027-07-01 이후는 기준소득월액 상한 · 하한 고시가 나오기 전이라 멈춥니다.

## 노무 질문

수습 감액이 되는지, 프리랜서가 근로자인지 같은 질문은 같은 저장소의 [법령검토](../법령검토/) 스킬로 답합니다. 이 스킬은 계산만 하고 조문을 해석해 결론을 내지 않습니다.

## 하지 않는 것

- 월 중 입사 · 퇴사의 일할 계산(한 달치로 계산하고 확인사항에 적습니다)
- 퇴직연금(DB · DC) 가입자의 퇴직금, 미사용 연차수당, 국외 근무자의 건강보험료 경감
- 근로자인지 판단
- 부표가 필요한 소득(이자 · 배당 · 법인원천), 연말정산 A04 ~ A06, 수정 · 기한후 신고
- 지방소득세 파일, 홈택스 · 위택스 제출, 4대보험 신고, 명세서 발송

형식검증은 파일 형식만 봅니다. 세액과 소득 구분이 맞는지는 보지 않습니다. 결과는 검토용이고 신고 전 판단은 담당 세무사 · 회계사가 합니다. 공개 저장소에는 실제 회사 자료와 샘플 자료가 없습니다.

## 필요한 것

파이썬 3.10 이상과 `requirements.txt`(openpyxl · python-docx · pytest, 윈도우는 pywin32). 엑셀(윈도우)이나 리브레오피스가 있으면 집계표 수식을 계산해 값까지 저장하고, 없으면 엑셀에서 한 번 열어 저장하라고 알립니다. 전자신고 파일은 둘 다 없어도 만들어집니다.
