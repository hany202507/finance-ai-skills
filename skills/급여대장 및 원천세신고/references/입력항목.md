# 입력항목 — 무엇을 어디서 채우고, 없으면 무엇을 묻나

헤더(레코드 21) 35칸 중 사람이 정해야 하는 것만 추렸다. 나머지는 고정값이거나 신고서에서 계산된다.
출처 표시는 규격서 테이블형식 표1 항목 번호.

## 1. 신고서(집계표 엑셀 또는 신고값 JSON)에서 오는 것 — 묻지 않는다

| 칸 | 출처 | 어디서 |
|---|---|---|
| 사업자등록번호 → 납세자ID | #3 | 신고서 시트 J5 |
| 상호 → 법인명 | #17 | 신고서 시트 B5 |
| 대표자 → 성명 | #21 | 신고서 시트 F5 |
| 귀속·지급·제출연월 | #8~10 | 신고서 시트 F4·J4·F6 |
| 작성일자 | #33 | 신고서 시트 J6 |
| 매월/반기 → 원천신고구분 | #22 | 신고서 시트 B4 |
| 전월미환급세액·기환급신청세액·일반환급·신탁·금융·합병·환급신청액 | 표2 | 신고서 시트 46행 |
| 연말정산여부 | #23 | 명세에 A04·A05·A06·A26·A46 있으면 Y (자동) |
| 신고서부표여부 | #28 | 명세에 A50·A60·A70·A80·A69 있으면 Y (자동 · 이 경우 부표 레코드 24가 따로 필요해 멈춘다) |
| 민원종류코드 | #12 | 수정신고면 FF101, 아니면 FF001 (자동) |

이 중 하나라도 비어 있으면 생성기가 "빠진 것"으로 멈춘다. 그때는 신고서를 고치게 하지, 값을 지어 넣지 않는다.

## 2. 회사기초정보 엑셀(회사기초정보_<사업자번호>.xlsx, 또는 설정_<사업자번호>.json)에서 오는 것 — 없으면 한 번에 묻는다

물을 때는 세무 실무자가 바로 답할 수 있는 말로 묻는다. "표1 #11" 같은 규격 번호는 답에 도움이 안 되므로 질문에 넣지 않는다.

| 순서 | 무엇 | 필수 | 어떻게 묻나 | 왜 필요한가 |
|---|---|---|---|---|
| 1 | 홈택스 사용자ID | 필수 | "홈택스에 로그인하는 ID가 무엇입니까? 세무대리인이 대신 올리면 대리인 ID입니다" | #11 Not Null. 틀리면 접수 자체가 안 된다 |
| 2 | 신고 종류 | 필수 | 정기 / 수정 / 기한후 셋 중 하나. 기본은 정기 | #6. 파일명 끝 두 자리·민원종류코드·환급신청 가능 여부가 이것으로 갈린다 |
| 3 | 세무대리인 신고 여부 | 필수(Y/N) | "세무대리인 명의로 신고합니까?" Y면 사업자번호·성명·관리번호·전화번호 넷을 이어서 묻는다 | #13~16 |
| 4 | 사업장 소재지 | 선택 | "사업장 주소를 적을까요? (비워도 접수됩니다)" | #18. 영문·한자는 소리나는 대로 한글로 |
| 5 | 사업장 전화번호 · 전자메일 | 선택 | 한 번에 | #19·20 |
| 6 | 세무프로그램코드 | 필수 | "세무프로그램 업체코드가 있습니까? 없으면 9000(규격서 문구) 또는 9999 중 고르십시오" | #34. 규격서 34번은 9000 이다. 9999 도 형식검증은 통과한다 |
| 7 | 일괄납부 · 사업자단위과세 · 소득처분 | 필수(Y/N) | 셋을 한 질문에. 기본 전부 N. "본점일괄납부 승인, 사업자단위과세, 이번 달 소득처분(인정상여) 신고 중 해당하는 것이 있습니까?" | #24·26·27 |
| 8 | 환급계좌 | 조건부 | 환급신청액 > 0 이고 정기신고일 때만. 은행과 계좌번호를 같이 | #31·32. 둘 중 하나만 있으면 오류 |

답을 받으면 회사기초정보 엑셀의 값 칸에 적는다. 다음 달에는 "지난달과 같습니까?" 한 번만 묻는다.

## 3. 사람이 확인해야 하는 것 (묻지는 않지만 결과에 적는다)

- 사용자ID 가 모의 데이터나 예시값이면 실제 로그인 ID로 바꿔야 접수된다.
- A22 퇴직소득이 있으면 55세 미만 퇴직자는 IRP 이전 대상(A22 · 세액 0, 소득세법 §146②)일 수 있다. 신고서 확인사항에 있는지 본다. A21 란은 연금계좌취급자가 적는다.
- 수정·기한후 신고면 환급신청 Y 불가, 환급신청액은 0으로 나간다(표2 #13).
- 반기납부 사업자는 귀속=반기 시작월, 지급=반기 종료월, 제출=다음 달이다(규격서 제출·징수·귀속연월 작성법 1.(2)).
