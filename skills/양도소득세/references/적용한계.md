# 적용 한계 (계획 1)

계산하지 않고 다루지않음이나 확인사항으로 돌려보내는 것.

이 스킬은 단계별 계획으로 범위를 넓힙니다. 지금은 계획 1 이고, 표의 「계획」 열은 그 항목을 다룰 계획 번호입니다.

| 계획 | 내용 |
|---|---|
| 1 | 지금 범위. 2025-01-01 이후 매매와 경매(매각대금 완납일이 양도일)로 양도한 주택·토지·건물의 판정, 계산, 검산, 질문지, 로컬 MCP. 수용도 계산하지만 조세특례제한법 감면은 계산하지 않는다 |
| 2 | 신고서식 PDF, 고객이 직접 채우는 HTML 질문지, 신축 후 5년 안 양도 가산세 |
| 3 | 전자신고 파일 |
| 4 | 기준정보 매일 갱신과 운영자 확인 |
| 5 | 상속·증여·입주권·분양권·겸용주택·비사업용 토지·특례 주택·양도차손 통산 등 범위 확대 |

다루지않음이나 질문 결과의 「계획」 값도 같은 번호입니다. 「없음」은 계획이 없다는 뜻입니다.

| 항목 | 처리 | 계획 |
|---|---|---|
| 2024-12-31 이전 양도 | 다루지않음 | 없음 |
| 상속·증여·부담부증여·조합원으로 취득한 자산, 이월과세 | 다루지않음 | 5 |
| 교환으로 양도(받은 자산의 시가가 양도가액이라 계산하지 않는다) | 다루지않음 | 5 |
| 부담부증여로 양도 | 다루지않음 | 5 |
| 양도 원인이 기타(다른 원인에 맞지 않는 경우) | 다루지않음 | 5 |
| 겸용주택, 조합원입주권, 분양권 | 다루지않음 | 5 |
| 세대에 입주권·분양권, 상속·임대·혼인·동거봉양·농어촌 주택 특례 | 다루지않음 | 5 |
| 비사업용 토지 판정이 필요한 토지 | 다루지않음 | 5 |
| 1985-01-01 전 취득(의제취득일) | 다루지않음 | 5 |
| 양도차손 통산 | 다루지않음 | 5 |
| 과세연도가 다른 양도를 한 번에 | 다루지않음. 과세연도마다 따로 계산한다 | 없음 |
| 계약서 금액과 실제 거래가액이 다른 경우(다운·업계약) | 다루지않음 | 없음 |
| 한시배제 나목·다목 | 확인사항 | 5 |
| 등록임대주택 중과배제 | 확인사항(아파트 장기임대 2027-12-31 양도기한) | 5 |
| 같은 해 다른 양도를 사실관계에 넣지 않은 경우 | 확인사항(기본공제와 합산 비교가 달라질 수 있다) | 5 |
| 조세특례제한법 감면, 감면 종합한도, 농어촌특별세 | 계산하지 않음 | 5 |
| 신축·증축 후 5년 안 양도의 환산·감정 가산세(소득세법 제114조의2) | 확인사항(가산세는 계산하지 않음) | 2 |
| 지구 단위 지정 | 질문(A02) | 없음 |
| 신고서식 PDF, 고객 HTML 질문지 | 하지 않음 | 2 |
| 전자신고 파일 | 하지 않음 | 3 |
| 매일 기준정보 갱신 | 하지 않음(초판 수동) | 4 |
| 주식·국외자산·파생상품, 비거주자 | 다루지않음 | 없음 |

양도 원인은 질문 P03 이 받습니다. 매매, 경매, 수용을 계산합니다. 경매의 양도일은 매수인이 매각대금을 다 낸 날이라 사실관계의 `양도.대금완납일` (없으면 `양도.잔금일`)을 씁니다. 교환, 부담부증여, 기타는 다루지않음으로 돌려보내고 계산하지 않습니다.

같은 세율 자산의 합산(소득세법 제104조⑤2호)과 합산 비교(같은 조 1호)는 계산합니다. 같은 해 양도를 모두 사실관계의 자산으로 넣으면 기본공제 배분과 합산이 함께 반영됩니다.

기준정보 확인일은 초판 뒤 계획 4 가 생기기 전까지 `fetch_articles.py` 를 돌린 날입니다. 7일이 지나면 모든 결과에 기준정보를 갱신하라는 경고가 붙으므로 운영자가 주 1회 기준정보를 다시 받아야 합니다(`references/기준정보_초판절차.md`).
