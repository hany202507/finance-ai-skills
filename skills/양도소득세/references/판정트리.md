# 판정 규칙

보유기간은 취득일 다음 날부터 양도일까지 채운 햇수로 셉니다(소득세법 제95조④, 민법 초일 불산입).

판정은 `yangdo/judge.py` 가 자산마다 정합니다. 사실관계와 `rules/` 의 규칙세트만 보고, 외부를 조회하지 않습니다. 판정에 필요한 사실이 없으면 계산하지 않고 질문을 돌려주고, 이 스킬이 다루지 않는 경우는 다루지않음을 돌려줍니다(목록은 `references/적용한계.md`). 사실관계의 자료형은 판정 전에 문항 정의의 `답형식` 대로 검사하고, 형식이 틀린 값은 판정에 쓰지 않고 그 문항을 다시 묻습니다. 아래 근거 키는 `yangdo/keys.py` 의 규칙 키이고, 값과 조문은 `rules/ruleset.json` 에서 읽습니다.

취득일과 양도일은 계약일, 잔금일, 등기접수일, 사용승인일 같은 원자료 날짜로 엔진이 정합니다(소득세법 제98조, 시행령 제162조①, 근거 키 `판정.취득양도시기`). 사용자에게는 묻지 않습니다. 날짜는 `YYYY-MM-DD` 글자만 받습니다. 경매로 양도하거나 취득한 건은 매수인이 매각대금을 다 낸 날(`대금완납일`, 없으면 잔금일)을 대금 청산일로 봅니다(민사집행법 제135조).

「모름」으로 답한 문항(사실관계 `모름` 목록)은 조건을 못 갖춘 것으로 봅니다. 공고일 이전 계약, 정비구역, 연장 사유, 보유거주예외가 여기에 해당합니다.

표에 못 적은 판정 세부입니다.

- **일시적 2주택의 1년 간격.** 종전 주택 양도가 시행령 제154조①의 예외(공공임대 5년 거주, 수용, 부득이한 사유 1년 거주)에 해당하면 「종전 주택 취득 1년 뒤 신규 취득」 요건을 적용하지 않습니다(시행령 제155조① 후단). 확인사항으로 증빙을 확인하라고 남깁니다. 공공기관 이전 종사자(`세대.기관이전종사자`)는 5년 처분기한과 함께 이 1년 간격 요건도 적용하지 않고, 확인사항에 이전 지역 요건을 확인하라고 남깁니다.
- **2년 기한의 공고일 예외.** 신규 주택 취득이나 계약·계약금 지급이 조정대상지역 공고일 이전이면 2년 기한을 적용하지 않습니다(시행령 제155조①1호 괄호).
- **한시배제 가목.** 보유 2년 이상 주택을 규칙세트의 기한(`중과.한시배제.가목.양도기한`)까지 양도하면 중과하지 않습니다. 양도일이 2025-02-27 이전이면 기한은 2025-05-09 이고, 2025-02-28 시행 개정으로 2026-05-09 까지 연장됐습니다. 나목(토지거래허가 대상 주택)과 다목(기한 전 양도 매매계약)은 판정하지 않고 확인사항으로 남깁니다.
- **지역 판정.** 조정대상지역 여부는 입력받지 않고 고시 이력을 효력발생일 순서로 다시 적용해 기준일마다 정합니다. 지구 단위로 지정된 적이 있는 주소는 문항 A02 로 묻습니다. 구나 읍면동이 더 필요하거나 이름이 고시와 맞지 않는 주소는 문항 A01 로, 취득 당시 주소가 달랐는지는 문항 A03 으로 묻습니다.
- **거주기간 구간.** 구간을 보유기간으로 자른 뒤 겹치거나 맞닿은 구간을 하나로 합쳐, 같은 날을 두 번 세지 않습니다. 합친 구간이 하나면 날짜로 채운 햇수를 쓰고, 여럿이면 일수 합을 365 로 나눈 햇수를 씁니다. 여럿일 때는 거주 2년 같은 요건 햇수의 경계에 걸릴 수 있어 확인사항을 남깁니다.
- **해외 출국 예외.** 해외이주(시행령 제154조①2호 나목)와 해외취학근무(다목)는 출국일 현재 그 집을 보유해야 합니다. 또 출국일부터 2년 안(2년째 되는 날 포함)에 양도해야 보유·거주 요건을 채운 것으로 봅니다. 출국일은 문항 H11(`보유거주예외일자`)로 받고, 엔진은 해외이주·해외취학근무일 때만 읽습니다. 값이 없으면 H11 을 묻고, 모른다고 답하면 예외를 적용하지 않고 확인사항을 남깁니다. 적용했더라도 출국일 현재 세대의 주택이 그 한 채뿐이었는지는 주택 목록으로 알 수 없어 확인사항으로 남깁니다. 수용, 공공임대 5년, 부득이한 사유 1년은 출국일 없이 입력한 사유대로 적용합니다.
- **중과의 일반주택 10호.** 엔진은 판 집의 중과배제 사유(X04)만 묻고 다른 주택의 사유는 묻지 않습니다. 다른 주택이 모두 중과배제 주택이라 판 집만 일반주택으로 남으면 10호(시행령 제167조의10①10호, 제167조의3①10호)로 중과가 빠질 수 있습니다. 그래서 중과로 계산할 때마다 이 확인사항을 붙입니다.

## 판정 뒤 계산

계산은 `yangdo/calc.py` 가 판정 결과를 받아 합니다. 원 미만은 단계마다 버립니다. 세율, 공제율, 기준금액은 규칙세트에서 읽습니다. 코드에 남은 고정값은 `references/규칙세트_스키마.md` 에 있습니다.

| 순서 | 계산 | 근거 키 |
|---|---|---|
| 1 | 양도가액은 전체 양도가액에 지분을 곱합니다. 취득가액은 실지거래가액(계약서, 기타자료)을 쓰고, 모르면 매매사례가액, 감정가액 평균, 환산취득가액 순서로 추계합니다 | 판정.추계순서, 판정.환산 |
| 2 | 추계하면 필요경비는 개산공제(취득 당시 기준시가에 율을 곱한 값)입니다. 환산이고 환산취득가액과 개산공제의 합이 자본적지출과 양도비의 합보다 작으면, 그 지출을 필요경비로 하고 취득가액은 0 으로 합니다(소득세법 제97조②2호 단서) | 개산공제율, 개산공제율.미등기, 판정.개산공제비교 |
| 3 | 필요경비 중 취득세는 금액을 그대로 넣습니다. 취득부대, 자본적지출, 기타, 양도비는 항목마다 증빙종류가 세금계산서·계산서·카드영수증·현금영수증·계좌이체인 것만 넣고, 자본적지출 중 일반 수선은 뺍니다. 뺀 항목은 검토 문서에 사유와 함께 나옵니다 | 판정.필요경비증빙 |
| 4 | 고가주택이면 과세양도차익은 양도차익에 (전체 양도가액 - 12억원) / 전체 양도가액을 곱한 값입니다 | 고가주택기준, 판정.고가안분 |
| 5 | 장기보유특별공제는 과세양도차익에 공제율(표1 또는 표2)을 곱합니다 | 장특공.표1, 장특공.표2.보유, 장특공.표2.거주 |
| 6 | 기본공제는 연 한도 안에서 양도일이 이른 자산부터(같은 날이면 id 순) 양도소득금액만큼 나눠 씁니다. 미등기와 전액비과세 자산은 받지 못합니다 | 기본공제 |
| 7 | 세율은 미등기면 단일세율, 단기면 단일세율과 누진세율 중 큰 쪽, 중과면 누진세율에 가산세율을 더한 값입니다 | 기본세율, 단기.*, 미등기, 중과.* |
| 8 | 지방소득세는 지방세법의 개인지방소득세 표준세율로 따로 계산합니다 | 지방.* |

### 합산

같은 해 둘 이상의 자산에 세액이 나오면 산출세액은 다음 두 금액 중 큰 값입니다(소득세법 제104조⑤).

| 금액 | 계산 | 결과 필드 |
|---|---|---|
| 같은 세율 자산 합산 세액(2호) | 같은 세율이 적용되는 자산의 과세표준을 합쳐 그 세율로 계산한 세액의 합 | `호별합산세액` |
| 합산 비교 세액(1호) | 모든 과세표준을 합쳐 기본세율로 계산한 세액 | `합산비교세액` |

기본세율을 쓰는 자산은 종류와 상관없이 한 묶음입니다. 중과2, 중과3, 미등기, 단기는 같은 세율끼리만 묶고, 전액비과세 자산은 묶음에 들어가지 않습니다. 묶음 키는 `calc.merge_key` 가 정하고 자산 `계산` 의 `합산묶음` 에 나옵니다.

묶음 세액은 구성원 가운데 양도일이 가장 이른 자산(같은 날이면 id 가 앞선 자산)의 양도일 기준 세율로 한 번에 구합니다. 그래서 입력 순서는 결과에 영향을 주지 않습니다. 구성원의 양도일 세율이 서로 다르면 묶음 세액을 정하지 않고 다루지않음(계획 5)으로 돌려보냅니다. 현재 규칙세트에서는 이 경우가 생기지 않습니다.

`산출세액` 은 `max(호별합산세액, 합산비교세액)` 이고 지방소득세도 같은 방식입니다. 합산 비교는 과세 자산이 둘 이상일 때만 하므로 자산이 하나면 `합산비교세액` 은 0 입니다. `자산별세액` 은 자산마다 따로 계산한 참고값이고 산출세액을 정하는 데 쓰지 않습니다. 검토 문서의 합계 표에 자산별 산출세액 합, 두 세액, 산출세액이 모두 나옵니다.

같은 해 다른 양도는 사실관계에 자산으로 넣어야 합산과 기본공제에 반영됩니다. 넣지 않고 `연간.다른양도` 를 true 로 답하면 계산에는 들어가지 않고, 기본공제와 합산 비교를 다시 확인하라는 확인사항이 붙습니다.

## 검산

판정을 거치지 않고 조문 식으로 직접 계산해 엔진 값과 대조합니다. 하나라도 어긋나면 종료코드 1 입니다.

| 번호 | 검사 |
|---|---|
| V1 | 전액비과세 자산의 양도가액이 기준 이하이고 세액이 0 인지 |
| V2 | 장기보유특별공제율이 소득세법 제95조② 표1·표2 를 식으로 직접 구한 값과 같은지 |
| V3 | 중과·미등기 자산에 장기보유특별공제가 없는지 |
| V4 | 과세표준이 양도소득금액에서 기본공제를 뺀 값인지, 기본공제 합이 연 한도 이하인지 |
| V5 | 과세표준을 100만원 늘렸을 때 세액 증가분이 한계세율로 계산한 값과 같은지 |
| V6 | 지방소득세에 10을 곱한 값과 산출세액의 차이가 10원 이하인지 |
| V7 | 과세양도차익이 양도차익(음수면 0) 이하이고 산출세액이 0 이상인지 |
| V8 | 보유년이 날짜로 다시 센 값과 같은지 |
| V9 | 고가주택 과세양도차익이 안분 식을 직접 계산한 값과 같은지 |
| V10 | 산출세액이 `max(호별합산세액, 합산비교세액)` 과 같은지(지방소득세도), 자산별 합과 과세표준 합이 자산 행의 합과 같은지 |
| 워크북 | 계산근거 엑셀의 수식을 다시 계산한 값이 엔진 값과 같은지 |

엔진과 워크북이 맞는다는 사실은 판정이 맞다는 증거가 아닙니다. 둘이 같은 판정을 쓰기 때문입니다. 판정은 확인사항과 근거 조문으로 사람이 확인합니다.
