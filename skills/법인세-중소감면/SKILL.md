# 법인세-중소감면

계산은 엔진과 엑셀 수식이 한다. AI 가 하는 일은 받은 자료를 입력 양식으로 옮기는 것과, 엔진이 낸 확인 줄을 회계사에게 전하는 것이다. 감면율 · 금액을 손으로 만들지 않는다. 감면 업종인지와 별표 3 업종 번호(한국표준산업분류)는 회계사가 고르고, 엔진은 입력한 대로 판정한다. 결과는 검토용이고 신고 전 최종 판단은 세무 전문가가 한다.

- 기준과 조문: `scripts/ctax/smereduce/rules.yaml`(항목마다 근거 조문 · 판 · 등급, 실행은 같은 내용의 `rules.json` 을 읽는다)
- 입력 항목 전체(형식 · 비었을 때 · 받는 곳 · 설명): [references/입력정의.md](references/입력정의.md). 입력 양식의 「정의」 시트와 같은 내용이다
- 사람이 읽는 사용법: [README.md](README.md)

## 돌리는 법

이 스킬 폴더의 `scripts/` 에서 `PYTHONUTF8=1 python -m ctax smereduce "<회사>/<연도> 법인세" [옵션]` 을 돌린다. 신고 건 폴더는 아무 곳이나 되고 이름만 `<회사>/<연도> 법인세` 꼴로 한다. 사용자는 파이썬을 치지 않고 파일을 주고 말로 시킨다.

| 사용자 | Claude |
|---|---|
| 「샘플로 중소감면 돌려 줘」 | 작업 폴더에 `샘플기계/2025 법인세` 를 잡고 `--sample` 로 입력을 만든 뒤 옵션 없이 한 번 더 돌린다. 기대값은 감면세액(112) 34,185,365원, 소기업 · 수도권 외 · 감면율 30%, 감면한도 92,500,000원 |
| 입력 엑셀(`중소감면_입력.xlsx` 꼴)을 붙이고 「계산해 줘」 | `<회사>/<연도> 법인세` 를 잡고 `--input "<붙인 파일>"` 로 돌린다 |
| 세무조정계산서 · 사업자등록증 · 손익계산서만 붙임 | `--template` 으로 빈 양식을 만들고 아래 「순서」 2번대로 옮긴 뒤 돌린다 |
| 「빈 양식 줘」 | `--template` 으로 만든 `중소감면_입력.xlsx` 를 파일로 준다. 채운 예시는 `--sample` 이 만든다 |

| 옵션 | 하는 일 |
|---|---|
| `--template` | 빈 입력 양식을 `00 받은자료/중소기업감면/중소감면_입력.xlsx` 로 만들고 끝낸다(이미 있으면 그대로 둔다) |
| `--sample` | 합성 회사(샘플기계) 입력을 같은 곳에 만들고 끝낸다 |
| `--input <파일>` | 위 위치 대신 그 파일을 입력으로 읽는다 |
| `--no-excel` | 엑셀 재계산을 건너뛴다 |
| `--keep` | `_색인/신고건.json` 「중소기업특별세액감면」 을 쓰지 않는다 |

엑셀이 없는 환경(맥, 리눅스, Claude 앱 실행 환경)에서는 엔진이 「엑셀 재계산을 하지 않았습니다」 를 낸다. 정상이다. 이때는 화면의 감면세액(엔진 값)과 확인 줄을 전하고, 결과 워크북을 엑셀로 열면 수식이 계산되어 「목록」 시트에 검산과 엔진 대조가 나온다고 알려 준다. 결과 파일은 반드시 사용자에게 넘긴다.

## 입력

입력은 `<회사>/<연도> 법인세/00 받은자료/중소기업감면/중소감면_입력.xlsx` 한 파일이다. 시트 둘이고 엔진은 회사 시트만 읽는다.

| 시트 | 줄 | 필수 |
|---|---|---|
| 회사 | 한 항목 한 줄(A 항목 · B 값 · C 설명 · D 받는 곳) | 과세연도 시작일 · 종료일, 업종, 별표 3 업종 호, 매출액, 본점 수도권, 각 사업연도 소득금액, 과세표준, 산출세액 |
| 정의 | 항목마다 형식 · 비었을 때 · 받는 곳 · 설명 | 읽지 않는다 |

선택 항목(비우면 기본값으로 읽는다): 중소기업(기본 Y), 업종 괄호 제외 업종, 일반 서적 출판업, 소기업 규모 기준 직접 입력, 감면 사업장 수도권, 감면 제외 소득(0), 이월결손금 · 비과세 · 소득공제(0), 공제액등이 생긴 사업(불분명), 상시근로자 수(해당 · 직전, 비우면 한도 1억원), 최저한세 과세표준 · 세율(7%), 먼저 적용할 다른 최저한세 대상 감면 · 공제, 통합고용 세액공제, 제127조 제4항 세액공제, 같은 사업장 다른 감면, 적용 선택. Y · N 칸을 비우면 N 이다(중소기업만 기본 Y).

자료별로 받는 곳:

| 자료 | 받는 곳 | 들어가는 항목 |
|---|---|---|
| 사업자등록증(업태 · 종목 · 사업장 주소) | 회사 | 업종 · 업종 괄호 제외 업종 · 일반 서적 출판업 · 감면 사업장 수도권 |
| 법인등기부(사업연도 · 본점) | 회사, 대법원 인터넷등기소 | 과세연도 · 본점 수도권 |
| 중소기업 등 기준검토표(51호), 한국표준산업분류 | 당기 신고서 | 중소기업 · 별표 3 업종 호 · 최저한세율(졸업 유예) |
| 손익계산서 | 당기 결산 | 매출액 · 감면 제외 소득(영업외 이자 · 배당 · 임대료 · 처분손익) |
| 세무조정계산서(3호) · 이월결손금 관리대장 · 소득구분계산서(48호) | 당기 세무조정 | 각 사업연도 소득금액 · 이월결손금 · 비과세 · 소득공제 · 공제액등이 생긴 사업 · 과세표준 · 산출세액 |
| 최저한세조정계산서(4호) | 당기 세무조정 | 최저한세 과세표준 · 세율 |
| 급여대장 또는 법인세-통합고용 결과(종전 범위 인원) | 회사 급여 담당 | 상시근로자 수(해당 · 직전) |
| 공제감면세액계산서, 다른 공제감면 결과 | 당기 세무조정 | 통합고용 세액공제 · 제127조 제4항 세액공제 · 같은 사업장 다른 감면 · 적용 선택 |

1. **업종**은 조특법 제7조 제1항 제1호 감면 업종 목록(양식의 목록) 중 감면 사업장의 업종이다. 해당이 없으면 「감면 업종 아님」. 도매 · 소매 · 의료업은 감면율이 낮다.
2. **별표 3 업종 호**는 주된 업종의 중소기업기본법 시행령 별표 3 번호(1 ~ 43)다. 그 호의 매출액 기준 이하면 소기업이다. 워크북 「0기준」 시트에 43줄 기준표(2025. 9. 1. 개정 표와 그 전 표)가 있다.
3. **본점이 수도권(서울 · 인천 · 경기)이면** 지방 사업장도 수도권 감면율이다(제7조 제1항 단서).
4. **감면 제외 소득**은 감면 사업장 · 감면 업종 소득이 아닌 것이다. 엔진이 고르지 않으니 손익계산서 영업외 항목을 보고 넣는다. 비우면 0 이고 확인 줄이 나온다.
5. **상시근로자 수**는 한도 계산에만 쓴다. 직전보다 줄면 1명당 5백만원을 1억원에서 뺀다. 법인세-통합고용 스킬을 돌렸으면 그 종전 범위 인원을 쓴다.

## 순서

1. **양식 만들기**: `--template`. 이미 있으면 그대로 둔다. 설치 확인은 `--sample`.
2. **자료 옮기기**: 위 표대로 회사 시트를 채운다. 값은 원본에서 그대로 옮기고 지어내지 않는다. 업종 · 별표 3 호는 한국표준산업분류로 회계사가 고른다.
   - **계산 전에 되묻는다(건너뛰지 않는다).** 감면 제외 소득(감면 업종이 아닌 사업, 영업외 소득)이 얼마인지, 이월결손금이 어느 사업에서 생겼는지 모르면 엔진을 돌리기 전에 회사에 한 번에 묻는다. 비우면 감면소득이 커진다. 답을 못 받으면 기본값으로 돌린 값을 **잠정치** 로만 전한다.
3. **엔진 실행**: `PYTHONUTF8=1 python -m ctax smereduce "<회사>/<연도> 법인세"`. 화면 줄은 아래 「결과물」 표대로 읽는다. `확인:` 줄은 회계사에게 그대로 전한다.
4. **워크북 확인**: 「목록」 의 결과 · 검산 · 확인할 것을 먼저 본다. 노란 칸을 고쳤으면 입력 파일도 고치고 다시 돌린다.
5. **보고**: 감면세액과 ⑦ · ⑧ · ⑨, 감면율 구분(기업 규모 · 지역 · 업종), 한도와 상시근로자 출처, 최저한세로 깎인 금액, 통합고용 공제 당기 · 이월, 중복 배제 확인 줄, 엔진 대조 · 검산 결과, 이 검증이 보지 않는 것.

## 판단이 들어간 곳 (회계사에게 알릴 것)

- **통합고용세액공제와 함께 받는다(★★★)**: 제127조 제4항 본문의 공제 목록에 제29조의7 · 제29조의8이 없고, 단서는 제6조(창업감면)만 막는다. 같은 해 최저한세 여지는 감면이 먼저 쓴다. 공제는 남은 여지만큼 받고 넘는 금액은 이월한다. 공제 순서는 납세자가 고를 수 있어 「먼저 적용할 다른 최저한세 대상 감면 · 공제」 로 바꾼다.
- **창업감면과의 관계(★★★)**: 같은 사업장이면 제127조 제5항으로 하나만 고른다. 창업감면 기간(5개 과세연도)이 끝나면 중소기업특별세액감면을 받는다.
- **통합투자 등 제127조 제4항 공제(★★★)**: 감면과 하나만 고른다. 감면은 이월되지 않고 공제는 이월된다는 점을 확인 줄로 알린다.
- **한도의 소수 인원(★★☆)**: 감소 인원이 1.5명이면 7,500,000원을 뺀다. 조문은 「1명당」 만 정해 소수 처리는 엔진 규칙이다.
- **소기업 판정 매출액(★★☆)**: 과세연도가 1년 미만이어도 연 환산하지 않는다. 시행령 제6조 제4항이 「매출액」 만 정한다.
- **별표 3 판(★★☆)**: 소기업 기준표는 2025년 9월 1일 개정됐다(도매 · 소매 50억 → 60억원 등). 과세연도 종료일이 그날 이후면 새 표, 앞이면 옛 표(2017. 10. 17. 개정)로 가린다. 세법 적용례가 없어 종료일 현재 시행 표를 쓴 것은 엔진 규칙이다. 2025 과세연도처럼 표가 바뀐 해는 확인 줄이 옛 표 기준도 알린다.
- **수소발전사업(★★☆)**: 적용 시기 부칙을 찾지 못해 2026년 이후 개시 과세연도로 두었다.
- **감면소득 계산(★★☆)**: 공제액등(이월결손금 · 비과세 · 소득공제)이 생긴 사업이 불분명하면 소득금액 비례로 안분한다(법인세법 시행령 제96조).
