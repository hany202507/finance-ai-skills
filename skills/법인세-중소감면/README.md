# 중소기업특별세액감면 사용법 (ctax smereduce)

입력 엑셀 한 파일(회사 시트)을 넣으면 중소기업에 대한 특별세액감면(조세특례제한법 제7조)을 판정하고 감면세액을 계산한다. 검증 엑셀과 세액감면(면제)신청서(조특 별지 제2호서식) 112 줄 PDF 가 나온다. 판정 · 감면율 · 감면세액을 엑셀 수식으로 다시 계산해 파이썬 엔진 값과 40개 값을 대조한다.

Claude Code 에서 쓰는 절차는 [SKILL.md](SKILL.md) 에 있다. 이 폴더(`skills/법인세-중소감면/`)를 `~/.claude/skills/` 에 두면 「중소기업특별세액감면 계산해 줘」 라고 하면 스킬이 SKILL.md 순서대로 계산하고, 받은 자료를 입력 양식으로 옮기는 일도 스킬이 한다.

## 0. 먼저 샘플로 돌려 보기

합성 회사(샘플기계, 실제 회사와 무관)가 들어 있다. Claude Code 에서는 「샘플로 중소감면 돌려 줘」 라고 하면 스킬이 아래 두 명령을 돌린다. 직접 돌릴 때는 이 폴더의 `scripts/` 에서 아래 두 줄을 친다. 신고 건 폴더는 아무 곳이나 되고 이름만 `<회사>/2025 법인세` 꼴로 한다.

```
python -m ctax smereduce "C:/temp/샘플기계/2025 법인세" --sample
python -m ctax smereduce "C:/temp/샘플기계/2025 법인세"
```

첫 줄이 입력 파일을 만들고 둘째 줄이 검증 엑셀과 신청서 PDF 를 만든다. 아래 값이 나오면 설치가 된 것이다.

| 항목 | 기대값 |
|---|---|
| 비율 구분 · 감면율 | 소기업(매출 90억원 ≤ 별표 3 제13호 120억원) · 수도권 외 · 그 밖 → 30% |
| 감면소득 | 820,000,000 − 이자수익 20,000,000 − 이월결손금 안분 97,560,975 = 702,439,025 |
| ⑦ 대상세액 | 116,800,000 × 702,439,025 ÷ 720,000,000 × 30% = 34,185,365 |
| 감면한도 | 1억원 − 1.5명 감소 × 5백만원 = 92,500,000 |
| 중소기업특별세액감면(112) | 34,185,365 |
| 통합고용 세액공제 | 40,000,000 중 당기 32,214,635 · 이월 7,785,365 |
| 화면 셋째 줄 | 엔진 대조 40개 중 40개 일치 · 검산 8개 중 8개 통과 |

샘플은 수도권 외 지역에서 기타 기계 및 장비 제조업을 하는 2025 과세연도 법인이다. 각 사업연도 소득 8억2천만원 중 이자수익 2천만원은 감면 제외 소득이고, 이월결손금 1억원은 생긴 사업이 불분명해 소득금액 비례로 안분한다. 상시근로자가 30명에서 28.5명으로 줄어 한도가 깎인다.

입력 하나를 바꿔 다시 돌리면 결과가 아래처럼 바뀐다.

1. 「본점 수도권」 을 Y 로: 소기업 · 수도권 · 그 밖 20%, 감면세액 22,790,243.
2. 「매출액」 을 13,000,000,000 으로: 별표 3 기준을 넘어 중기업 · 수도권 외 · 그 밖 15%, 감면세액 17,092,682.
3. 「상시근로자 수(직전)」 를 28.5 로: 감소가 없어 한도 1억원, 감면세액은 그대로.
4. 「업종」 을 「감면 업종 아님」 으로: 감면율 0, 감면세액 0.
5. 과세연도를 2025-07-01 ~ 2025-12-31, 「매출액」 을 7,000,000,000, 「창업 · 분할 · 합병 과세연도」 를 Y 로: 매출액을 6개월에서 연 140억원으로 환산해 중기업 · 수도권 외 · 그 밖 15%, 감면세액 17,092,682. 「창업 · 분할 · 합병 과세연도」 가 N 이면 환산하지 않아 소기업 30% 이고 확인 줄이 나온다.

## 1. 입력: 준비할 자료와 넣는 곳

입력은 `<회사>/<연도> 법인세/00 받은자료/중소기업감면/중소감면_입력.xlsx` 한 파일이다. 빈 양식은 아래 명령이 만든다.

```
python -m ctax smereduce "<회사>/2025 법인세" --template
```

| 시트 | 넣는 것 |
|---|---|
| 회사 | 한 항목 한 줄. B 열에 값, C 열은 설명, D 열은 받는 곳. 「(필수)」 가 붙은 항목이 비면 끝 코드 2 로 멈춘다 |
| 정의 | 항목마다 형식 · 비었을 때 · 받는 곳 · 설명. 엔진은 읽지 않는다. 같은 표가 [references/입력정의.md](references/입력정의.md) 에 있다 |

| 자료 | 받는 곳 | 들어가는 항목 |
|---|---|---|
| 사업자등록증(업태 · 종목 · 사업장 주소 · 개업일), 업종별 요건 자료(요양급여 비율 · 훈련 실적 · 차량 등록) | 회사 | 업종 · 업종 괄호 제외 · 한정 요건 미충족 · 일반 서적 출판업 · 감면 사업장 수도권 |
| 법인등기부(사업연도 · 본점 · 설립 · 분할 · 합병 등기일) | 회사, 대법원 인터넷등기소 | 과세연도 · 본점 수도권 · 창업 · 분할 · 합병 과세연도 |
| 중소기업 등 기준검토표(51호), 한국표준산업분류 | 당기 신고서 | 중소기업 · 별표 3 업종 호 |
| 손익계산서 | 당기 결산 | 매출액 · 감면 제외 소득 |
| 세무조정계산서(3호) · 이월결손금 관리대장 · 소득구분계산서(48호) | 당기 세무조정 | 각 사업연도 소득금액 · 이월결손금 · 과세표준 · 산출세액 |
| 최저한세조정계산서(4호) | 당기 세무조정 | 최저한세 과세표준 · 세율 |
| 상시근로자 수(해당 · 직전) | 급여대장 또는 법인세-통합고용 결과 | 상시근로자 수 |
| 함께 받으려는 공제감면(통합고용 · 통합투자 · 창업감면) | 공제감면세액계산서 | 회사 시트 「통합고용 세액공제」 · 「제127조 제4항 세액공제」 · 「같은 사업장 다른 감면」 · 「적용 선택」 |

필수는 과세연도 시작일 · 종료일, 업종, 별표 3 업종 호, 매출액, 본점 수도권, 각 사업연도 소득금액, 과세표준, 산출세액이다. 나머지는 비우면 기본값으로 본다(Y · N 항목은 N, 중소기업만 기본 Y, 금액은 0, 상시근로자가 없으면 한도 1억원). 과세연도는 2023-01-01 이후 개시하고 1년을 넘지 않아야 하며, 최저한세율은 7% 를 넘지 못한다. 어기면 끝 코드 2 로 멈춘다.

비워 두면 감면액이 달라지는 항목은 둘이다. 감면 제외 소득을 비우면 영업외 소득까지 감면소득에 들어가 감면이 커지고, 이월결손금이 감면사업에서 생겼는데 「불분명」 으로 두면 감면소득에서 덜 빠진다. 모르면 회사에 먼저 묻는다.

## 2. 돌리기

```
python -m ctax smereduce "<회사>/2025 법인세"
```

| 옵션 | 하는 일 |
|---|---|
| `--template` · `--sample` | 빈 양식 · 합성 회사 입력을 만들고 끝낸다 |
| `--input <파일>` | 정해진 위치 대신 그 파일을 읽는다 |
| `--no-excel` | 엑셀 재계산을 건너뛴다 |
| `--keep` | `_색인/신고건.json` 「중소기업특별세액감면」 을 쓰지 않는다 |

엔진 대조와 검산 결과를 화면에 내려면 엑셀과 pywin32(`pip install pywin32`)가 있어야 한다. 없으면 엑셀 재계산을 건너뛴다. 이때는 워크북을 엑셀로 열어 「목록」 시트에서 같은 결과를 본다. 워크북이 엑셀에 열려 있으면 쓰지 못하니 닫고 돌린다.

## 3. 결과물

| 파일 | 내용 |
|---|---|
| `2 조서/중소감면_검증.xlsx` | 검증 워크북. 판정 · 감면율 · 금액이 모두 수식이다 |
| `2 조서/중소감면_법정서식.pdf` | 법제처 별지 제2호서식 원본 1쪽(112 줄)과 3쪽(1A4 합계) 위에 값만 얹은 신고용 서식. 상호 외 신청인 란 · 날짜 · 서명과 4쪽 ❺ 감면한도계산은 사람이 적는다 |
| `_색인/중소감면.json` | 판정 · 금액 · 검산 · 확인 줄 |
| `_색인/신고건.json` 의 「중소기업특별세액감면」 | 감면세액 · 대상세액 · 감면율 · 한도 · 감면소득. 다른 도구가 이어 읽게 남긴다 |

| 시트 | 내용 |
|---|---|
| 목록 | 결과, 검산 8개, 확인할 것. 여기부터 본다 |
| 0입력 · 0기준 | 입력 값과 법령 값(감면 비율 표 · 별표 3 규모 기준 43줄(새 표 · 옛 표) · 한도), 값마다 근거 조문 |
| 2계산 | 감면 대상 → 소기업(개월 수 · 연 환산 매출액) · 수도권 · 업종 구분 → 감면율 → 한도 → 감면소득 → 감면세액 · 최저한세 → 중복 배제 · 통합고용 |
| 3신청서 | 별지 제2호서식 112 줄과 1A4 합계 |
| 4엔진대조 | 파이썬 엔진 값과 수식 값 40개 |

화면 첫 줄은 감면세액(112)과 ⑦ → ⑧ → ⑨, 둘째 줄은 판정 · 비율 구분 · 감면율 · 한도 · 감면소득, 셋째 줄은 엔진 대조와 검산, 그 아래 `확인:` 줄은 회계사가 볼 판단이다. 끝 코드는 0 모두 통과, 1 확인할 검산이나 불일치가 있음, 2 입력을 읽지 못함이다. 2 일 때는 메시지에 시트 · 행 · 항목이 나온다.

| 검산 | 어긋나면 볼 곳 |
|---|---|
| 신청서 1A4 ⑨ = 2계산 신청 금액 | 3신청서 수식 |
| 112 ⑨ ≤ ⑧ ≤ ⑦ | 최저한세 · 한도 줄 수식 |
| ⑨ ≤ 감면한도 | 상시근로자 수 · 한도 줄 |
| ⑦ = ⑨ + 한도로 뺀 금액 + 최저한세로 뺀 금액 | 한도 · 최저한세 줄 수식 |
| 감면세액 ≤ 감면소득에 대한 세액 | 감면율 수식 |
| 감면소득 ≤ 과세표준 | 감면 제외 소득 · 이월결손금 입력 |
| 감면 뒤 세액이 최저한세를 지킴 | 최저한세 과세표준 · 세율 · 먼저 적용할 금액 |
| 엔진 대조 불일치 0건 | 4엔진대조에서 어느 줄인지 본다. 노란 셀을 고쳤으면 입력 파일을 고치고 다시 돌린다 |

## 4. 회계사가 정할 것

- **업종과 별표 3 호**: 감면 업종인지와 주된 업종 번호는 한국표준산업분류로 회계사가 고른다. 엔진은 입력한 대로 판정한다.
- **감면 제외 소득**: 엔진이 고르지 않는다. 영업외 이자 · 배당 · 임대료 · 처분손익과 감면 업종이 아닌 사업 소득을 회계사가 넣는다.
- **최저한세 순서**: 엔진은 감면이 최저한세 여지를 먼저 쓴다고 본다. 납세자가 공제를 먼저 고르면 「먼저 적용할 다른 최저한세 대상 감면 · 공제」 에 그 금액을 넣는다.
- **창업 · 분할 · 합병 과세연도**: 1년 미만이면 엔진이 매출액을 연 환산한다(시행규칙 제2조 제4항 단서). 사업연도 변경 · 법인 전환 첫 과세연도도 환산한다는 해석이 있어 해당 여부는 회계사가 정한다.
- **업종 괄호 제외 · 한정 요건**: 의원 · 치과의원 · 한의원의 요양급여비용 비율, 직업능력개발훈련이 주된 사업인지, 지식재산 임대인지, 전기 · 수소 자동차 비율을 회계사가 확인한다.
- **한도의 소수 인원, 개월 수 세는 법(1개월 미만은 1개월), 별표 3 판(과세연도 종료일 현재 시행 표), 2026-09-18 을 걸치는 과세연도의 발전사업 업종(과세연도 시작일 현재 목록), 한도와 최저한세가 함께 걸릴 때 서식 ⑧ 에 적을 값**은 엔진 규칙이고 회계사 확인 전이다.

## 5. 다루지 않는 것

개인사업자 110%(제7조 제2항) · 알뜰주유소(제3항), 2023-01-01 앞에 개시한 과세연도(종전 규정), 사업장이 여러 곳이고 감면율이 다른 경우의 합산, 한 사업장에서 감면율이 다른 업종을 함께 경영할 때의 소득 구분, 제128조 제2항 ~ 제4항의 감면 배제(결정 · 기한 후 신고, 경정을 미리 알고 낸 수정신고, 현금영수증가맹점 미가입 · 신용카드 · 현금영수증 발급 거부 등), 세액감면신청서 4쪽 ❺, 상시근로자 수 세기(법인세-통합고용 스킬을 쓴다).
