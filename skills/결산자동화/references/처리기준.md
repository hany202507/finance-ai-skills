## A. 표준 처리 관례 (회사 불문 재사용)

- **대원칙 — 보통예금(현금) 출금은 손익계정과 직접 상대하지 않는다.** 비용은 먼저 미지급금(상품은 외상매입금, 매출은 외상매출금)으로 인식하고, 지급·회수 때 보통예금과 상계한다. 그러면 발생 전표와 지급 전표를 따로 검토할 수 있다(전표 틀=와꾸 검토). 검산: `verify_close.py` 의 「보통예금 출금과 손익계정이 직접 상대한 전표 0건」. 입금 쪽 이자수익, 임차보증금·비품 같은 자산 취득은 이 원칙 밖이다.
- **급여(총액법)**: 발생 = 급여(차) / 예수금 + 미지급금(실지급액)(대). 지급 = 미지급금(차) / 보통예금(대, 현금흐름 영업-급여). 은행 급여출금 = 실지급액과 대사.
- **4대보험 납부**: 납부월 10일에 예수금(차, 전월 급여공제 상계) + 복리후생비(차, 회사부담분) / 미지급금(대)로 먼저 인식하고, 같은 날 미지급금(차) / 보통예금(대)로 지급한다. 예수금 잔액이 다음 달로 이월. 첫 달 납부는 기초 예수금 전액을 상계. 회사부담분은 납부월에 인식한다(귀속월 발생 인식은 급여대장에 부담분 열이 없어 쓰지 않는다. 확인사항에 한계로 적는다).
- **경비·자산 매입(세금계산서)**: 비용(자산) + 부가세대급금 / 미지급금(253). 지급 = 미지급금 / 보통예금(현금흐름 태그는 지급 전표의 보통예금 줄). 프로파일 `매입품목_계정` 상대계정은 상품 251, 그 밖은 253. 더존 매입매출 업로드의 상대계정도 이 값을 따른다.
- **보험료·세금과공과·이자비용·프로파일 은행라벨 출금(교통비 정산 등)**: 비용 / 미지급금 → 미지급금 / 보통예금. 엔진 `pay_out()` 이 지급 전표를 만든다.
- **카드**: 비용(+부가세대급금) / 미지급금(253) → 카드대금 결제 때 미지급금 / 보통예금. 매출: 외상매출금 → 회수 때 보통예금 / 외상매출금. PG 정산 수수료는 정산 때 외상매출금과 상계한다(프로파일 `정산차감_규칙`, 매출을 외상매출금으로 먼저 인식하므로 이 원칙에 맞는다).
- **감가·무형상각(정액)**: (취득가 − 잔존0) ÷ 내용연수 × (해당 개월/12). 결산조정(감가상각비/감가상각누계액, 무형자산상각비/무형자산상각누계액).
- **매출원가 대체**: 기초재고 + 당기매입 − 기말재고. 실사값 없으면 직전 수준·원가율로 **잠정** + 확인사항. 결산조정(상품매출원가/상품).
- **부가세 정리**: 매출세액(예수금) − 공제가능 매입세액(대급금) = 순액. (+)면 미지급세금, (−)면 미수금. 결산조정으로 예수금·대급금을 0으로 상계.
- **이자 현금흐름 분류**: 예금이자수익=영업, 차입금이자비용=재무 (K-GAAP 복수분류). 확인사항 「전기 승계」에 1행.
- **카드 라우팅**: 국내 과세·**공제 가능분(가맹점 사업자번호 확인)** → 매입매출(과세유형 57, 공급가=총액×10/11 내림). 해외결제·불공제·간이·**사업자번호 미확인** → 일반전표(전액 비용, 세액 미분리).
- **더존 코드변환**(workbook 내부코드→더존, 일반전표 업로드 시): 이자비용 951→**931**(더존 951=투자자산처분손실), 감가상각비 820→**818**(더존 820=수선비), 무형자산상각비 840→840. 나머지 판관비 8xx는 표준 일치.

## B. 매입세액 불공제 사유 체크리스트 (매입공제 반영 전 필수)

매입을 **매입매출(공제)**로 넣기 전 아래 해당 여부를 검토. 해당하면 **불공(54) 또는 일반전표 전액비용**. 애매하면 잠정+등재. (부가세법 §39, 시행령 §75)

1. **접대비(기업업무추진비)** 관련(거래처 선물·경조사·유흥·골프·상품권·식사접대) — 세금계산서 있어도 불공제. (직원 대상 복리후생비는 공제 → 접대성 vs 복리후생 구분)
2. 사업무관 지출 / 대표·개인 사적 사용.
3. **비영업용 소형승용차** 구입·임차·유지(1000cc 초과). 경차·화물·9인승↑·운수업용 예외.
4. 면세사업 관련 매입 / 공통매입세액 안분 대상.
5. **여객운송·목욕·이발·미용·입장권 발행업**(시행령 §75) — 신용카드매입도 불공제(전세버스 예외).
6. 간이과세자·면세사업자로부터의 매입(세금계산서 미발급).
7. 세금계산서 미수취·필요적 기재사항 부실·사실과 다른 세금계산서.
8. 등록 전 매입세액 — 등록신청일 역산 20일 이내분 예외.
9. **가맹점 사업자번호·과세유형 미확인 신용카드 매입** — 공제 근거 불충분 → 일반전표 전액비용(카드사 번호로 대체 금지).

> 트리거: 적요·품명에 식대·접대·경조·선물·상품권·주유·차량·리스·골프·유흥·회식·기부가 보이면 즉시 판정하고 확인사항 「부가세·세무」에 등재. 당기 해당 없어도 '검토 완료·해당 없음'을 검증 요약에 남긴다.

## C. 회사 프로파일 — 템플릿

새 회사는 이 블록을 채워 `scripts/profile_<회사>.py`로 만든다(예시: `profile_sample.py`).

```
- 업종/형태 / 회계기준(K-GAAP·K-IFRS) / 설립일
- 매출 계정 매핑: 품목/유형 → 401 상품매출 / 404 (제품·용역)매출
- 매입 품명 → (기본계정, 상대계정): 상품(146,251)·식자재(452,103)·임차료(819,103) …
- 카드 가맹점 → 계정/부가세: (가맹점유형 → 계정 / 공제·불공제·전액비용)
- 감가상각 자산: (자산코드) 정액 N년
- 차입금: (은행) 금액·이율·월이자
- 회사 설정 계정명(더존 표준과 다른 것): 801=급여, 404=용역매출 …
- 게시일 관례: 매출 발생일·매입 계상일·회수일 등
- 급여 공제 항목 / 거래처코드 체계
- 확정된 판단(전기 승계) 표 / 미해결 이슈 / 기간 이력
- (선택) 부문손익·CC 매핑: 수익부문 정의(적요→부문) / 코스트센터 정의(적요·가맹점→계정+CC) / 공통비 배부 기준 — `scripts/segment_pnl.py` RULES 구조
```

## E. 핵심 대사 관계 (이게 맞으면 거의 다 맞다)
- 기말현금 = 기초현금 + (은행 총입금 − 총출금)
- 외상매출금 기말 = 기초 + 매출(공급가+세액) − 회수
- 외상매입금 기말 = 기초 + 외상매입(총액) − 지급
- 미지급금 기말 = 기초 + (카드·경비·급여·4대보험 발생) − 지급. 카드 외에는 같은 달 지급으로 0 에 가깝다
- 미지급세금 = 매출세액 − 공제가능 매입세액
- 자산총계 = 부채총계 + 자본총계 + 당기순이익
