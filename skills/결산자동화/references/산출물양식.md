# 산출물 규격 — 4종 & 수식 규칙 (설계서 §8)

에이전트=초안작성자, 전문가=최종확정자. 결산확정 workbook·확인사항은 **전문가 검토용**,
더존 업로드 2종은 **업로드용(값·숫자형)**. 분개 한 줄을 고치면 재무제표까지 자동 재계산돼야 한다.

## 산출물 4종
1. `결산확정_{기간}.xlsx` — 8시트(분개장·결산조정분개·시산표·손익계산서·재무상태표·현금흐름표_직접법·근거·검증리포트). 시산표·재무제표는 **살아있는 수식**.
2. `일반전표_업로드_더존_{기간}.xlsx` — 더존 일반전표(값·숫자형).
3. `매입매출전표_업로드_더존_{기간}.xlsx` — 더존 매입매출전표(값·숫자형·per-invoice).
4. `확인사항_{기간}.docx` — 전문가 검토용 Word(가장 중요). 「확정·회신 필요 항목」 요약 + 판단 5필드 표.

## 1. 결산확정 workbook — 8시트 & 컬럼
| 시트 | 컬럼 |
|---|---|
| 분개장 | 전표No·일자·구분·계정코드·계정·차변·대변·**현금흐름**·**분류**·적요·거래처 |
| 결산조정분개 | 조정번호·일자·계정코드·계정·차변·대변·적요 (+합계) |
| 시산표 | 코드·계정·기초잔액·기중차변·기중대변·조정차변·조정대변·기말잔액 (+합계) |
| 손익계산서 | 과목·금액·비고 (I.매출액~X.당기순이익 구분식) |
| 재무상태표 | 과목·기초·증감·기말 ([자산]/[부채]/[자본]) |
| 현금흐름표_직접법 | 구분·항목·금액, 영업/재무 항목별 상세, 기초/순증감/기말현금 |
| 근거 | 항목·값·비고 |
| 검증리포트 | No·검증항목·결과(PASS/FAIL, IF수식)·상세 |

## 2. 수식 규칙 (살아있는 워크북의 핵심 — `build_workbook.py`가 구현)
- 분개장·결산조정분개 = 값 입력. 합계행만 SUM.
- **시산표**(코드=A열):
  - 기초 = `SUMIFS(분개장.차변, 코드, A, 구분,"전기이월") − SUMIFS(분개장.대변,…,"전기이월")`
  - 기중차/대 = `SUMIFS(분개장.차변/대변, 코드, A, 구분,"<>전기이월")`
  - 조정차/대 = `SUMIFS(결산조정분개.차변/대변, 코드, A)`
  - 기말 = `기초 + 기중차 − 기중대 + 조정차 − 조정대` (net-debit; 부채·자본·수익은 음수)
  - 합계행 기말 = 0 이어야 대차 균형.
- **손익계산서** = 시산표 기말 셀 참조. 매출·이자수익은 부호 반전(−H). 소계·순이익은 사칙.
- **재무상태표** = 기말: 자산 H, 부채·자본 −H. 기초: 시산표 C. 증감=기말−기초. 당기순이익=손익 셀 참조.
- **현금흐름표(직접법)** = 항목별 `SUMIFS(분개장, 현금흐름 태그)`. 태그는 `영업-매출회수/영업-급여/…/재무-이자지급`처럼 **항목 단위**. 기말현금 = 순증감 + 기초현금.
- **검증리포트** = `=IF(조건,"PASS","FAIL")`.
- 더존 업로드 2종은 반대로 **수식 금지·값(숫자형)만**.

## 3. 더존 업로드 (상세는 [더존업로드양식.md](더존업로드양식.md))
- 라우팅: 세금계산서·계산서·공제 카드 → 매입매출 / 급여·이체·차입·자본·카드대금·결산조정 → 일반전표.
- **숫자형 규칙**: 금액·**사업자등록번호**·계정코드·과세유형 = 숫자형(int). 텍스트면 반려. **앞자리 0 있는 거래처코드만 텍스트**('00139').

## 4. 확인사항 .docx (설계서 부록 B — `build_docx.py`가 구현)
구성: ① 전문가 확정·회신 필요 항목(요약 체크리스트) → ② 판단 5필드 표(No|항목|상황|선택지|추천안·근거|재무영향) → ③ 전기 방식 승계·편차 표 → ④ 채권·채무 기말잔액 → ⑤ 손익 요약 → ⑥ 검증 요약 → 꼬리말(산출물 경로·중복 업로드 주의·잠정 확정 전 업로드 금지). Word 표는 머리행 음영·굵게, 추천안·편차 강조.
