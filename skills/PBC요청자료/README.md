# PBC요청자료

외부감사를 시작할 때 감사 폴더 하나에 받은 자료를 넣으면, 무엇을 받았고 무엇이 빠졌는지와 회사에 보낼 요청 메일 초안을 만듭니다. 전기 감사보고서 · 전기조서로 회사 정보와 전기 의견을 채우고 계약 단계 조서 초안도 만듭니다.

- **결과.** 요청자료 목록(`PBC_요청자료목록.xlsx`, 실제 요청자료 양식 75~90줄), 요청 메일 초안(.txt), 계약전위험평가(1100) · 감사업무조건합의(1200 워드) · 기업이해(2100) 초안.
- **빠진 자료는 기간까지 봅니다.** 의사록 · 원천세가 9월까지만 있으면 「10~12월분」, 잔액증명이 10월말이면 「12월말 기준」 이 빠진 것입니다. 해당 계정 잔액이 없으면 그 자료는 요청하지 않습니다.
- **다시 요청.** 메일을 보낸 날을 적어 두면 다음 메일에서 앞서 요청한 자료를 따로 묶습니다.
- **나누는 일.** 엑셀 숫자는 엔진이 읽고, 스캔본 · 문서에서 감사인 이름 같은 글을 읽는 일은 Claude 가 「확인 전」 으로 넣습니다. 판단 칸과 메일 보내기는 회계사 몫입니다.

## 시험해 보기

가상 회사 도담소프트(가상)의 2025 기말감사 1차 수령 자료 6개가 `examples/모의자료/받은자료/` 에 있습니다. Claude 에게 「PBC요청자료 예시로 돌려 줘」 라고 하면 감사 폴더를 만들고 자료를 넣어 돌립니다. 기대 결과는 받은 2 / 18, 빠진 자료 14건입니다.

전기 자료는 실제 감사 자료 양식으로 만들었습니다. 전기 감사보고서는 DART 양식 19쪽입니다(감사인의 감사보고서 2쪽, 재무제표 5종, 주석 22개). 전기조서(WTB)는 시트 10개가 수식으로 이어진 엑셀입니다(표지 · TB · 재무상태표 · 손익계산서 · AJE · CF정산표와 공시용 재무제표 4종). 그래서 2100 기업이해의 「전기 대비 변동」 시트에 과목마다 전기 금액이 나오고, 큰 변동은 전기 수행중요성 74,925,000원을 기준으로 가립니다. 「전기 과목 없음」 은 투자유가증권 · 감가상각누계액 두 과목만 남습니다.

## 한계

- 감사 엔진에서 감사 폴더 표준 · 받은자료 판독 · 시작 자료 · 빠진 자료 판정에 쓰는 부분만 담았습니다(`scripts/audit`). 분석적 검토 · 정산표 · 계정별 조서는 공개본에 없습니다.
- 스캔 PDF 를 글자로 읽으려면 Node.js 와 kordoc(`npx kordoc`)이 있어야 합니다. 없으면 `--no-ocr` 로 돌리고 Claude 가 쪽을 읽습니다.
