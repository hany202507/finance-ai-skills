# 서식·규격 근거

숫자 하나가 어디서 왔는지 따라갈 수 있어야 고칠 수 있다. 아래는 엔진이 박아둔 규칙과 그 출처다.
등급은 ★★★ 원문 확인 / ★★☆ 요지만 / ☆ 확인 불가.

출처 약칭

## 2. ⑤총지급액에서 뺄 비과세 — `집계.py` 의 `면제비과세열`

⑤는 **비과세와 과세미달을 포함한 총지급액**이다. 다만 지급명세서 제출이 면제되는 소득은 뺀다.

| 규칙 | 근거 | 등급 |
|---|---|---|
| 면제 대상 = 소득세법 시행령 §214①2의2·2의3 | https://www.law.go.kr/법령/소득세법%20시행령/제214조 | ★★★ |
| 2의2 = 법 §12 3호 **가~사목, 카·타·하·너·버·저목** | 같은 조문 | ★★★ |
| 2의3 = **시행령 §12 2호·3호·4호·8호** (일직료·숙직료·여비, 자가운전보조금, 제복·제화 등) | 같은 조문 | ★★★ |

그래서 **자가운전보조금(령 §12 3호)은 빼고**, 식대(법 §12 3호 러목)·국외근로(거목)·육아수당은
목록에 없으므로 **비과세여도 ⑤에 남긴다**. 달마다 이 범위를 달리 잡으면 지급명세서와 어긋난다.

## 3. 명세표 각 칸 — `집계.py` 의 `_신고서서식`

규격서의 세부 레코드(C103900, 자료구분 23) 항목 순서:
원천징수소득코드 / 인원 / 총지급액 / 징수세액(소득세 등) / 징수세액(농특세) / 가산세 /
당월조정환급세액 / 납부세액(소득세 등) / 납부세액(농특세)

| 규칙 | 근거 | 등급 |
|---|---|---|
| ④인원·⑤총지급액은 **양의 정수**. 총지급액이 인원보다 작으면 오류 | 규격서 [4][5]번 항목 | ★★★ |
| ⑥징수세액에는 양수 제한이 없다 → **중도퇴사 환급으로 음수 가능** | 규격서 (⑥에만 양의정수 점검 없음) | ★★★ |
| ⑩납부세액 소득세등은 **「소득세등(가산세 포함)」** 이고 **양의정수형식점검** 대상 | 규격서 납부세액 표 머리 + 항목 점검 | ★★★ |
| 그래서 `⑩ = MAX(0, ⑥ + ⑧가산세 − ⑨당월조정환급세액)` | 위 두 줄에서 따라 나옴 | ★★★ |
| ⑩⑪은 **가감계와 단독코드(A50·A60·A69·A70·A71·A80·A90), 그리고 A99** 에만 적는다 | 규격서 표25·납부세액 구조 | ★★★ |
| A99 는 위 줄들의 **합**이다. 따로 ⑥−⑨ 로 다시 계산하면 각 줄에 환급을 배분한 순간 어긋난다 | 총합계의 뜻 | ★★☆ |
| 실제 금액이 있는 소득만 레코드를 만든다 (0으로 채운 레코드 금지) | 규격서 | ★★★ |

엑셀 신고서는 **서식**이라 0인 줄도 자리를 지킨다. 전자파일에서 0 줄을 빼는 것은
`홈택스전자신고` 스킬 몫이다.

## 5. 소득코드와 가감계 — `집계.py` 의 `가감계규칙`

규격서 표25 기준. 가감계 = 구성 코드의 합.

| 가감계 | 구성 |
|---|---|
| A10 근로 | A01 간이세액 · A02 중도퇴사 · A03 일용 · A04 연말정산 |
| A20 퇴직 | A21 연금계좌 · A22 그 외 |
| A30 사업 | A25 매월징수 · A26 연말정산 |
| A40 기타 | A41 연금계좌 · A42 그 외 · A43·A44 종교인 · A49 가상자산 · A59 인적용역 |
| A47 연금 | A45 공적연금 · A46 연말정산 · A48 연금계좌 |

**A99 총합계 = 가감계 전부 + 단독코드(A50 이자 · A60 배당 · A69 저축해지 · A70 비거주자양도 ·
A71 금융투자 · A80 법인원천 · A90 수정신고).** 홈택스가 실제 납부할 세액을 여기서 읽는다.
가감계 블록만 더하면 이자·배당이 통째로 샌다.

연말정산 항목의 가감계 반영 (★★★ 규격서):
- A04(합계)는 A10에 반영, **A05(분납신청)는 반영 안 됨**, A06(납부금액)은 징수세액으로 반영
- 사업소득도 같다 — A26 반영, A27 미반영, A28 반영

## 7. 이 서식은 어느 시점 기준인가 — 대조한 것과 안 한 것

「최신 양식이냐」는 물음에 뭉뚱그려 답하지 않기 위해 나눠 둔다.

**원문과 대조한 것 (★★★)**
- 계산 규칙 전부 — 위 1~6절. 근거는 국세청 「원천세이행상황신고서 전산매체제출요령」 **2026-05-16** 판과
  2026-07-01 시행 소득세법·시행령·국세기본법
- 환급세액 조정란의 **항목 번호와 순서** — 규격서 C103900 필드 목록
- 명세표의 **칸 이름과 검증 규칙** — 규격서 C103900 세부 레코드 목록
- 소득코드 집합과 가감계 구성 — 규격서 표25

**대조하지 않은 것 (☆)**
- 신고서 **칸의 물리적 배치**(테두리·병합·줄 순서)를 소득세법 시행규칙 별지 제21호서식 원본
  이미지와 한 칸씩 맞춰보지는 않았다. 이 워크북은 홈택스에 그대로 올리는 서식이 아니라
  **검토용 배치**이고, 실제 제출은 `신고값_YYYYMM.json` → `홈택스전자신고` 경로를 탄다
- 서식 개정으로 코드가 신설·폐지되면 지급연월 기준으로 유효한지 봐야 한다(규격서 경고).
  이 스킬은 코드의 유효기간을 검사하지 않는다

그래서 사용자에게는 이렇게 말하는 것이 정확하다 — **「계산 규칙은 2026-05-16 규격서에 맞췄고,
칸 배치는 검토용입니다. 제출은 전자파일로 합니다.」**

규격서가 새로 나오면 이 절의 날짜를 고치고, `대조.py` 로 확정본과 맞춰 본 뒤 넘어가라.

## 8. 퇴직소득 과세이연 — A21 인지 A22 인지

| 규칙 | 근거 | 등급 |
|---|---|---|
| 퇴직일 현재 연금계좌에 있거나 연금계좌로 지급되는 경우, 또는 지급받은 날부터 **60일 이내** 연금계좌에 입금되는 경우에는 **연금외수령 전까지 원천징수하지 않는다** | 소득세법 §146②  https://www.law.go.kr/법령/소득세법/제146조 | ★★★ |
| 이미 원천징수된 경우 그 거주자는 **환급을 신청할 수 있다** | 같은 항 | ★★★ |
| 원천징수하지 않은 때에는 원천징수영수증에 **그 사유를 함께 적어** 발급한다 | 소득세법 §146③ 단서 | ★★★ |

그래서 A21(연금계좌)로 정정할 때는 **코드만 옮기고 세액을 그대로 두면 안 된다.** 이 스킬은
소득세를 다시 계산하지 않으므로, `확인사항.py` 가 「이 세액이 애초에 걷히지 말았어야 하는
금액인지」를 같이 묻고 칸을 비워 둔다. 대장 비고가 구분 글자와 어긋날 때도 마찬가지다.
