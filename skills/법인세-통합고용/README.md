# 통합고용세액공제 사용법 (ctax employ)

월별 급여대장과 사원명부를 엑셀 한 파일에 넣으면 상시근로자 수를 세어 공제세액계산서(조특 별지 제10호의9서식)와 상시근로자 명세서(제10호의10서식)까지 채운 검증 엑셀을 만든다. 2025년 12월 31일이 속하는 과세연도까지 쓴다. 2026 과세연도부터는 공제가 기존공제와 신규공제로 나뉘는데 이 엔진은 아직 계산하지 않는다(SKILL.md 「2026 과세연도부터」).

Claude Code 에서 쓰는 절차는 [SKILL.md](SKILL.md) 에 있다. 이 폴더(`skills/법인세-통합고용/`)를 `~/.claude/skills/` 에 두면 「통합고용세액공제 계산해 줘」 로 스킬이 같은 순서를 돌고, 급여 자료를 입력 양식으로 옮기는 일도 스킬이 한다.

## 0. 먼저 샘플로 돌려 보기

합성 회사 스무 명(실제 회사 · 사람과 무관)이 들어 있다. 이 폴더의 `scripts/` 에서 두 줄이면 된다. 신고 건 폴더는 아무 곳이나 되고 이름만 `<회사>/2025 법인세` 꼴로 한다.

```
python -m ctax employ "C:/temp/샘플회사/2025 법인세" --sample
python -m ctax employ "C:/temp/샘플회사/2025 법인세"
```

첫 줄이 입력 파일을 만들고 둘째 줄이 `2 조서/통합고용_검증.xlsx` 를 만든다. 같은 입력이 `examples/샘플회사_통합고용_입력.xlsx` 에도 있다. 아래 값이 나오면 설치가 된 것이다.

| 항목 | 기대값 |
|---|---|
| 해당 과세연도 상시근로자 수 · 청년등 | 13.31 · 8.73 |
| 직전 과세연도 상시근로자 수 · 청년등 | 11.32 · 6.99 |
| 증가 인원(전체 · 청년등 · 청년등 외) | 1.99 · 1.74 · 0.25 |
| 1차년도 세액공제액 | 27,355,000 (1.74 × 1,450만원 + 0.25 × 850만원) |
| 2차 · 3차년도 · 추가공제 | 37,500,000 · 14,500,000 · 13,000,000 |
| 세액공제액 | 92,355,000 |
| 화면 셋째 줄 | 엔진 대조 106개 중 106개 일치 · 검산 11개 중 11개 통과 |

사람마다 한 가지 경우를 넣었고 사원명부 「비고」 열에 적혀 있다.

| 사번 | 경우 | 결과 |
|---|---|---|
| S01 · S02 | 임원 겸 최대주주, 그 배우자 | 상시근로자가 아니다 |
| S07 | 2025년 8월에 35세 | 청년등 7개월(0.58), 나머지는 청년등 외 |
| S09 | 2025년 2월 계약 때 34세, 12월에 35세 | 청년 간주 3년이라 열한 달 모두 청년등(0.91) |
| S12 | 2025년 6월 20일 퇴사 | 월말 재직은 5월까지(0.41) |
| S14 · S15 | 1년 미만 기간제, 1년 이상 기간제 | S14 는 제외, S15 는 상시근로자지만 청년에서 빠진다 |
| S16 · S17 | 단시간 80시간, 40시간 | 0.5명, 제외 |
| S18 · S19 | 계약 때 62세, 장애인 | 나이와 무관하게 청년등 |
| S20 | 병역 21개월 | 그만큼 뺀 나이로 2025년 내내 청년 |
| S04 | 육아휴직 복귀자 | 추가공제 1명 |

입력 파일을 고쳐 다시 돌려 보면 검산이 어떻게 반응하는지 볼 수 있다.

1. 회사 시트 「청년 간주 적용」 을 N 으로: S09 의 청년등이 0.83 으로 줄고 1차년도 세액공제액이 26,875,000 이 된다.
2. 급여대장에서 S11 의 2024-09 줄을 지운다: 그 달이 근무개월에서 빠져 직전 인원이 11.24 가 되고 「직전 과세연도: 월말 재직인데 급여가 없는 달 수」 검산이 확인으로 바뀐다.
3. 급여대장 한 줄의 사번을 S99 로 바꾼다: 「급여대장 사번이 모두 사원명부에 있음」 검산이 확인으로 바뀐다.

## 1. 준비할 자료

| 자료 | 받는 곳 | 들어가는 시트 |
|---|---|---|
| 급여대장. 해당 과세연도와 직전 과세연도 열두 달씩(사람별 지급액, 소득세 · 국민연금 · 건강보험 공제액) | 회사 급여 담당, 더존 · 위하고 출력 | 급여대장 |
| 사원명부. 퇴사자 포함(생년월일 · 입사일 · 퇴사일 · 고용형태) | 인사 담당 | 사원명부 |
| 임원 · 최대주주와 친족 · 1년 미만 계약 · 단시간근로자 소정근로시간 | 등기부, 주주명부, 근로계약서 | 사원명부 |
| 병역 기간, 장애 · 경력단절 · 북한이탈주민 해당자 | 병적증명서 등 | 사원명부 |
| 전기 신고서의 조특 10호의9(1차년도 세액공제액, 그해 인원) | 전기 세무조정계산서 | 회사 |
| 기업 구분(중소 · 중견 · 일반), 인원이 늘어난 곳이 수도권인지 | 51호 기준검토표, 사업장 주소 | 회사 |

필수는 사원명부의 사번 · 성명 · 생년월일 · 입사일 · 고용형태와 급여대장의 귀속연월 · 사번 · 지급액이다. 나머지는 비우면 「해당 없음」 으로 본다. 직전 과세연도 급여대장이 없으면 전기 신고서의 인원을 회사 시트에 넣는다. 주민등록번호는 넣지 않는다.

## 2. 순서

`scripts/` 폴더에서 돌린다. 신고 건 폴더는 `<회사>/2025 법인세` 꼴이다.

```
python -m ctax employ "<회사>/2025 법인세" --template
```

`<회사>/2025 법인세/00 받은자료/급여/통합고용_입력.xlsx` 가 생긴다. 시트 「회사」 · 「사원명부」 · 「급여대장」 을 채운다. 열 설명은 「정의」 시트에 있고, 채운 모습은 `examples/샘플회사_통합고용_입력.xlsx`(합성 회사 스무 명)에서 본다.

더존 급여대장 PDF 가 있으면 급여대장 시트는 아래 명령으로 붙인다. 달마다 읽은 사람 수가 PDF 의 「합계(N명)」 과 같을 때만 넣는다.

```
python -m ctax.employ.douzone_pdf "<급여대장 PDF 폴더>" "<회사>/2025 법인세/00 받은자료/급여/통합고용_입력.xlsx"
```

다 채웠으면 돌린다.

```
python -m ctax employ "<회사>/2025 법인세"
```

화면에 세액공제액, 해당 · 직전 인원, 「엔진 대조 N개 중 N개 일치 · 검산 11개 중 K개 통과」, 확인할 것이 나온다. 종료 코드는 0 모두 통과, 1 확인할 검산이 있음, 2 입력을 읽지 못함이다. 2 일 때는 메시지에 시트 · 행 · 열이 나온다.

## 3. 산출물

| 파일 | 내용 |
|---|---|
| `2 조서/통합고용_검증.xlsx` | 검증 워크북. 숫자 칸은 모두 수식이다 |
| `_색인/통합고용.json` | 인원 · 금액 · 검산 결과 · 확인할 것 |
| `_색인/신고건.json` 의 `상시근로자` | 해당 · 직전 상시근로자 인원. 다른 도구가 이어 읽을 수 있게 남긴다 |

워크북 시트는 계산 순서대로다.

| 시트 | 내용 |
|---|---|
| 목록 | 결과, 검산 11개, 확인할 것. 여기부터 본다 |
| 0기준 | 회사 정보, 계산 방식, 1인당 공제금액 |
| 1사원명부 · 2급여대장 | 입력과 사람별 판정(제외 사유, 청년 제외시점) |
| 3판정_해당 · 직전 · 직전전 | 사람마다 달마다 급여 · 근무개월 · 청년등 |
| 4인원 | 과세연도별 상시 · 청년등 인원 |
| 5공제액 | 1 · 2 · 3차 연도와 추가공제 |
| 6서식10의9 · 7서식10의10 | 법정 서식 두 장 |
| 8엔진대조 | 파이썬 엔진 값과 수식 값 |

값을 바꾸려면 입력 파일을 고치고 다시 돌린다. 워크북의 노란 칸을 직접 고쳐도 수식은 다시 계산되지만 엔진 대조와 명세서의 사람 줄 구성은 옛 값으로 남는다. 워크북이 엑셀에 열려 있으면 쓰지 못하니 닫고 돌린다. 엔진 대조와 검산 결과를 화면에 내려면 엑셀과 `pip install pywin32` 가 있어야 한다. 없으면 그 줄을 건너뛰고, 워크북을 엑셀로 열면 「목록」 시트에서 같은 결과를 본다.

## 4. 회계사가 정할 것

- **청년 간주**: 2025년 1월 1일 이후 계약만 대상이다. 계약 체결일에 34세 이하였던 정규직을 2025년 계약은 3년(일반기업 2년), 2026년 이후 계약은 4년(3년) 동안 청년등으로 센다. 2024년 이전 계약은 간주가 없다. 적용이 기본값이고 회사 시트 「청년 간주 적용」 N 으로 끈다.
- **급여가 없는 달**: 급여대장이 있는 과세연도는 그 달 급여가 있어야 근무개월로 센다. 무급휴직처럼 근로관계가 이어진 달까지 넣으려면 회사 시트 「급여 없는 달 포함」 Y.
- **사원명부에 적은 값**: 임원 · 친족 · 계약기간 · 고용형태 · 장애 등은 적힌 대로 쓴다. 엔진은 그 값이 맞는지 보지 않는다.
- **계산하지 않는 것**: 인원이 줄었을 때의 추가 납부세액, 정규직 전환 추가공제, 합병 · 분할 · 승계 인원.

## 5. 자주 막히는 곳

| 증상 | 볼 곳 |
|---|---|
| 「급여대장 사번이 모두 사원명부에 있음」 이 확인 | 급여대장과 사원명부의 사번이 다르다. 더존은 달에 따라 성명 표기가 달라지니 성명 말고 사번으로 잇는다 |
| 「월말 재직인데 급여가 없는 달」 이 확인 | 그 달은 근무개월에서 빠졌다. 입사일이 실제보다 이르거나 급여대장이 빠졌거나 무급휴직이다 |
| 직전 인원 출처가 「없음」 | 직전 과세연도 급여대장도 전기 신고 인원도 없다. 1차 연도 공제를 계산하지 않는다 |
| 전기 신고서와 인원이 다르다 | 전기에 쓴 제외 사유와 청년 구분을 전기 명세서와 맞춰 본다. 전기 신고서를 그대로 다시 내려면 「청년 간주 적용」 N |
