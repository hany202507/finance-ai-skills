# 재무 AI 면접점검, AI와 함께 준비하는 가이드

AI와 대화하며 면접을 준비하는 방법입니다. 「재무 AI 면접 대비 체크리스트」로 준비할 것을 정하고, 「재무 AI 면접 채점기준」으로 AI가 내 답에 1~4점을 매기게 합니다. Claude, ChatGPT 등 어느 AI든 됩니다. 아래 상자 안의 글을 그대로 복사해 보내고, 대괄호 안은 내 내용으로 바꿉니다.

## 시작 전에

**준비물**
- 대비 체크리스트와 채점기준 전문(대화창에 붙여넣기)
- 지원 회사의 공개 자료: 공시, 재무제표, 최근 뉴스
- 내 사례를 적은 메모. 문장이 거칠어도 됩니다

**AI에게 넣지 않는 것**
- 전 직장·인턴 회사의 내부 자료. 사례를 설명할 때는 숫자와 이름을 지우고 방식만 적습니다
- 회사가 허용하지 않은 AI 도구에 업무 자료를 넣지 않습니다

**지킬 것**
- AI는 내가 말한 내용만 알고 사실인지 확인하지 못합니다. 점수는 검증된 평가가 아닌 참고이고, 최종 판단은 내가 합니다
- AI가 만들어 준 숫자나 사례를 내 경험처럼 말하지 않습니다. 면접관이 ③에서 "그 자료는 실제 데이터였나요"라고 물으면 바로 드러납니다
- 대화 기록을 지우지 않습니다. 무엇을 물었고 어디서 방향을 바꿨는지가 ④의 증거입니다

## 1단계. 대화 설정

새 대화를 열고 먼저 보냅니다.

```
당신은 재무 면접 코치입니다. 지금부터 제가 붙여 넣는 「재무 AI 면접 대비 체크리스트」와 「재무 AI 면접 채점기준」으로 저를 점검합니다.

규칙
1. 한 번에 질문 하나만 합니다.
2. 제 답에 숫자가 없으면 숫자를 물어봅니다. 제가 모르는 숫자를 대신 만들어 주지 않습니다.
3. 점수는 채점기준의 1~4점 문장을 그대로 인용해 매기고, 왜 그 점수인지 한 줄로 말합니다.
4. 제 답을 더 그럴듯하게 고쳐 쓰지 않습니다. 부족한 부분만 짚습니다.
5. 모르는 것은 모른다고 말합니다.

준비되면 "두 문서를 붙여 주세요"라고 답하세요.
```

AI가 요청하면 두 문서를 붙여넣습니다.

## 2단계. 회사 읽기 (①)

공개 자료를 붙이고 체크리스트의 「면접 전, 회사 읽기」 순서대로 정리시킵니다.

```
지원하려는 회사는 [회사명]입니다. 아래에 공개된 공시, 재무제표, 최근 뉴스를 붙입니다.

[붙여넣기]

체크리스트의 「면접 전, 회사 읽기」 순서로 정리해 주세요.
1. 무엇으로 버는지
2. 지금 무엇을 미는지
3. 그래서 재무 일이 어떻게 생겼을지
4. 힘들 만한 곳 가설 두세 개
5. 각 가설을 확인할 지표와, 이 자료에서 찾은 근거

자료에 없는 내용은 추정이라고 표시하고, 근거가 없으면 비워 두세요.
```

정리된 가설은 AI가 맞다고 한 것으로 쓰지 않고, 공시 원문에서 내가 직접 확인합니다. 확인한 뒤 이어서 보냅니다.

```
면접관 역할을 해 주세요. "저희 재무에 어떤 문제가 있을 것 같나요."라고 물어 주세요. 제 답을 듣고 ① 맥락 설정력 점수를 매겨 주세요.
```

답할 때는 지표보다 추론을 먼저 말하고 지표를 근거로 댑니다. 3점 미만이면 같은 질문으로 한 번 더 답합니다.

## 3단계. 내 사례 점검 (②③④)

```
제 사례는 [사례 이름]입니다. 설명은 다음과 같습니다.

[사례 메모]

채점기준의 ② ③ ④ 항목으로 인터뷰해 주세요. 항목마다 점수 근거가 될 질문을 하나씩 하세요. 마지막에 아래 표로 정리해 주세요.
항목 | 지금 점수 | 비어 있는 것 | 1점 올리려면 필요한 것
```

표에서 비어 있는 것이 가장 많은 항목이 먼저 고칠 곳입니다. ③이 1점이면 다른 항목보다 먼저 고칩니다.

## 4단계. 모의 면접

한 항목씩 합니다. ③을 먼저 권합니다.

```
면접관 역할을 해 주세요. 항목 [③ 검증력]으로 모의 면접을 합니다. 체크리스트의 질문으로 시작하고, 제 답에 따라 따라오는 질문(예: "그 자료는 실제 데이터였나요")까지 파고드세요. 질문은 최대 5개입니다. 끝나면 채점기준으로 점수와 근거를 말하고, 제가 얼버무린 문장을 그대로 인용해 알려 주세요.
```

답은 외우지 않고 사례 메모를 보며 말합니다. 같은 사례를 다른 방향에서 묻도록 항목을 바꿔 가며 반복합니다.

## 5단계. 약한 항목 고치기

```
점수가 낮은 항목은 [③]입니다. 채점기준에서 한 점 올리려면 제가 실제로 해야 할 일을 하루 안에 할 수 있는 크기로 쪼개 주세요. 제가 구할 수 있는 공개 자료로만 하세요.
```

고친 뒤에는 새 대화에서 4단계를 다시 합니다. 같은 대화에서 하면 AI가 이전 답을 기억해 점수가 후하게 나옵니다.

## 6단계. 마지막 확인

```
지금까지 제 답을 이어 붙여서 "AI로 일을 잘하고, 결과에 책임지는 사람"으로 들리는지 판단해 주세요. 들리지 않으면 어느 항목의 어떤 답이 빠졌는지 말해 주세요.
```

| 1 | 대화 설정, 체크리스트와 채점기준 붙여넣기 | |
