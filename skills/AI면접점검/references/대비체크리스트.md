# 재무 AI 면접 대비 체크리스트

재무 면접에서 AI를 일에 쓴 경험을 어떻게 말할지 준비하는 체크리스트입니다.

## 면접관에게 남길 한 문장

> **AI로 일을 잘하고, 결과에 책임지는 사람**

면접관이 "AI를 어떻게 쓰셨어요"라고 직접 묻지 않더라도, 성장 경험, 어려움을 극복한 경험, 실수한 경험 같은 늘 나오는 질문에 내가 만든 것으로 답할 수 있습니다. 아래 네 항목은 그 답을 준비하는 목록입니다.

| 항목 | 면접관이 확인하는 것 |
|---|---|
| ① 맥락 설정력 | 우리 일을 이해하고 할 일을 스스로 찾을 수 있나 |
| ② 분해력 | 일을 나눠 AI를 적용하고, 여러 도구를 묶어 구조화할 수 있나 |
| ③ 검증력 | 목표와 결과를 비교해 개선할 수 있나 |
| ④ 지속력 | 부족한 점을 메우며 계속 운영하고 해결할 수 있나 |

## ① 맥락 설정력

**나오는 질문:** "저희 재무에 어떤 문제가 있을 것 같나요." / "입사하면 처음에 무엇을 하겠습니까." / "성장했다고 느낀 경험을 말씀해 주세요."

회사 상황은 공시·재무제표·뉴스로 면접 전에 알 수 있습니다. 면접관에게 무엇을 하면 되는지 되묻지 않고, 자료로 파악한 내용을 말합니다.

- [ ] 회사가 무엇으로 버는지 한 문장으로 말할 수 있다
- [ ] 그래서 재무 일이 어떻게 생겼을지, 어디가 힘들지 가설이 두세 개 있다
- [ ] 가설마다 확인할 지표를 찾아 봤다
- [ ] 입사 후 첫 할 일을 되묻지 않고 순서로 말할 수 있다
- [ ] 원래 모르던 분야를 익혀 만든 경험이 있고, 처음 생각이 틀렸던 순간을 댈 수 있다

이렇게 말합니다. "채널이 여섯 개라 정산 대사가 매달 일이겠습니다. 매출채권도 3년째 늘고 있습니다."

입사 첫 주는 이 순서로 답합니다. 지난 3개월 자료를 AI와 읽어 매달 바뀌는 것을 파악하고, 시간이 가장 많이 드는 건을 찾고, 지난달 것을 작게 다시 만들어 어긋나는 곳을 확인하고, 할 일 목록을 만들어 우선순위를 정합니다.

## ② 분해력

**나오는 질문:** "어려움을 극복한 경험을 말씀해 주세요." / "여럿이 한 일에서 본인 역할은 무엇이었나요."

어려움을 통째로 안 되던 것으로 놓고, 어떻게 쪼개 풀었는지로 답합니다.

- [ ] 일을 단계로 나눴고, 왜 그렇게 나눴는지 말할 수 있다
- [ ] 단계마다 규칙, AI, 사람 중 누가 맡는지 정했다
- [ ] 도구를 둘 이상 썼다면 결과를 어떻게 넘겼는지 말할 수 있다
- [ ] 사람이 확인하는 단계가 있고 그 이유를 말할 수 있다
- [ ] 애매한 건을 어떻게 처리할지 정해 두었다
- [ ] 단계 구분이 설계서·스킬·체크리스트 같은 파일로 남아 있어 남이 다시 돌릴 수 있다

| 맡기는 곳 | 기준 | 예 |
|---|---|---|
| 규칙 | 판단이 필요 없어 코드·수식으로 박는다 | 계정과목 매핑, 반올림 |
| AI | 매번 다르지만 틀려도 되돌릴 수 있다 | 적요 분류, 초안, 이상치 후보 |
| 사람 | 틀리면 회사 바깥에 영향이 간다 | 최종 승인, 예외 방침, 숫자 확정 |

재무에서는 사람이 확정하는 단계가 남아 있어야 합니다.

## ③ 검증력

**나오는 질문:** "실수한 경험과 알아챈 방법을 말씀해 주세요." / "꼼꼼하다는 걸 보여줄 사례가 있나요."

가장 먼저 준비할 항목입니다. "꼼꼼한 편입니다"는 증거가 없으니 숫자로 답합니다.

- [ ] 목표를 숫자로 먼저 정했다. 건당 몇 분, 마감 며칠, 오류 몇 건 이내
- [ ] 몇 건을 돌렸고 몇 건이 안 맞았는지, 안 맞은 것이 몇 종류였는지 셌다
- [ ] 쓴 자료는 내가 만든 것이 아닌 실제 자료다
- [ ] 안 맞은 것을 고쳐서 다시 돌렸다
- [ ] 깨질 경우를 미리 뽑아 하나씩 돌려봤다

반드시 따라오는 질문이 있습니다. **"그 자료는 실제 데이터였나요, 만드신 건가요."**

정산·결산·급여는 한 달치 자료만 있으면 끝까지 돌려볼 수 있고, 맞았는지가 1원 단위로 확정됩니다. 실제 자료는 DART 공시, 국가통계포털, 지자체 계약 내역, 본인 계좌·카드 내역, 동아리 회비, 가족 사업체 장부에서 구할 수 있습니다. 규모는 상관없고 맞춰볼 답이 이미 있는지만 보면 됩니다.

## ④ 지속력

**나오는 질문:** "가장 오래 붙잡고 한 일이 무엇인가요." / "끝까지 해낸 경험을 말씀해 주세요."

끝까지를 지금 기준으로 말합니다. 재료는 손댄 횟수와, 운영하다 부족해서 메운 것입니다.

- [ ] 지금도 쓰고 있다. 혼자 써도 된다
- [ ] 만든 뒤 몇 번 고쳤는지, 그중 한 번은 무엇을 왜 고쳤는지 말할 수 있다
- [ ] 운영 중 문제가 생겨 해결한 일이 있다
- [ ] 남이 써본 적이 있고, 그때 나온 말로 고친 적이 있다
- [ ] 아직 부족한 점과 다음에 고칠 것을 말할 수 있다
- [ ] 멈췄다면 왜 멈췄는지 안다. 크레딧, 자료 형식 변경, 한 번 쓰고 말 물건이었다는 것도 답이 됩니다

따라오는 질문은 **"마지막으로 손댄 게 언제예요, 왜 손댔어요."** 안 쓰면서 쓰고 있다고 하면 마지막 수정일로 드러납니다.

## 사례 고르기

네 항목에 답하려면 만든 것 하나를 끝까지 설명할 수 있어야 합니다. 여러 개를 얕게 말하지 않습니다.

내 사례: ______________________

- [ ] 끝까지 갔다. 작아도 됩니다
- [ ] 막힌 적이 있다. 너무 매끄러운 사례는 약합니다
- [ ] 지금도 쓴다. 혼자 써도 됩니다
- [ ] 원래 모르던 분야였다. 재무 경력이 없으면 가장 중요한 조건입니다

주제가 재무일 필요는 없습니다. 다만 "이 방식을 결산에 옮기면 어디부터 손대겠습니까"에는 답할 수 있어야 합니다.

들고 갈 게 없으면 열흘이면 하나 만듭니다.

| 일 | 할 것 |
|---|---|
| 1 | 모르는 분야를 하나 고릅니다 |
| 2 | 정답이 확정된 자료를 한 달치 구합니다 |
| 3~5 | 단계 세 개로 작게 만들고, 하나는 사람이 확인하게 둡니다 |
| 6 | 돌려서 몇 건이 안 맞는지 셉니다 |
| 7~8 | 고쳐서 다시 돌리고 무엇이 왜 틀렸는지 적습니다 |
| 9~10 | 한 명에게 써보게 하고 요청 하나를 반영합니다 |

튜토리얼은 그대로 따라가지 않습니다. 막히지 않게 만들어져 있어서 말할 재료가 안 생깁니다.

## 면접 전, 회사 읽기

공시 항목을 훑는 것만으로는 사전조사가 아닙니다. 회사가 무엇으로 돈을 벌고 어디로 가는지 읽고 재무 일이 어떻게 생겼을지 추론해야 합니다. 지표는 그 추론을 확인하는 데 씁니다. 추론을 먼저 말하고 지표를 근거로 댑니다.

순서대로 한 줄씩 적습니다.

1. 무엇으로 버나(누가 사고, 언제 돈이 들어오고, 원가는 무엇인가): ______
2. 지금 무엇을 미나(외형, 마진, 회수): ______
3. 그러면 재무 일이 어떻게 생겼겠나: ______
4. 어디가 힘들지 가설 두세 개: ______
5. 가설을 확인해줄 지표: ______

| 이렇게 번다면 | 재무 일과 힘든 곳 |
|---|---|
| B2B 제조·수주 | 수주 → 생산 → 납품 → 검수 → 청구. 원가 배부 기준, 검수 지연에 걸린 매출 인식 |
| 이커머스·플랫폼 | 채널·PG마다 정산 주기와 수수료가 다름. 정산 대사, 채널 수만큼 늘어나는 예외 |
| 구독·SaaS | 선수금을 기간으로 나눠 인식, 해지·환불 상시. 이연수익, MRR과 회계 매출의 차이 |
| 유통·리테일 | 재고가 돈, 판촉비가 여러 곳에 걸림. 재고 실사와 평가, 판촉비 귀속 시점 |
| 용역·프로젝트 | 투입 시간이 곧 원가, 청구는 뒤에 옴. 진행률 산정, 미청구 채권 |

| 내 가설 | 확인하는 곳 (상장사는 DART 30분) |
|---|---|
| 정산·대사가 복잡할 것 | 매출 구성, 거래처 집중도, 특수관계자 거래 |
| 원가·수익인식이 어려울 것 | 핵심감사사항(KAM) |
| 회수가 안 될 것 | 매출채권 회전일수 3년 추이, 대손 설정률 |
| 재고가 무거울 것 | 재고자산 회전일수, 평가손실 |
| 결산·감사 압박이 클 것 | 감사의견, 내부회계 의견, 최근 증자·합병 공시 |
| (비상장) 조직이 커지는 중일 것 | 국민연금 가입자 추이, 채용공고에 적힌 시스템 이름 |

면접에서는 이렇게 말합니다. "채널이 여섯 개면 정산 주기가 달라 대사가 매달 일이겠습니다. KAM에도 수익인식이 있더라고요." 회사 내부를 모르는 상태의 추론이므로 단정하지 않고 "…이지 않으신가요"로 닫습니다. 면접관이 정정하거나 보태는 내용이 ①의 재료가 됩니다.
