# 재무 AI 면접 채점기준

「재무 AI 면접 대비 체크리스트」의 네 항목을 1~4점으로 매기는 기준입니다. 내 답이나 AI와 나눈 모의 면접을 이 기준으로 점검합니다.

## 쓰는 법

- 항목마다 답에 해당하는 가장 높은 점수를 매깁니다.
- 점수는 합산하지 않습니다. 항목별로 어디가 비었는지 보는 용도입니다.
- ③ 검증력을 가장 무겁게 봅니다. 다른 항목이 높아도 ③이 1점이면 다른 항목보다 먼저 고칩니다.

## ① 맥락 설정력: 자료로 회사와 일을 파악하고 할 일을 찾는가

| 점수 | 기준 |
|---|---|
| 1 | "알려주시는 대로 하겠습니다". 무엇을 할지 되묻는다 |
| 2 | 공시·뉴스를 읽었지만 사실을 나열한다. "매출이 늘었고 KAM이 수익인식이더라고요." |
| 3 | 자료를 보고 이 회사 재무에서 어디가 힘들지를 말한다. 예: "채널이 여섯 개라 정산 대사가 매달 일이겠습니다. 매출채권도 3년째 늘고 있습니다." |
| 4 | 3점에 더해, 입사하면 어떻게 할지 방법을 순서로 말한다. 회사가 해놓은 일(지난 결산 파일, 기존 보고서)을 AI로 분석해 부족한 곳을 찾고 우선순위를 정하는 순서다. 예: "입사하면 지난 3개월 결산 파일을 AI와 읽어서 시간이 가장 많이 드는 건을 찾고, 그것부터 자동화하겠습니다." |

## ② 분해력: 일을 나눠 AI를 적용하고, 여러 도구를 묶어 구조화하는가

| 점수 | 기준 |
|---|---|
| 1 | "프롬프트를 잘 써서 한 번에 나오게 했습니다" |
| 2 | 단계로 나눴지만 이유를 말하지 못한다. 도구는 하나다 |
| 3 | 단계마다 규칙 · AI · 사람을 가르고 이유를 댄다. 도구 둘 이상을 이어 썼다 |
| 4 | 단계 구분이 설계서·스킬·체크리스트 파일로 남아 남이 다시 돌릴 수 있고, 애매한 건의 처리 방침이 정해져 있다 |

## ③ 검증력: 목표와 결과를 비교해 개선하는가

| 점수 | 기준 |
|---|---|
| 1 | "확인했습니다." "잘 나오는 걸 봤습니다." |
| 2 | 결과를 숫자로 말한다. "150건 중 14건이 안 맞았고 종류는 셋이었습니다." |
| 3 | 목표와 결과를 내가 지어내지 않은 실제 자료로 비교했고, 차이를 고쳐 다시 돌렸다 |
| 4 | 깨질 경우를 미리 뽑아 하나씩 돌려봤다 |

## ④ 지속력: 부족한 점을 메우며 계속 운영하고 해결하는가

| 점수 | 기준 |
|---|---|
| 1 | 만들고 안 쓴다. 제출 이후 열어보지 않았다 |
| 2 | 가끔 쓰지만 만든 뒤로 손댄 적이 없다 |
| 3 | 계속 쓰고, 부족한 점을 찾아 메웠고, 무엇을 왜 고쳤는지 말할 수 있다 |
| 4 | 남이 써보고 한 말로 고쳤거나 마감 한 주기를 통과시키며 고쳤고, 운영 중 생긴 문제를 해결한 이력이 있다 |

## 4D와의 대응

네 항목은 Anthropic의 AI Fluency 4D(Dakan·Feller, CC BY-NC-SA 4.0)를 재무에 맞게 옮긴 것입니다. 4D에는 점수 기준이 없어서 1~4점은 직접 붙였습니다. Delegation은 목표 파악과 일 나누기 두 쪽으로 나눠 ①과 ②에 배치했습니다.

| 항목 | AI Fluency 4D |
|---|---|
| ① 맥락 설정력 | Delegation (목표 파악) |
| ② 분해력 | Delegation (일 나누기) + Description |
| ③ 검증력 | Discernment |
| ④ 지속력 | Diligence |

<sub>이 기준은 제안하는 기준입니다. 회사마다 평가 방식이 다르며 채용 결과를 보장하지 않습니다.</sub>
