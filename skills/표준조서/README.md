# 표준조서

시산표 · 전기 재무제표 · 분개장 · 매출채권 명세가 든 자료 폴더 하나로 정산표와 계정별 표준조서를 엑셀로 만듭니다. 전기조서가 없는 감사 건이나, 감사반 조서를 한 가지 양식으로 맞추고 싶을 때 씁니다. Claude 가 자료를 먼저 읽고 회사 이름 · 결산일 · 수행중요성 · 표본 위험 수준처럼 감사인이 정할 것만 묻습니다.

- **정산표.** `8100B_정산표.xlsx` 한 파일에 시트가 셋입니다. 계정별(코드 · 계정명 · 영역 · 전기 · 당기 회사제시 · 수정 · 최종 · 증감), 재무제표(표시과목 합계, 전기 열은 전기 재무제표, 자산 − 부채 − 자본 검산), 수정 제안(감사인이 적는 줄, 다시 만들어도 남음).
- **표준조서.** 정산표에 잔액이 있는 영역마다 한 파일입니다. 표지(실증절차 · 경영진 주장 · 해당 여부) · Lead(계정 블록 · 증감 · 정산표 대사 · Audit memo · 발견사항 · 결론) · 절차 시트 · 주석 · 정산표 시트로 되어 있습니다. 조서 파일끼리 외부 연결 수식이 없고, 조서마다 들어 있는 정산표 시트를 엔진이 다시 씌웁니다.
- **매출채권(4000C).** 거래처별 잔액 명세, 채권 조회 표본(금액 단위 표본, 수행중요성 · 위험 수준을 감사인이 줌), 대체적 절차(기말 후 입금), 연령 구간을 엔진이 채웁니다. 감사인이 적은 칸과 수식은 다시 씌워도 같은 거래처 줄에 남습니다.
- **자료가 바뀌면.** 자료 폴더에 파일을 넣거나 바꾸고 `refresh` 를 돌리면 정산표와 조서 숫자가 바뀝니다. Lead 의 새 계정은 예비 줄에 나타나고, 사라진 계정은 「정산표에 없음」 으로 남습니다.
- **AI 칸.** 계정의 주요 내용 · 증감 분석 · 이슈 · 위험 대응 · 해당 여부 제안을 Claude 가 연보라 칸에 쓰고, 감사인이 확인 열에 O 를 적습니다. 금액이 든 글은 엔진이 받지 않습니다.
- **기간.** 기간은 사업연도 시작일부터 셉니다. 중간감사는 조서 머리에 「사업연도 시작 ~ 기준일」 을 적고, 손익 개월 수가 전기와 다르면 증감을 내지 않습니다. 작년 표준조서를 올해로 옮길 수 있습니다(`roll`).

## 시험해 보기

가상 회사 가온정밀(가상)의 2025년 자료가 `examples/모의자료/` 에 있습니다. 폴더를 다른 곳에 복사한 뒤 Claude 에게 「이 폴더로 표준조서 만들어 줘」 라고 하면 자료를 읽고 묻습니다. 「가온정밀(가상), 2025-12-31 기말감사, 수행중요성 6천만 원, 위험 수준 보통」 이라고 답하면 표준조서 16개와 정산표가 나옵니다.

## 한계

- 수행중요성 · 위험 수준 · 절차 해당 여부 · 결과 · 결론 · 서명은 엔진이 정하지 않습니다. 감사인이 조서에 적습니다.
- 절차 시트 표를 엔진이 채우는 것은 매출채권(4000C)뿐입니다. 다른 영역의 절차 시트는 감사인이 회사 명세를 붙여 씁니다.
- 한공회 감사조서서식 문장은 싣지 않습니다. 매출채권이 아닌 영역의 표지에는 서식의 절차 번호만 있습니다.
- 조회서 발송 · 회신 대장은 없습니다. 채권 조회 표의 발송일 · 회신 잔액은 감사인이 적습니다.
- 엑셀(xlsx · xlsm)과 CSV 만 읽습니다. PDF · 스캔 자료는 읽지 않습니다.
