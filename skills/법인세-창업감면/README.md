# 창업중소기업 세액감면 사용법 (ctax startup)

입력 엑셀 한 파일(회사 시트 · 연도별 시트)을 넣으면 창업중소기업 등에 대한 세액감면(조세특례제한법 제6조)을 판정하고 감면세액을 계산한다. 검증 엑셀과 세액감면(면제)신청서(조특 별지 제2호서식) PDF 가 나온다. 판정 · 감면율 · 감면세액을 엑셀 수식으로 다시 계산해 파이썬 엔진 값과 55개 칸을 대조한다.

Claude Code 에서 쓰는 절차는 [SKILL.md](SKILL.md) 에 있다. 이 폴더(`skills/법인세-창업감면/`)를 `~/.claude/skills/` 에 두면 「창업감면 계산해 줘」 라고 하면 스킬이 SKILL.md 순서대로 계산하고, 받은 자료를 입력 양식으로 옮기는 일도 스킬이 한다.

## 0. 먼저 샘플로 돌려 보기

합성 회사(샘플창업, 실제 회사와 무관)가 들어 있다. Claude Code 에서는 「샘플로 창업감면 돌려 줘」 라고 하면 스킬이 아래 두 명령을 돌린다. 직접 돌릴 때는 이 폴더의 `scripts/` 에서 아래 두 줄을 친다. 신고 건 폴더는 아무 곳이나 되고 이름만 `<회사>/2025 법인세` 꼴로 한다.

```
python -m ctax startup "C:/temp/샘플창업/2025 법인세" --sample
python -m ctax startup "C:/temp/샘플창업/2025 법인세"
```

첫 줄이 입력 파일을 만들고 둘째 줄이 검증 엑셀과 신청서 PDF 를 만든다. 아래 값이 나오면 설치가 된 것이다.

| 항목 | 기대값 |
|---|---|
| 판정 | 감면 대상 · 2025이전\|과밀외 · 일반 · 2차 연도(감면 끝 2028-12-31) |
| 감면율 · 추가감면율 | 50% · 12%(상시근로자 12 → 15, 종전 제7항 3 ÷ 12 × 50/100) |
| 11O(영문 O, 최저한세 적용제외) | 6,720,000 (산출세액 56,000,000 × 12%) |
| 111(최저한세 적용대상) | 대상 28,000,000 → 최저한세로 2,000,000 배제 → 26,000,000 |
| 창업중소기업 세액감면 합계 | 32,720,000 |
| 화면 셋째 줄 | 엔진 대조 55개 중 55개 일치 · 검산 8개 중 8개 통과 |

샘플은 2023-03-02 수도권 밖에서 제조업으로 창업한 일반(청년 아님) 법인이다. 2023 결손, 2024 처음 소득이라 2025 과세연도가 2차 연도다. 산출세액 5,600만원 · 과세표준 4억원 · 최저한세 2,800만원이고, 회사 시트 「먼저 적용할 다른 최저한세 대상 감면 · 공제」 200만원을 먼저 빼서 111 줄이 200만원 깎인다.

입력 하나를 바꿔 다시 돌리면 결과가 아래처럼 바뀐다.

1. 「대표자 생년월일」 을 1995-01-01 로: 청년창업, 감면율 100%, 전액 11O(최저한세 적용제외), 추가감면 없음.
2. 「창업 지역」 을 수도권과밀억제권역으로: 감면율 0(일반 · 과밀), 합계 0.
3. 「수입금액」 을 70,000,000 으로: 제6항 소규모, 감면율 100%.
4. 「법인전환」 을 Y 로: 창업에 해당하지 않아 감면세액 0.

## 1. 입력: 준비할 자료와 넣는 곳

입력은 `<회사>/<연도> 법인세/00 받은자료/창업감면/창업감면_입력.xlsx` 한 파일이다. 빈 양식은 아래 명령이 만든다.

```
python -m ctax startup "<회사>/2025 법인세" --template
```

| 시트 | 넣는 것 |
|---|---|
| 회사 | 한 항목 한 줄. B 열에 값, C 열은 설명, D 열은 받는 곳. 「(필수)」 가 붙은 항목이 비면 끝 코드 2 로 멈춘다 |
| 연도별 | 창업한 과세연도부터 해당 과세연도까지 한 줄씩. 과세연도 시작일 · 종료일 · 감면사업 소득금액(결손이면 음수) · 수입금액 · 상시근로자 수 |
| 정의 | 항목마다 형식 · 비었을 때 · 받는 곳 · 설명. 엔진은 읽지 않는다. 같은 표가 [references/입력정의.md](references/입력정의.md) 에 있다 |

| 자료 | 받는 곳 | 들어가는 항목 |
|---|---|---|
| 사업자등록증(개업연월일 · 업태 · 종목 · 사업장 주소) | 회사 | 창업일 · 업종 · 창업 지역 · 신성장 서비스업 |
| 법인등기부(사업연도 · 본점 · 대표이사 · 이전 · 지점) | 회사, 대법원 인터넷등기소 | 과세연도 · 창업 지역 · 대표자 생년월일 · 이전 · 지점 |
| 주주명부 · 주식등변동상황명세서, 대표자 병적증명서 | 회사 · 대표자 | 대표자 최대주주 · 청년 요건 상실일 · 병역 개월 수 |
| 설립 경위(합병 · 사업양수 · 법인전환 · 자산 인수 여부와 금액) | 회사 | 창업 아닌 사유 일곱 줄 |
| 창업 뒤 과세연도별 세무조정계산서(3호) · 손익계산서 | 전기 신고서 | 연도별 시트 |
| 당기 산출세액 · 과세표준 · 감면소득, 최저한세조정계산서(4호) | 당기 세무조정 | 회사 시트 금액 줄 |
| 수입금액(손익계산서 매출액) | 당기 결산 | 수입금액 |
| 상시근로자 수(해당 · 직전) | 급여대장 또는 법인세-통합고용 결과 | 회사 · 연도별 시트 |
| 함께 받으려는 공제감면(통합고용 · 고용증대 · 통합투자 · 중소기업특별세액감면) | 공제감면세액계산서 | 회사 시트 「통합고용 · 고용증대 세액공제」 · 「제127조 제4항 세액공제」 · 「중소기업특별세액감면」 · 「적용 선택」 |

필수는 회사 시트의 과세연도 시작일 · 종료일, 창업일, 업종, 창업 지역, 산출세액, 과세표준, 감면소득, 수입금액과 연도별 시트다. 나머지는 비우면 「해당 없음」 으로 본다(Y · N 칸은 N, 중소기업만 기본 Y). 주민등록번호는 넣지 않는다.

비워 두면 감면액이 달라지는 항목은 둘이다. 창업 아닌 사유(승계 · 법인전환 · 재개업 · 확장)를 비우면 창업으로 보아 감면이 커질 수 있고, 대표자 생년월일 · 최대주주를 비우면 청년창업이 아닌 것으로 보아 감면이 작아질 수 있다. 모르면 회사에 먼저 묻는다.

## 2. 돌리기

```
python -m ctax startup "<회사>/2025 법인세"
```

| 옵션 | 하는 일 |
|---|---|
| `--template` · `--sample` | 빈 양식 · 합성 회사 입력을 만들고 끝낸다 |
| `--input <파일>` | 정해진 위치 대신 그 파일을 읽는다 |
| `--no-excel` | 엑셀 재계산을 건너뛴다 |
| `--keep` | `_색인/신고건.json` 「창업감면」 을 쓰지 않는다 |

엔진 대조와 검산 결과를 화면에 내려면 엑셀과 pywin32(`pip install pywin32`)가 있어야 한다. 없으면 엑셀 재계산을 건너뛴다. 이때는 워크북을 엑셀로 열어 「목록」 시트에서 같은 결과를 본다. 워크북이 엑셀에 열려 있으면 쓰지 못하니 닫고 돌린다.

## 3. 결과물

| 파일 | 내용 |
|---|---|
| `2 조서/창업감면_검증.xlsx` | 검증 워크북. 판정 · 감면율 · 금액이 모두 수식이다 |
| `2 조서/창업감면_법정서식.pdf` | 법제처 별지 제2호서식 원본 1쪽(11O · 111 줄)과 3쪽(1A4 합계) 위에 값만 얹은 신고용 서식. 사업자등록번호 · 대표자 · 생년월일 · 주소 · 날짜 · 서명은 사람이 적는다 |
| `_색인/창업감면.json` | 판정 · 줄별 금액 · 검산 · 확인 줄 |
| `_색인/신고건.json` 의 「창업감면」 | 111 대상세액 등. 다른 도구가 이어 읽게 남긴다 |

| 시트 | 내용 |
|---|---|
| 목록 | 결과, 검산 8개, 확인할 것. 여기부터 본다 |
| 0입력 · 0기준 | 입력 값과 법령 값(감면율 표 · 기한 · 나이 · 한도), 칸마다 근거 조문 |
| 1연도별 | 과세연도별 소득 · 수입금액 · 상시근로자 |
| 2계산 | 창업 해당 → 감면기간 → 청년 → 지역 → 소규모 · 신성장 → 감면율 → 추가감면 → 감면세액 → 최저한세 · 한도 · 중복 |
| 3신청서 | 별지 제2호서식 11O · 111 · 1A4 줄의 ⑥ ~ ⑨ |
| 4엔진대조 | 파이썬 엔진 값과 수식 값 55개 |

화면 첫 줄은 합계와 11O · 111, 둘째 줄은 판정 · 감면율 · 추가감면율 · 차수, 셋째 줄은 엔진 대조와 검산, 그 아래 `확인:` 줄은 회계사가 볼 판단이다. 끝 코드는 0 모두 통과, 1 확인할 검산이나 불일치가 있음, 2 입력을 읽지 못함이다. 2 일 때는 메시지에 시트 · 행 · 항목이 나온다.

| 검산 | 어긋나면 볼 곳 |
|---|---|
| 신청서 1A4 ⑨ = 2계산 합계 | 3신청서 수식 |
| 11O · 111 ⑨ ≤ ⑧ ≤ ⑦ | 최저한세 · 한도 줄 수식 |
| 감면세액 합계 ≤ 감면소득에 대한 세액 | 감면율 · 추가감면율 수식 |
| 감면율 + 추가감면율 ≤ 100% | 0기준 감면율 표 |
| 감면 후 111 이 최저한세를 지킴 | 최저한세 과세표준 · 세율 · 먼저 적용할 금액 |
| 5억원 한도(2025 이후 창업) | 0기준 감면 한도 |
| 엔진 대조 불일치 0건 | 4엔진대조에서 어느 줄인지 본다. 노란 칸을 고쳤으면 입력 파일을 고치고 다시 돌린다 |

## 4. 회계사가 정할 것

- **업종과 창업 아닌 사유**: 감면 업종인지(한국표준산업분류)와 승계 · 법인전환 · 재개업 · 확장인지는 회계사가 정해 입력한다. 엔진은 입력한 대로 판정한다.
- **최초 소득 과세연도**: 엔진은 감면사업 소득금액이 처음 0 보다 큰 해로 본다. 다르게 보면 회사 시트 「최초 소득 과세연도 종료일」 에 넣는다.
- **최저한세 순서**: 111 줄은 최저한세 여지(산출세액 − 최저한세 − 「먼저 적용할 다른 최저한세 대상 감면 · 공제」) 안에서만 받는다. 다른 감면 · 공제를 먼저 적용할지는 납세자가 고른다. 먼저 적용하면 그 금액을 이 항목에 넣고, 비우면 창업감면이 여지를 먼저 쓴다.
- **고용증가 추가감면을 11O 줄에 적는 것, 청년 요건 상실 기업을 소규모 감면에서 빼는 것, 감면율 0 인 기업에 추가감면을 주지 않는 것**은 엔진 규칙이고 회계사 확인 전이다.
