# 법인세-창업감면

계산은 엔진과 엑셀 수식이 한다. AI 가 하는 일은 받은 자료를 입력 양식으로 옮기는 것과, 엔진이 낸 확인 줄을 회계사에게 전하는 것이다. 감면율 · 금액을 손으로 만들지 않는다. 감면 업종인지(한국표준산업분류)와 창업 아닌 사유가 있는지는 회계사가 정하고, 엔진은 입력한 대로 판정한다. 결과는 검토용이고 신고 전 최종 판단은 세무 전문가가 한다.

- 기준과 조문: `scripts/ctax/startup/rules.yaml`(항목마다 근거 조문 · 판 · 등급, 실행은 같은 내용의 `rules.json` 을 읽는다)
- 입력 항목 전체(형식 · 비었을 때 · 받는 곳 · 설명): [references/입력정의.md](references/입력정의.md). 입력 양식의 「정의」 시트와 같은 내용이다
- 사람이 읽는 사용법: [README.md](README.md)

## 돌리는 법

이 스킬 폴더의 `scripts/` 에서 `PYTHONUTF8=1 python -m ctax startup "<회사>/<연도> 법인세" [옵션]` 을 돌린다. 신고 건 폴더는 아무 곳이나 되고 이름만 `<회사>/<연도> 법인세` 꼴로 한다. 사용자는 파이썬을 치지 않고 파일을 주고 말로 시킨다.

| 사용자 | Claude |
|---|---|
| 「샘플로 창업감면 돌려 줘」 | 작업 폴더에 `샘플창업/2025 법인세` 를 잡고 `--sample` 로 입력을 만든 뒤 옵션 없이 한 번 더 돌린다. 기대값은 합계 32,720,000원(11O 6,720,000 · 111 26,000,000), 감면율 50% · 추가감면율 12%, 2차 연도 |
| 입력 엑셀(`창업감면_입력.xlsx` 꼴)을 붙이고 「계산해 줘」 | `<회사>/<연도> 법인세` 를 잡고 `--input "<붙인 파일>"` 로 돌린다 |
| 사업자등록증 · 등기부 · 전기 신고서만 붙임 | `--template` 으로 빈 양식을 만들고 아래 「순서」 2번대로 옮긴 뒤 돌린다 |
| 「빈 양식 줘」 | `--template` 으로 만든 `창업감면_입력.xlsx` 를 파일로 준다. 채운 예시는 `--sample` 이 만든다 |

| 옵션 | 하는 일 |
|---|---|
| `--template` | 빈 입력 양식을 `00 받은자료/창업감면/창업감면_입력.xlsx` 로 만들고 끝낸다(이미 있으면 그대로 둔다) |
| `--sample` | 합성 회사(샘플창업) 입력을 같은 곳에 만들고 끝낸다 |
| `--input <파일>` | 위 위치 대신 그 파일을 입력으로 읽는다 |
| `--no-excel` | 엑셀 재계산을 건너뛴다 |
| `--keep` | `_색인/신고건.json` 「창업감면」 을 쓰지 않는다 |

엑셀이 없는 환경(맥, 리눅스, Claude 앱 실행 환경)에서는 엔진이 「엑셀 재계산을 하지 않았습니다」 를 낸다. 정상이다. 이때는 화면의 감면세액(엔진 값)과 확인 줄을 전하고, 결과 워크북을 엑셀로 열면 수식이 계산되어 「목록」 시트에 검산과 엔진 대조가 나온다고 알려 준다. 결과 파일은 반드시 사용자에게 넘긴다.

## 입력

입력은 `<회사>/<연도> 법인세/00 받은자료/창업감면/창업감면_입력.xlsx` 한 파일이다. 시트 셋이고 엔진은 앞의 둘만 읽는다.

| 시트 | 줄 | 필수 |
|---|---|---|
| 회사 | 한 항목 한 줄(A 항목 · B 값 · C 설명 · D 받는 곳) | 과세연도 시작일 · 종료일, 창업일, 업종, 창업 지역, 산출세액, 과세표준, 감면소득, 수입금액 |
| 연도별 | 창업한 과세연도부터 해당 과세연도까지 한 줄씩 | 과세연도 시작일 · 종료일, 감면사업 소득금액(결손이면 음수), 수입금액. 상시근로자 수는 선택 |
| 정의 | 항목마다 형식 · 비었을 때 · 받는 곳 · 설명 | 읽지 않는다 |

선택 항목(비우면 기본값으로 읽는다): 중소기업(기본 Y), 업종 단서 제외 업종, 대표자 생년월일 · 병역 개월 수 · 최대주주, 청년 요건 상실일, 신성장 서비스업, 창업 아닌 사유 일곱 줄(승계 · 자산 인수 · 인수 자산 비율 · 사업 분리 · 법인전환 · 재개업 · 확장), 이전 · 지점 지역과 날, 최초 소득 과세연도 종료일, 상시근로자 수(해당 · 직전), 최저한세 과세표준 · 세율, 먼저 적용할 다른 최저한세 대상 감면 · 공제, 함께 받으려는 공제감면 셋(통합고용 · 고용증대, 제127조 제4항 세액공제, 중소기업특별세액감면), 적용 선택. Y · N 칸을 비우면 N 이다(중소기업만 기본 Y). 주민등록번호는 넣지 않는다.

자료별로 받는 곳:

| 자료 | 받는 곳 | 들어가는 항목 |
|---|---|---|
| 사업자등록증(개업연월일 · 업태 · 종목 · 사업장 주소) | 회사 | 창업일 · 업종 · 업종 단서 제외 업종 · 창업 지역 · 신성장 서비스업 |
| 법인등기부(사업연도 · 본점 · 대표이사 · 이전 · 지점) | 회사, 대법원 인터넷등기소 | 과세연도 · 창업 지역 · 대표자 생년월일 · 이전 · 지점 지역과 날 |
| 주주명부 · 주식등변동상황명세서 | 회사 | 대표자 최대주주 · 청년 요건 상실일 |
| 대표자 병적증명서 | 대표자 | 대표자 병역 개월 수 |
| 설립 경위(설립 등기 · 정관 · 사업양수도 계약서 · 현물출자 내역 · 개시 당시 자산 명세) | 회사 | 창업 아닌 사유 일곱 줄 |
| 중소기업 등 기준검토표(51호) | 당기 · 전기 신고서 | 중소기업 · 중소기업 아니게 된 날 |
| 창업 뒤 과세연도별 세무조정계산서(3호) · 손익계산서 | 전기 신고서 | 연도별 시트, 최초 소득 과세연도 |
| 당기 3호 · 소득구분계산서(48호) · 최저한세조정계산서(4호) | 당기 세무조정 | 산출세액 · 과세표준 · 감면소득 · 최저한세 줄 |
| 손익계산서 매출액, 수입금액조정명세서(16호) | 당기 결산 | 수입금액 |
| 급여대장 또는 법인세-통합고용 결과(종전 범위 인원) | 회사 급여 담당 | 상시근로자 수 |
| 공제감면세액계산서, 다른 공제감면 결과 | 당기 세무조정 | 함께 받으려는 공제감면 셋, 적용 선택 |

1. **창업일은 사업 개시일이다.** 사업자등록증 개업연월일을 쓴다. 법인 설립등기일과 다르면 회계사에게 알린다.
2. **창업 지역**은 네 가지 중 하나다: 수도권과밀억제권역 · 수도권(과밀억제권역 · 인구감소지역 제외) · 수도권 인구감소지역 · 수도권 밖. 주소만 보고 과밀억제권역인지 정하기 어려우면(인천 · 경기 일부) 회사 · 회계사에게 묻는다. 엔진은 주소를 판정하지 않는다.
3. **업종**은 조특법 제6조 제3항 각 호 이름 중 하나다(양식의 목록). 각 호 단서의 제외 업종(뉴스제공업 · 가상자산 매매 · 변호사업 · 공인회계사업 · 세무사업 · 오락장 운영업 등)이면 「업종 단서 제외 업종」 Y.
4. **연도별 시트**는 전기 신고서(3호 · 손익계산서)에서 각 사업연도 소득금액(감면사업분)과 수입금액을 옮긴다. 감면사업 소득금액이 처음 0 보다 큰 해가 최초 소득 과세연도다.
5. **상시근로자 수**는 고용증가 추가감면에만 쓰인다. 법인세-통합고용 스킬을 돌렸으면 그 종전 범위 인원(화면 둘째 줄)을 쓴다. 창업한 과세연도는 직전 줄이 없으면 엔진이 직전 인원을 0 으로 둔다. 법인전환 · 사업 승계로 시작했으면 「상시근로자 수(직전)」 에 종전 사업 인원을 넣는다.

## 순서

1. **양식 만들기**: `--template`. 이미 있으면 그대로 둔다. 설치를 확인하거나 사용법을 보일 때는 `--sample`.
2. **자료 옮기기**: 받은 자료에서 그대로 옮기고 지어내지 않는다. 모르는 칸은 비우고 물을 목록에 적는다.
   - **계산 전에 되묻는다(건너뛰지 않는다).** 설립 경위(합병 · 사업양수 · 법인전환 · 같은 업종 재개업 · 기존 사업 확장, 종전 사업 자산을 샀는지와 그 비율, 사업 분리 임직원 창업이면 2026-02-27 이후 개시분은 종전 회사와 친족관계 · 경영지배관계인지), 대표자가 최대주주인지, 대표자 생년월일 · 병역 기간을 모르면 엔진을 돌리기 전에 회사에 한 번에 묻는다. 비운 칸은 「아니오」 로 읽혀 감면을 크게 잡거나(창업 아닌 사유) 작게 잡는다(청년). 답을 못 받으면 돌린 값을 **잠정치** 로만 전한다.
3. **엔진 실행**: `PYTHONUTF8=1 python -m ctax startup "<회사>/<연도> 법인세"`. 화면 줄은 아래 「결과물」 표대로 읽는다. `확인:` 줄은 회계사에게 그대로 전한다.
4. **워크북 확인**: 「목록」 시트의 결과 · 검산 · 확인할 것을 먼저 본다. 노란 칸을 고쳤으면 입력 파일도 고치고 다시 돌린다(엔진 대조는 입력 파일 값 기준이다).
5. **보고**: 합계와 11O · 111, 판정 근거(창업일 · 업종 · 지역 · 청년 여부 · 차수 · 감면기간 끝나는 날), 추가감면 계산, 최저한세 · 5억원 한도로 깎인 금액, 중복 배제(통합고용 · 고용증대와 함께 받을 수 있는지), 엔진 대조 · 검산 결과, 확인 줄, 회사에 물을 칸, 이 검증이 보지 않는 것.

워크북 시트는 계산 순서대로다.

| 시트 | 볼 것 |
|---|---|
| 목록 | 결과(합계 · 11O · 111 · 감면 대상 · 구분 · 감면율 · 추가감면율 · 차수), 검산 8개, 확인할 것 |
| 0입력 | 회사 시트와 같은 값(노란 칸) |
| 0기준 | 창업 기한 · 청년 나이 · 소규모 수입금액 한도 · 업종별최소고용인원 · 5억원과 감면율 표, 칸마다 근거 조문 |
| 1연도별 | 과세연도별 소득 · 수입금액 · 상시근로자 |
| 2계산 | 1 창업 해당 → 2 감면기간 → 3 청년 → 4 지역 → 5 소규모 · 신성장 → 6 감면율 → 7 추가감면 → 8 감면세액 → 9 최저한세 · 한도 · 중복 |
| 3신청서 | 별지 제2호서식 11O · 111 · 1A4 줄의 ⑥ ~ ⑨ |
| 4엔진대조 | 엔진 값과 수식 값 55개. 「불일치」 가 있으면 입력이나 수식이 바뀐 것이다 |

검산 8개: 신청서 1A4 ⑨ = 2계산 합계, 11O ⑨ ≤ ⑧ ≤ ⑦, 111 ⑨ ≤ ⑧ ≤ ⑦, 감면세액 합계 ≤ 감면소득에 대한 세액, 감면율 + 추가감면율 ≤ 100%, 감면 후 111 이 최저한세를 지킴, 5억원 한도(2025 이후 창업), 엔진 대조 불일치 0건.

## 판단이 들어간 곳 (회계사에게 알릴 것)

근거와 등급은 `rules.yaml`. 아래는 회계사 확인 전이다.

- **최초 소득 과세연도**: 감면사업 소득금액이 처음 0 보다 큰 해. 다르게 보면 회사 시트 「최초 소득 과세연도 종료일」 에 넣어 덮는다.
- **추가감면분은 11O 줄**(제132조 제1항 제4호 나목, 최저한세 적용제외).
- **111 줄은 최저한세 여지 안에서만 받는다.** 여지는 산출세액 − 최저한세 − 「먼저 적용할 다른 최저한세 대상 감면 · 공제」 다. 다른 감면 · 공제를 먼저 적용할지는 납세자가 고른다. 먼저 적용하면 그 금액을 이 항목에 넣고, 비우면 창업감면이 여지를 먼저 쓴다.
- **청년 요건 상실 기업**은 소규모(제6항) · 종전 고용증가 추가감면 대상이 아니라고 보았다.
- **감면율 0 인 기업**(과밀억제권역 일반 창업)은 고용증가 추가감면도 없다고 보았다.
- **신성장 서비스업의 「최초로 세액을 감면받는 과세연도」** 를 최초 소득 과세연도로 두었다.
- **5억원 한도 초과분**은 111 줄에서 먼저 뺀다.
- **현행 제6항 1억4백만원과 종전 제7항(× 50/100)** 은 한 곳에서만 원문을 읽었다(★★☆).

## 확인한 법령 값 (★★★, 두 곳 원문 대조)

- 감면율: 2025년 이전 창업은 과밀억제권역 밖 청년 100% · 과밀억제권역 청년과 과밀억제권역 밖 일반 50% · 과밀억제권역 일반 0, 2026년 이후 창업은 수도권 밖과 수도권 인구감소지역 청년 100% · 일반 50%, 수도권(과밀 · 인구감소 제외) 청년 75% · 일반 25%, 과밀억제권역 청년 50% · 일반 0(제6조 제1항). 소규모 100% · 75% · 50%(제6항).
- 감면기간: 최초 소득 과세연도와 그 다음 과세연도 개시일부터 4년 이내에 끝나는 과세연도까지. 5년 동안 소득이 없으면 5년이 되는 날이 속하는 과세연도부터(제1항).
- 고용증가 추가감면: 2025년 이후 창업은 증가율(직전과 업종별최소고용인원 중 큰 값 기준), 한도 50%(감면율 75% 인 연도는 25%), 1% 미만 버림, 100% 감면 연도 제외(제7항, 시행령 제5조 제14항 10명 · 5명). 창업한 과세연도는 직전 과세연도 상시근로자 수를 0 으로 보아 업종별최소고용인원(10명 · 5명)이 기준이다(시행령 제5조 제17항 → 제23조 제13항 제1호).
- 5억원 한도와 통합고용 · 고용증대 중복 배제는 2025년 1월 1일 이후 창업부터(제6조 제13항, 제127조 제4항 단서, 부칙 <제20617호> 제2조).
- 최저한세 적용제외: 100% 감면 연도와 추가감면분(제132조 제1항 제4호 가목 · 나목).
