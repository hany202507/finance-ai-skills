## 시험해 보기

`examples/모의자료/` 는 제조업체 가온정밀(가상)의 자료다. 회사 · 거래처 · 사람 이름과 숫자는 모두 지어냈고, 기말 후 매출 취소 같은 이상 전표를 일부러 심었다. 분개장에는 작성자 · 승인자 · 입력일시 열이 있다(어떤 전표를 심었는지는 `tests/make_entry_columns.py` 머리말).

```bash
python scripts/run.py examples/모의자료/분개장_2025.xlsx --after examples/모의자료/분개장_2026_기말후.xlsx \
    --tb examples/모의자료/재무제표_시산표.xlsx --fy-end 2025-12-31 --pm 60000000 --company "가온정밀(가상)" --out out
```

기대 결과: 분개장 1,751행 · 차대 일치. 주말 · 공휴일 1, 기말 후 취소 · 역분개 6, 결산일 근처 큰 금액 32(기준 30,000,000), 드문 계정 조합 10, 끝자리 0 반복 16, 적요 없음 0, 수기 조정 4, 전표 형식 이상 0, 전표번호 중복 · 순서 역전 0, 한 번만 나온 거래처 4, 이익을 늘린 전표 5, 중복 의심 0, 대표 · 주주 · 임원 0, 자본 0, 적요 주의 낱말 3, 계정별로 평소보다 큰 금액 4, 자기 승인 · 승인 없음 5, 드물게 분개한 작성자 5, 결산 후 입력 6, 업무 시간이 아닌 입력 6. 결산월 매출은 월평균의 2.12배다. 먼저 볼 전표는 고위험 시험 전부 35 · 점수 상위 3 이다.
