# 분개테스트

회사 분개장 엑셀로 감사 분개 테스트(JET, 한공회 3600-JET) 조서를 만듭니다. 분개장 전부를 읽어 완전성을 맞추고, 시험 일곱 가지에 걸린 전표를 목록으로 냅니다.

- **완전성.** 차변 합계 = 대변 합계, 손익계정 분개장 순액 = 회사제시 시산표.
- **시험 일곱 가지.** 주말 · 공휴일 전표, 기말 후 취소 · 역분개(결산일 전 전표와 짝), 결산일 근처 큰 금액(수행중요성 기준), 드문 계정 조합, 끝자리 0 반복, 적요 없음, 수기 조정 전표.
- **결과.** `3600-JET_분개테스트.xlsx`. 요약 시트(시험별 건수 · 금액 · 확인 칸), 결과 목록(전표마다 사유와 회계사 검토 결과 칸), 완전성 시트.
- **입력.** 당기 분개장(여러 파일 가능), 결산일 후 분개장, 회사제시 시산표, 수행중요성. 더존 · 위하고 등 한 줄 한 계정 꼴과 두 계정 칸 꼴을 읽습니다.

## 시험해 보기

가상 회사 가온정밀(가상)의 분개장 · 결산일 후 분개장 · 시산표가 `examples/모의자료/` 에 있습니다. Claude 에게 「분개테스트 예시로 돌려 줘」 라고 하면 됩니다. 기말 후 매출 취소 같은 이상 전표를 일부러 심어 두었습니다.

## 한계

- 걸린 전표가 부정인지는 엔진이 정하지 않습니다. 회계사가 결과 목록에 검토 결과를 적습니다.
- 분개장에 입력구분(수기 · 자동) 열이 없으면 수기 조정 전표는 결산일 근처 적요 낱말로 대신 찾습니다.
- 공휴일 표는 2024~2026 입니다. 다른 해는 `scripts/definitions/jet.yaml` 에 더합니다.
