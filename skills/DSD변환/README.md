# DSD변환

DART 에 공시된 감사보고서 · 연결감사보고서를 DART 편집기 파일(dsd)로 바꿉니다. 회사가 dsd 를 주지 않았거나 초도 감사라 전기 dsd 가 없을 때, 작년 공시로 올해 dsd 를 시작할 때 씁니다.

- **원문 그대로.** 문단 · 표 · 칸 · 숫자 · 서식 표시는 공시 원문 바이트 그대로 두고, 공시 때 빠진 편집기 요소(삽입 위치 13곳 · 목차 · 안내문 · 문서 머리 · meta.xml)만 되살립니다.
- **다음 기수 초안.** 요청하면 당기 숫자를 전기 칸으로 옮기고 기수 · 해를 하나씩 올린 초안과 원고 엑셀을 만듭니다. 유형자산 같은 변동표는 새 당기 기초를 작년 기말로 채웁니다.
- **입력.** 접수번호(14자리), DART 에서 받은 PDF, 공시서류원본 xml 가운데 하나. 접수번호 · PDF 는 OpenDART 인증키(환경변수 `DART_API_KEY`)가 있어야 받습니다.

## 쓰는 법(Claude 에게 이렇게 말합니다)

1. 「<접수번호> dsd 로 바꿔 줘」 또는 「<PDF · xml 경로> dsd 로 바꿔 줘」.
2. 「다음 기수 초안까지 만들어 줘」. 원고 엑셀에서 고친 뒤 「이 원고로 dsd 다시 만들어 줘」.
3. 만든 dsd 는 DART 편집기로 열어 본 뒤에 씁니다. 숫자 검증은 [DSD푸팅](../DSD푸팅/) 스킬로 합니다.

## 검증

- 같은 보고서의 공시 원문과 편집기 저장 dsd 짝 두 건에서, 변환 결과의 삽입 위치 · 안내문 · 목차의 차례와 앞뒤 요소가 편집기 파일과 같았습니다.
- 2026년 3월 공시된 감사보고서 13건 · 연결감사보고서 8건을 바꿔 원문과 판 비교를 하니 추가 · 삭제 · 변경이 모두 0건이었습니다. dart4 꼴 공개 원문 49건 모두 본문이 원문과 같았습니다.

## 한계

- DART 편집기가 결과 파일을 여는지는 엔진으로 확인할 수 없습니다. 편집기 샘플과 뼈대가 같아 열릴 것으로 보지만, 열어 보고 쓰십시오. 열리지 않으면 `--bare` 판(문서 머리와 meta.xml 만 더한 판)도 열어 보십시오.
- 연결 감사보고서 틀은 편집기 샘플이 없어 별도 감사보고서 틀의 서식 코드와 이름을 연결로 바꾼 추정입니다. 감사인의 감사보고서 절의 라이브러리 파일 이름(FILENAME)도 추정입니다.
- 요약 코드(자산총계 · 감사의견 구분 등)는 원문 값 그대로입니다. 편집기 「문서 헤더정보」 에서 고칩니다.
- 다음 기수 초안은 자본변동표와 해마다 줄이 다른 표(날짜별 변동 내역 등)를 옮기지 않습니다. 감사인의 감사보고서 · 외부감사 실시내용 · 문단 속 날짜는 작년 글로 남습니다.
- 사업 · 반기 · 분기보고서 안의 감사보고서와 2019년 무렵 이전의 옛 dart3 원문은 바꾸지 않습니다.
