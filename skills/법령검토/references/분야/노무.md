# 분야: 노무

근로기준법, 근로자퇴직급여 보장법, 최저임금법과 그 특별법(기간제법, 파견법, 남녀고용평등법 등)을 다룬다.

## 1. 적용법 정하기

조문을 열기 전에 아래 사실부터 정한다. 질문에 없으면 가정을 적고 답을 갈라 쓴다(「5명 이상이면 …, 4명 이하면 …」).

| 확인할 사실 | 왜 | 출발 조문 |
|---|---|---|
| 상시근로자가 5명 이상인가 | 4명 이하면 근로기준법 일부만 적용된다 | 근로기준법 제11조, 시행령 제7조와 별표 1, 제7조의2(세는 법) |
| 4주 평균 주 소정근로시간이 15시간 미만인가 | 주휴·연차·퇴직급여가 빠진다 | 근로기준법 제18조 제3항, 근로자퇴직급여 보장법 제4조 제1항 단서 |
| 근로자인가(대표이사·임원, 프리랜서) | 근로기준법은 근로자에게만 적용된다 | 근로기준법 제2조 제1항 제1호, 대법원 판례 |
| 계약 형태(기간제, 단시간, 파견) | 특별법이 먼저 적용된다 | 기간제 및 단시간근로자 보호 등에 관한 법률, 파견근로자 보호 등에 관한 법률 |
| 사건 날짜(퇴직일, 해고일, 임금 지급일) | 기준일이다 | 없으면 오늘. 「2027년 최저임금」처럼 연도로 물으면 그해 1월 1일 |

## 2. 자주 묻는 질문과 출발 조문

| 질문 | 출발 조문 | 같이 볼 것 |
|---|---|---|
| 연차휴가 | 근로기준법 제60조, 제61조(사용 촉진) | 1년 계약직의 15일: 대법원 2021다227100 |
| 퇴직금 요건·계산 | 근로자퇴직급여 보장법 제4조·제8조, 근로기준법 제2조(평균임금) | 근로기준법 시행령 제2조(평균임금에서 빼는 기간) |
| 해고 | 근로기준법 제23조, 제26조(예고), 제27조(서면 통지), 제28조(구제 신청) | 4명 이하면 별표 1 |
| 연장·야간·휴일근로 가산 | 근로기준법 제56조 | 4명 이하면 적용 안 됨(별표 1) |
| 통상임금 | 근로기준법 시행령 제6조 | 대법원 2024. 12. 19. 2020다247190 전원합의체(적용 시점 주의) |
| 최저임금 | 최저임금법 제5조·제6조·제10조, 해마다 나오는 고용노동부 고시 | 수습 감액(제5조 제2항), 산입 범위(제6조 제4항) |
| 주휴 | 근로기준법 제55조, 제18조 제3항 | |

## 3. 출처

| 무엇 | 도구 | 주의 |
|---|---|---|
| 조문 | korean-law `get_law_text` | 별표는 법제처 통합검색 `get_annexes` |
| 고용노동부 행정해석(질의회시) | 법제처 통합검색 `search_decisions(domain="moel")` → `get_decision_text(domain="moel", id)` | 낱말은 두세 개만 준다(AND 검색). 본문까지 찾으려면 `options={"search": 2}` |
| 대법원 판례 | 법제처 통합검색 `search_decisions(domain="precedent", options={"search": "both", "court": "대법원"})`, 사건번호는 `options={"caseNumber": "…"}` | 최신순이라 `display` 를 10 으로 준다 |
| 노동위원회 판정 | `domain="nlrc"` | 제목 검색이라 0건이 잦다. 0건을 「판정 없음」으로 적지 않는다 |
| 산재·고용보험 재심사 | `domain="iaciac"`, `domain="eiac"` | |
| 고시(최저임금 등) | 법제처 통합검색 `execute_tool("search_admin_rule")` → `execute_tool("get_admin_rule")` | 본문이 첨부 PDF 뿐인 고시가 있다. 사용자 허락을 받고 내려받아 `pypdf` 로 읽는다 |

같은 뜻을 다르게 적은 말이 많다. 0건이면 다른 표기로 한 번 더 찾는다: 「5인 미만」·「4인 이하」·「4명 이하」, 「초단시간」·「주 15시간 미만」, 「연차」·「연차유급휴가」, 「퇴직금」·「퇴직급여」.

개정 논의가 잦은 쟁점(4명 이하 사업장 적용 확대, 주휴수당)은 기준일이 오늘이어도 의안 검색을 한다(`bill_search.py --대상 "근로기준법:제11조" --키워드 "5인 미만"`).
