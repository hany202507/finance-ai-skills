# 분야: 세법

국세(소득세, 법인세, 부가가치세, 상속세·증여세 등), 조세특례제한법, 국세기본법, 지방세를 다룬다. 세법 조문은 TaxDoctor 와 korean-law 두 곳에서 같은 판을 읽어야 ★★★ 다.

## 1. 적용법 정하기

| 확인할 사실 | 왜 | 출발 조문 |
|---|---|---|
| 세목 | 법률·시행령·시행규칙이 세목마다 따로다 | 해당 세법 |
| 납세자(개인, 법인, 비거주자·외국법인) | 비거주자는 조세조약이 먼저다 | 해당 세법, 조세조약 |
| 과세기간·사업연도, 거래일(양도일 등) | 기준일이다. 과세기간을 물으면 그 기간 끝 날 | |
| 조세특례제한법 특례가 있는가 | 감면·공제가 따로 있다 | 조세특례제한법 |
| 지방세가 따로 붙는가 | 지방소득세 등은 지방세법이다 | 지방세법 |

## 2. 자주 묻는 질문과 출발 조문

| 질문 | 출발 조문 | 같이 볼 것 |
|---|---|---|
| 1세대 1주택 비과세 | 소득세법 제89조 제1항 제3호, 시행령 제154조·제155조 | 양도소득세 스킬 |
| 장기보유특별공제 | 소득세법 제95조 | |
| 업무용승용차 비용 | 법인세법 제27조의2 | 시행령 제50조의2 |
| 가산세 | 국세기본법 제47조의2 이하 | 세법자문-회신 스킬 |

## 3. 출처

| 무엇 | 도구 | 주의 |
|---|---|---|
| 조문 | TaxDoctor `get_article` 과 korean-law `get_law_text` 같은 판 | 머리줄 법령명이 요청과 같은지 본다 |
| 조세심판원 결정 | korean-law `search_rulings(source="tribunal")` → `get_ruling` | 본문이 온다 |
| 국세청 예규·해석 | korean-law `search_rulings(source="nts")`, 법제처 통합검색 `search_decisions(domain="nts")` | 예규는 본문 링크를 열어 읽은 것만 ★★★ |
| 판례 | TaxDoctor `search_cases`, 법제처 통합검색 `domain="precedent"` | |
