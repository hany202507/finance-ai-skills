# 분야: 상법(회사법)

상법 회사편과 상장회사 특례, 필요하면 자본시장과 금융투자업에 관한 법률을 다룬다.

## 1. 적용법 정하기

| 확인할 사실 | 왜 | 출발 조문 |
|---|---|---|
| 회사 종류(주식회사, 유한회사 등) | 적용되는 장이 다르다 | 상법 제3편 |
| 자본금이 10억원 미만인가 | 소규모회사 특례가 있다(이사 1~2명, 감사 생략, 이사회 기능을 주주총회·이사가 나눔) | 상법 제383조, 제409조 제4항, 제363조 제3~5항 |
| 상장회사인가 | 상장회사 특례와 자본시장법이 먼저 적용된다 | 상법 제542조의2 이하, 자본시장법 제165조의2 이하 |
| 정관에 정한 것이 있는가 | 정관으로 달리 정할 수 있는 조문이 많다 | 해당 조문의 「정관으로 정한」 문구 |
| 결의일·거래일 | 기준일이다 | 없으면 오늘 |

## 3. 출처

| 무엇 | 도구 | 주의 |
|---|---|---|
| 조문 | korean-law `get_law_text` | |
| 대법원 판례 | 법제처 통합검색 `search_decisions(domain="precedent", options={"search": "both", "court": "대법원"})`, 사건번호는 `options={"caseNumber": "…"}` | 제목 검색만 하면 「자기주식」 같은 낱말에 세무 사건이 앞에 깔린다 |
| 법제처 법령해석례 | korean-law `search_decisions(domain="expc")` 또는 법제처 통합검색 `domain="interpretation"` | |
| 거래소 규정·공시 | 이 스킬의 도구로는 못 본다 | 웹으로 찾으면 ★★☆ |
