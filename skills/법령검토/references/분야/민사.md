# 분야: 민사(민법·임대차 등)

민법과 그 특별법(주택임대차보호법, 상가건물 임대차보호법, 이자제한법 등)을 다룬다.

## 1. 적용법 정하기

| 확인할 사실 | 왜 | 출발 조문 |
|---|---|---|
| 특별법이 있는 계약인가(주택·상가 임대차, 금전대차 이자 등) | 특별법이 민법보다 먼저 적용된다 | 주택임대차보호법, 상가건물 임대차보호법, 이자제한법 |
| 당사자 한쪽이라도 상인인 거래인가 | 상법(상행위)이 먼저다. 상사시효는 5년이다 | 상법 제64조 |
| 사건 날짜(계약일, 종료일, 청구일) | 기준일이다 | 없으면 오늘 |

## 2. 자주 묻는 질문과 출발 조문

| 질문 | 출발 조문 | 같이 볼 것 |
|---|---|---|
| 소멸시효 기간 | 민법 제162조(일반 10년), 제163조·제164조(단기) | 상사채권은 상법 제64조 |
| 시효가 언제부터 진행하나 | 민법 제166조 | |
| 임대차 보증금 반환 | 주택임대차보호법 제4조 제2항, 상가건물 임대차보호법 제9조 제2항 | 대법원 2016다244224, 244231 |
