# 현금흐름표 · 워크북 시트 구성

> 현금흐름표 스킬의 딸린 자료다. 결과 워크북의 시트 뜻이나 분개장에서 활동이 비어 있는 줄의 이유를 설명할 때 읽는다. 본문의 「아래 「검증의 두 묶음」」 은 SKILL.md 의 그 절이다.
> 2026-11-15 SKILL.md 에서 글자 그대로 옮겼다.

## 워크북

| 시트 | 내용 |
|---|---|
| 요약 | 두 묶음. 내부 일관성(산술·대사·구조, 10~12개)과 독립 검산(A·B·B'·C). 주어진 기말과 다른 계정 수, 확인사항 수, 활동별 합계 |
| 독립검산 | 분류와 무관한 사실로 분류를 확인한다(아래 「검증의 두 묶음」). 전부 분개장 SUMIFS 수식 |
| 현금흐름표_직접법 | 항목별 `SUMIFS(분개장 현금영향, 최종활동, 최종항목)`. Ⅰ영업 Ⅱ투자 Ⅲ재무 Ⅳ환율 Ⅴ증감 Ⅵ기초 Ⅶ기말 |
| 현금흐름표_간접법 | 정산표에서 당기순이익 · 손익 계정과목별 가산 · 차감 · 순액 · 자산부채 변동. 투자·재무·환율은 직접법 항목 |
| 간접법_정산표 | 감사인 정산표. 계정 행별 기말·기초·증감·검산과 설명 칸, 합계, 요약(활동별 = 직접법), 손익계산서 대사. 모든 칸이 분개장 수식(비용가산·수익차감·비현금 칸은 분개장 정산칸·정산라벨·정산금액 열에서) |
| 비교 | 활동별 직접법 · 정산표 · 차이, 재분류 내역 |
| 분개장 | 원 분개 + 현금흐름 열(현금영향·기본/자동/수정/최종 활동·항목·판정 방법·경로·원천·확인·적요 판정·분류 대상·이유) + 정산 열(비현금 몫이 정산표 어느 칸·라벨로 가는지, 금액) + 투자·재무 관련 비현금(독립검산 B 상한용), 분할·정산분할 행 |
| 기말재무상태표 | 주어진 기말 잔액. 정산표 기말 대조 칸이 참조한다 |
| 분류기준 | 활동 정의, 줄 상태별(분류함·현금 계정·분할 합계·현금 없는 전표·현금과 같은 편) 줄 수와 이유, 분류 순서, 판정 방법별 뜻·신뢰도·줄 수·금액, 정책과 적요 원칙 |
| 비현금거래 | 활동이 섞인 비현금분. `비현금 투자·재무 거래` 는 주석 공시 대상(문단 43) |
| 확인사항 | 분류·내용·금액·회계사 판단(노란 칸) |
| 계정규칙 · 전기재무상태표 | 판정 근거와 원자료 |

### 활동이 비어 있는 분개장 줄

분류 실패가 아니라 분류할 현금이 없는 줄이다. `분류 대상·이유` 열이 줄마다 어디로 갔는지 적는다.

| 줄 | 이유 | 어디서 설명되나 |
|---|---|---|
| 현금 계정 줄 | 현금흐름 그 자체 | 같은 전표의 상대 줄이 분류된다 |
| 분할 합계 줄 | 현금이 여러 항목으로 나뉨 | 바로 아래 분할 줄 |
| 현금이 없는 전표의 줄 | 현금이 오가지 않음(발생·대체·결산정리) | 간접법 정산표의 비용가산·수익차감·비현금거래·영업자산부채 증감, 또는 당기순이익 |
| 현금 전표지만 현금과 같은 편인 줄 | 현금과 함께 차변(또는 대변)이라 이 줄로 현금이 안 오감(이자 원천세 선납세금, 외상 취득분 미지급금) | 위와 같다 |

한 해 분개장 약 19만 줄로 돌려 보면 분류한 줄은 1만 1천 줄 남짓이고 나머지는 이 네 가지다.
