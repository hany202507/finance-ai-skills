# DSD초안

전기(작년) 감사보고서 · 연결감사보고서 dsd 하나로 당기 초안 dsd 를 만듭니다. 회사가 준 전기 dsd 든, [DSD변환](../DSD변환/) 이 작년 공시 원문으로 만든 dsd 든 그 파일만 있으면 됩니다.

- **옮기는 것.** 당기 숫자를 전기 칸으로 옮기고 당기 칸을 비웁니다. 기수 · 해 +1, 표지 · 재무제표 머리 · 날짜 속성도 한 해 뒤로. 변동표의 새 당기 기초는 작년 기말, 따로 둔 당기 · 전기 두 표는 전기 표를 작년 당기 표 사본으로. 자본변동표와 위아래로 쌓은 주석 표, 세로 병합 칸이 든 표도 줄을 더하고 지워 옮깁니다.
- **손대지 않는 것.** 당기 · 전기를 가르지 못하는 표(당기말 한 기간만 적는 주주 · 담보 · 약정 표, 날짜별 변동 내역)는 작년 숫자를 그대로 두고 원고 엑셀에 분홍으로 칠합니다. 감사인의 감사보고서 · 외부감사 실시내용 · 문단 속 날짜와 금액도 작년 글입니다.
- **결과.** `<회사>_<다음 연도>_감사보고서_초안.dsd`, 원고 엑셀, 원고 검사와 초안 검산, 안내 파일. 만든 dsd 를 다시 읽어 원고와 칸마다 견주고, 같은 전기 파일이면 몇 번을 돌려도 바이트까지 같습니다.
- **검증.** 2026년 3월 공시 감사보고서로 견주면 엔진이 옮긴 표의 초안 숫자 가운데 94.5%(11개 회사) · 94.2%(처음 보는 26개 회사)가 올해 공시와 같았습니다. 43개 회사 초안 검산 0건.

## 쓰는 법(Claude 에게 이렇게 말합니다)

1. 「<전기 dsd 경로> 로 당기 초안 만들어 줘」.
2. 전기 dsd 가 없으면 먼저 「<접수번호> dsd 로 바꿔 줘」([DSD변환](../DSD변환/)), 그 다음 1번.
3. 원고 엑셀에서 고친 뒤 「이 원고로 dsd 다시 만들어 줘」. 만든 dsd 는 DART 편집기로 열어 본 뒤에 쓰고, 숫자는 [DSD푸팅](../DSD푸팅/) 으로 검증합니다.

## 시험해 보기

실제 회사 파일 없이 보려면 `tests/dsd_company.py` 가 가상 회사 누리정밀(가상)의 작년 dsd 를 만듭니다. `python -m pytest -q tests` 가 그 파일로 초안을 두 번 만들어 같은지, sheet → build 와 본문이 같은지 봅니다.

## 한계

- 당기 숫자는 채우지 않습니다. 정산표 · 조서로 채웁니다.
- 요약 코드(자산총계 · 감사의견 구분 등)는 작년 값 그대로입니다. 편집기 「문서 헤더정보」 에서 고칩니다.
- 회사가 올해 줄 · 표 모양을 바꾼 곳은 초안이 작년 모양이라 손으로 고칩니다.
- 사업 · 반기 · 분기보고서 안의 감사보고서는 다루지 않습니다.
