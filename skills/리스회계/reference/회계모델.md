# 리스회계(K-IFRS 1116) 회계모델 — 계산식·전표·함정

## 계산식 (월 단위)
```
월이자율        = 연 할인율 / 12
리스부채(최초)  = Σ 리스료ₜ / (1+월이자율)^t        ← 현재가치
                  선급(기시): t = 0..n-1 / 후급(기말): t = 1..n
사용권자산(최초)= 리스부채 + 선급리스료 + 리스개설직접원가 + 복구원가추정 − 리스인센티브
매월 이자비용   = (선급) (기초−지급)×월이자율 / (후급) 기초×월이자율   ← 유효이자율법
매월 감가상각비 = 사용권자산 / 상각기간                                ← 정액법
상각기간        = 매수선택권 행사 확실 시 내용연수, 아니면 리스기간
```
- 선급(annuity-due): 월초 지급 → 잔액 감소 후 이자 발생 → 마지막 지급월에 잔액 0(빈 행 없음).
- 검증 항등식: 총리스료 − 리스부채 = 총이자 = Σ(매월 이자). 기말잔액 0이면 정확히 성립.

## 전표 (분개)
- 최초인식(개시일):
  - 차) 사용권자산  / 대) 리스부채(현재가치)
  - 구성요소별로 따로 적는다: 선급리스료는 대) 선급리스료, 리스개설직접원가는 대) 보통예금,
    복구원가는 대) 복구충당부채, 리스인센티브는 차) 보통예금(사용권자산에서 차감)
  - 보증금: 차) 임차보증금 / 대) 보통예금  ← 리스료 아님, 별도 자산
- 매월(선급 기준):
  - 차) 리스부채   / 대) 보통예금      ← 리스료 지급(월초)
  - 차) 이자비용   / 대) 리스부채      ← 유효이자
  - 차) 감가상각비 / 대) 감가상각누계액 ← 정액
- 단기·소액 면제(1116.5): 12개월 이하(매수선택권 없음)·소액 → 자산·부채 없이
  차) 지급리스료 / 대) 보통예금.

## 검증 전략
1. 차변합 = 대변합 (전 기간). 각 전표가 차=대 동일액이므로 ROUND 후에도 항상 일치.
2. 리스부채·사용권자산 마지막 기간 후 장부금액 = 0.
3. 총리스료 − 리스부채 = 총이자.
4. `formulas` 라이브러리로 수식 독립 평가 → 엔진값과 일치(삼중 일치).
5. 할인율·갱신·단기리스 판단은 회계사 확정(가정 명시).

## 한계
- 변동리스료·리스변경(재측정)은 단순화 — 발생 시 수동/질문.
- 갱신·해지옵션 "행사 상당히 확실" 판단은 회계사 입력 의존.
- 복구원가·리스인센티브는 입력값이 있을 때만 반영. 복구원가는 현재가치로 입력한다.
- 복구충당부채의 기간 경과 이자(전입액)는 전표에 넣지 않는다. 별도로 계산해 추가한다.
- 선급↔후급 전환은 재생성 필요(할인율·리스료는 라이브 재계산).
- 다계약·다통화·연결은 로드맵.
