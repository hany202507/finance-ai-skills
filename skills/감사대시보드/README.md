# 감사대시보드

외부감사 한 건의 진행 상황을 조서 단위로 세어 화면 하나로 봅니다.

- **왼쪽.** 다섯 단계(시작 · 위험평가 · 실행 · 보고 · 종결)와 세부 항목 27개. 끝난 단계, 지금 단계, 항목별 상태와 이슈 수.
- **오른쪽.** 고른 항목의 조서번호와 상태, 스킬 적용 현황(엔진 실행 · AI 몫 · 회계사 확인), 이슈의 근거 금액과 출처 문서, 빠진 자료.
- **입력.** 감사 폴더의 `_색인` JSON(감사건 · 조서목록 · 문서목록 · 이슈 · 분석 · 실행기록). 화면을 그리기만 하고 숫자를 만들지 않습니다.
- **결과.** HTML 한 파일. 브라우저로 엽니다.

## 시험해 보기

가상 회사 가온정밀(가상)의 모의 감사 폴더 `_색인` 이 `examples/` 에 있습니다. 완성 화면은 `examples/감사대시보드_예시.html` 입니다. Claude 에게 「감사대시보드 예시로 만들어 줘」 라고 하면 됩니다.

## 한계

- `_색인` 을 만드는 감사 엔진 전체는 공개하지 않았습니다. 이 저장소의 PBC요청자료 · 분개테스트 · DSD푸팅은 그 엔진의 일부입니다. 자기 감사 건에 쓰려면 `_색인` 형식에 맞춰 조서목록 · 이슈를 채워야 합니다(예시 파일이 형식 견본입니다).
- 단계 · 조서 · 스킬 대응표는 `scripts/build.py` 맨 위에 있습니다. 조서 체계가 다르면 그 표를 고칩니다.
- `--demo` 는 시연용입니다. 조서 상태를 「위험평가까지 끝나고 실행 단계 중」 으로 바꿔 보이고, 화면 위 안내 띠에 그 사실을 적습니다.
