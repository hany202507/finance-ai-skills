# 출처별 결함과 대응

2026-10-09 양도소득세 근거 조사에서 같은 조문을 여러 출처로 받아 대조해 찾은 것이다. 새 결함을 찾으면 여기에 한 줄 더한다.

## TaxDoctor

| 결함 | 사례 | 대응 |
|---|---|---|
| 삭제된 조문을 요청하면 다른 법령의 같은 번호 조문을 오류 표시 없이 준다 | 소득세법 제93조 → 시행규칙 제93조, 제113조 → 시행령 제113조 | 머리줄 법령명이 요청과 같은지 본다. 다르면 korean-law 로 삭제 여부를 본다 |
| 위임 하위법령 목록이 빠진다 | 제95조 → 시행령 제159조의4·제160조, 제97조 → 제176조의2, 제104조의3 → 제168조의7·제168조의14 | `trace_references` 결과와 합친다 |
| 원천 스냅샷 해시가 법령 단위다 | 다른 조문이 개정돼도 바뀐다 | 조문이 바뀌었는지는 조문 본문으로 비교한다 |
| 시행예정 본문이 약 2,000자에서 잘리고 같은 판이 중복된다 | 소득세법 시행령 2027-01-01 판 | korean-law `get_law_text(mst, effective_date=시행일)` 로 전문을 읽는다 |
| `list_upcoming` 상태 표시가 낡는다 | 이미 시행된 2026-09-18 조특법 개정을 시행 전으로 표시 | 시행일과 오늘을 직접 비교한다 |
| 부칙 적용례를 주지 않거나 다른 판 부칙을 붙인다 | 시행령 제167조의10 2026-02-27 판에 2024-02-29 부칙이 붙음 | 부칙은 korean-law `get_addenda` 로 읽는다 |
| 서식 본문에서 ⑯ 뒤 란 번호를 `?` 로 바꾼다 | 소득세법 시행규칙 별지 제84호서식 | 란 번호는 원본 PDF·HWP 로 본다 |
| 현행판이 내부에서 「미검증」일 수 있다 | 시행령 제167조의3 2026-10-01 판 | korean-law 원문과 대조한 것만 쓴다 |
| 세법이 아닌 법령이 거의 없다 | 비세법 158개 중 2개만 수록 | korean-law 로 연다 |
| law.go.kr URL 을 주지 않는다 | 모든 응답 | ★★★ 에 필요한 URL 은 korean-law 에서 받는다 |

## korean-law (2026-10-09 이전 판)

아래 셋은 계획 0 에서 고쳤다. 고친 판인지는 `get_law_text` 머리에 `(오늘 YYYYMMDD 기준 시행 중인 판)` 이 붙는지로 안다.

| 결함 | 사례 | 고친 뒤 동작 |
|---|---|---|
| 짧은 법령명을 다른 법으로 찾았다 | 「주택법」 → 민간임대주택법·공영주택법, 「상법」 → 다른 법 | 이름이 정확히 같은 법령만 쓰고, 없으면 실패한다 |
| 날짜가 없으면 시행 전 개정이 섞인 공포본을 줬다 | 주택법 제63조의2 → 2027-03-09 시행본 | 오늘 시행 중인 판을 읽는다 |
| 표 안의 목·세목을 빠뜨렸다 | 소득세법 제104조①11·12호, 시행령 제167조의3 라·마목 | 목내용이 배열이어도 모두 출력한다 |

날짜는 실제 날짜 형식(YYYY-MM-DD 등)으로 줘야 한다. 형식이 틀린 날짜는 「날짜 형식이 아니다」 로 거절된다.

## 법제처 OPEN API (DRF)

- 본문은 `target=eflaw` 에 MST 와 `efYd` 를 함께 준다. `target=law` 에 MST 만 주면 시행 전 개정까지 섞인다
- 인증 실패도 HTTP 200 으로 온다. 응답의 `result` 에 「실패」가 있으면 실패로 본다
- 응답 링크에 OC 값이 평문으로 들어 있다. 저장·출력 전에 가린다
- 같은 시행일에 MST 가 여럿이면 가장 늦게 공포된 것을 쓴다
- 목록의 현행·시행예정 표시가 낡을 때가 있다. 시행일과 오늘을 직접 비교한다
- `lsInfoR.do` 와 law.go.kr 한글주소는 공식 OPEN API 가 아니다

## 법제처API (gomdori)

- 날짜를 주지 않으면 공포본을 준다. `efYd` 를 늘 준다
- 별표는 HTML 표로 와서 숫자 대조에 쓸 만하다

## 고시·공고

- 조정대상지역(행정규칙ID 85055)·투기과열지구(85053)는 법제처 행정규칙 연혁으로 감지된다. 지역 목록은 첨부 PDF 에만 있고, 제개정이유는 증감만 요약하며 표제가 틀린 경우가 있다(2025-1223호)
- 관보 검색은 제목 색인이다. 제목에 키워드가 없는 공고를 놓칠 수 있다
- 지정지역(투기지역)은 법제처 행정규칙에 없다. 관보로 본다
